## Overview

The MS Teams editor supports two authoring modes: a **Markdown** editor for straightforward messages, and a **JSONNET** editor for rich messages using Teams' [Adaptive Cards](https://adaptivecards.io/). Both modes use the same Variables panel and preview panel.

## Getting Started

To add MS Teams to a template, open the template in edit mode, click **+** in the channel tab row, select **MS Teams**, and click **Add Channels**.

To send MS Teams notifications, you need an MS Teams vendor configured in your workspace. See [MS Teams Vendor Integration](/docs/ms-teams-vendor-integration).

## Editor Modes

Switch between modes using the **JSONNET** and **Markdown** tabs at the top of the editor.

### Markdown Mode

A plain text editor that supports Markdown formatting. Use this for simple, readable messages that don't require rich card layouts or interactive components.

Supports **Handlebars** syntax for dynamic variables:
- Use `{{variable}}` for standard variables
- Use `{{{variable}}}` for variables containing special characters

The hint below the tab reads: *"Add variable in handlebars format as `{{...}}`. Enclose variable containing special characters in `{{{...}}}`"*

Supported Markdown formatting in Teams messages:

| Syntax | Output |
| --- | --- |
| `**text**` | **Bold** |
| `*text*` | *Italic* |
| `` `code` `` | Inline code |
| `[label](url)` | Hyperlink |
| `> text` | Blockquote |

The preview panel on the right renders the message as it appears in MS Teams — showing the bot name, timestamp, and message body in a real Teams message card, updating in real time as you type.

### JSONNET Mode

A code editor for writing JSONNET that evaluates to an [Adaptive Card](https://adaptivecards.io/) JSON payload. Use this for structured messages with rich layouts — images, tables, fact sets, action buttons, and input fields.

Supports **JSONNET** syntax for dynamic variables:
- Use `data.key` for top-level payload keys
- Use `data["$batched_events"].key` for batched event data

The hint below the tab reads: *"Add variable in JSONNET as `data.key` or `data["$batched_events"].key`"*

The preview panel renders a live preview of the Adaptive Card and shows a **Load preview** button to refresh it. JSONNET evaluation errors are displayed in red directly in the preview panel — e.g. `JsonnetEvaluateError: Expected token ")" but got (IDENTIFIER, ...)`. Fix the JSONNET syntax and click **Load preview** to re-render.

<Info>
  Design your Adaptive Card visually using the [Adaptive Cards Designer](https://adaptivecards.io/designer/), then adapt the resulting JSON into JSONNET syntax — replacing hardcoded values with `data.key` variable references — and paste it into the JSONNET editor.
</Info>

## Variables

### In Markdown mode (Handlebars)

| Source | Syntax | Description |
| --- | --- | --- |
| Trigger payload | `{{order_id}}` | Top-level key from workflow payload |
| Nested key | `{{order.status}}` | Nested object property |
| URL / special characters | `{{{tracking_url}}}` | Triple braces prevent HTML-escaping |
| Recipient profile | `{{$recipient.first_name}}` | From the user's SuprSend profile |
| Tenant property | `{{$brand.brand_name}}` | From the linked tenant |
| Batched event count | `{{$batched_events_count}}` | Number of batched events |

### In JSONNET mode

| Source | Syntax | Description |
| --- | --- | --- |
| Trigger payload | `data.order_id` | Top-level key from workflow payload |
| Nested key | `data.order.status` | Nested object property |
| Recipient profile | `data['$recipient'].first_name` | From the user's SuprSend profile |
| Tenant property | `data['$brand'].brand_name` | From the linked tenant |
| Batched events | `data['$batched_events'][0].key` | Individual batched event property |

For advanced Handlebars logic, see [Handlebars Helpers](/docs/handlebars-helpers).

## Live Preview

**Markdown mode** — the preview panel updates in real time as you type, rendering the message exactly as it appears in a Teams channel.

**JSONNET mode** — the preview panel renders your Adaptive Card and shows a **Load preview** button to re-render after edits. If your JSONNET has a syntax or evaluation error, the error message is displayed in red in the preview panel with the exact line and position of the problem. Fix the error and click **Load preview** to retry.

To preview with a specific user's data, search for a user in the **Recipient** section of the Variables panel.

## Variants

Templates support multiple **variants** — separate content versions for different tenants, languages, or conditions. The left panel shows **Open Tabs** (variants currently open) and **All Variants** (grouped by channel). The `default` variant is used when no other variant conditions match.
