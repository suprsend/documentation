---

The SuprSend React SDK provides drop-in components and headless hooks to embed a full-featured notification experience in your React application. Real-time delivery, customizable themes, and multiple layout options — all with minimal setup.

## Install

```bash
npm install @suprsend/react
```

## Quick look

```jsx
import { SuprSendProvider, Inbox } from "@suprsend/react";

function App() {
  return (
    <SuprSendProvider
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="USER_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <Inbox />
    </SuprSendProvider>
  );
}
```

## Get started

<Steps>
  <Step title="Authenticate">
    Generate a JWT token on your backend and pass it to `SuprSendProvider`. This securely connects the user to their notification feed.

    [Set up authentication →](/docs/react-authentication)
  </Step>
  <Step title="Add a component">
    Drop in `<Inbox />` for a popover feed or use `<Feed />` for a full-screen / side sheet layout. Add `<Toast />` for transient alerts.
  </Step>
  <Step title="Customize">
    Theme the components to match your app's design, add multi-language support, or go fully headless for complete control.
  </Step>
</Steps>
