---

The Expo SDK ships a headless in-app notification feed re-exported from [`@suprsend/react-core`](https://github.com/suprsend/suprsend-react-core). Render it with React Native primitives.

## Basic usage

Mount `SuprSendFeedProvider` inside [`SuprSendExpoProvider`](/docs/expo-integration#authentication):

<CodeGroup>
  ```tsx App.tsx
  import { SuprSendExpoProvider, SuprSendFeedProvider } from "@suprsend/expo-sdk";

  export default function App() {
    return (
      <SuprSendExpoProvider {...authProps}>
        <SuprSendFeedProvider>
          <RootNavigator />
        </SuprSendFeedProvider>
      </SuprSendExpoProvider>
    );
  }
  ```
</CodeGroup>

## Reading the feed

<CodeGroup>
  ```tsx Inbox.tsx
  import { useFeedData, useFeedClient } from "@suprsend/expo-sdk";
  import { FlatList, Text, Pressable } from "react-native";

  function Inbox() {
    const feedData = useFeedData();
    const feedClient = useFeedClient();

    return (
      <FlatList
        data={feedData?.notifications ?? []}
        keyExtractor={(n) => n.n_id}
        renderItem={({ item }) => (
          <Pressable onPress={() => feedClient?.markAsInteracted(item.n_id)}>
            <Text>{item.message.header}</Text>
          </Pressable>
        )}
      />
    );
  }
  ```
</CodeGroup>

For the full feed API (pagination, filters, mark-as-read helpers, etc.) see the [`@suprsend/react-core` docs](https://github.com/suprsend/suprsend-react-core).
