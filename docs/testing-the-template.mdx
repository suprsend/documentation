## Overview

The **Test** button in the template editor lets you send a real notification 
to a user's device directly from the editor — so you can see exactly how the 
message renders before going live.

Variables in the template are rendered using the mock data added in the 
**Input Payload** panel. Make sure all variables used in the template have 
corresponding values in mock data, otherwise the test notification will fail 
to render.

<Note>
  When [Test Mode](/docs/developer/test-mode) is enabled in your workspace, 
  template testing will respect Test Mode settings — test notifications are 
  delivered to your configured test channels instead of real users.
</Note>

---

## How to Send a Test

Click the **Test** button in the top-right corner of the template editor. A 
modal opens with two tabs: **Selected Variant** and **Template Group**.

---

### Selected Variant

Use this tab to test a **specific variant** of a specific channel — useful 
when you want to verify a particular variant's content in isolation.

| Field | Description |
| --- | --- |
| **Channel** | Select the channel to test (e.g. In-App Inbox, Email, SMS). |
| **Recipient** | Enter the `distinct_id` of the user who will receive the test. The user must exist in SuprSend. After entering, their registered identities for the selected channel are shown with checkboxes — deselect any you want to exclude. |
| **Notification Category** | The vendor and delivery settings for this [category](/docs/notification-category) will be used to send the notification. Defaults to Transactional. |
| **Tenant ID** | Select the [tenant](/docs/tenants) to test with. Defaults to `default`. |

Click **Send Test** to trigger the notification.

### Template Group

Use this tab to test the **entire template group** across all channels 
associated with the recipient — letting SuprSend automatically select the 
correct variant based on your inputs, exactly as it would in a real workflow run.

| Field | Description |
| --- | --- |
| **Recipient** | Enter the `distinct_id` of the user. All channels associated with that user are shown in a table with checkboxes — deselect any you want to exclude. |
| **Notification Category** | The vendor and delivery settings for this category will be used. Defaults to Transactional. |
| **Tenant ID** | Select the tenant to test with. Defaults to `default`. |

<Info>
  The variant whose conditions match the Tenant ID and recipient variables 
  entered will be sent — not necessarily the variant you are currently editing. 
  This reflects real workflow behavior.
</Info>

Click **Send Test** to trigger the notification.

<Frame caption="Template Group tab — test across all channels with automatic variant selection">
  <img src="/images/docs/templates-test-template-group.png" />
</Frame>

## After Sending

Once the test is triggered, go to the [Logs](/docs/logging) page to check the 
delivery status and see if the notification was rendered and sent successfully.
