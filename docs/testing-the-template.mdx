---
title: "Testing Templates"
description: "Send a test notification from the template editor to a real device to verify rendering, variables, and layout before publishing template changes."
---

You can send test notifications directly from the template editor to verify how the message appears on a user's device. This helps catch rendering issues, variable mismatches, and layout problems before pushing content to production.

## How to send a test

Click the **Test** button in the top-right corner of the template editor. The test panel offers two modes:

### Test a specific variant

Use the **Selected Variant** tab to test one variant on a **single channel**. This is useful when you want to verify how a specific channel's content looks - for example, testing only the SMS variant without triggering Email or Push.

<Steps>
  <Step title="Select channel and variant">
    Choose the **Channel** (for example, SMS, Email, In-App Inbox) from the dropdown. The currently open variant is pre-selected.
  </Step>
  <Step title="Enter recipient">
    Search by email or distinct ID. The panel shows available identities for the selected channel.
  </Step>
  <Step title="Choose category and tenant">
    Optionally select a **Notification Category** and **Tenant ID**. The variant whose conditions match will be sent.

    Notification Category is not required, but is used to fetch the correct [vendor](/docs/vendors) configuration for that category. If your vendors are configured per-category (for example, separate SMS vendors for transactional vs promotional), selecting the right category ensures the test uses the correct vendor.
  </Step>
  <Step title="Send">
    Click **Send Test**. Check [Logs](/docs/logging) to monitor the delivery status.
  </Step>
</Steps>

</Frame>

### Test the full template group

Use the **Template Group** tab to test across all enabled channels at once.

<Steps>
  <Step title="Enter recipient">
    Search by email or distinct ID. The panel lists all channels associated with that user along with their identities.
  </Step>
  <Step title="Select channels">
    Check the channels you want to include in the test.
  </Step>
  <Step title="Choose category and tenant">
    Optionally select a **Notification Category** and **Tenant ID**. Notification Category is not required but is used to fetch the correct [vendor](/docs/vendors) configuration for that category.
  </Step>
  <Step title="Send">
    Click **Send Test**. A test notification is sent on each selected channel.
  </Step>
</Steps>

</Frame>

## Important notes

- Variable data from the **Variables panel** (Input Payload, Recipient, Tenant) is used to render the test notification. Add values for all variables used in the template - missing values will cause the notification to fail.
- Tests use the **live version**. Commit your changes before testing to see the latest content.
- For WhatsApp and SMS (DLT) templates, the test will only succeed if the template has been approved by the vendor.
