## Overview

WhatsApp Business messaging is regulated by Meta. Every message sent outside a 24-hour customer-initiated window must use a **pre-approved message template**. The WhatsApp editor in SuprSend is designed around this structure — helping you build compliant templates with the right category, message type, and component layout.

The editor renders a live WhatsApp conversation preview on the right as you compose.

---

## Getting Started

To add WhatsApp to a template, open the template in edit mode, click **+** in the channel tab row, select **WhatsApp**, and click **Add Channels**.

To send WhatsApp messages, you need a WhatsApp Business vendor configured in your workspace. See [WhatsApp Vendor Integration](/docs/whatsapp-vendor-integration).

## Fields

### Template Category *(required)*

Meta requires every WhatsApp Business template to be categorised. Select the category that best describes your message:

| Category | Description |
| --- | --- |
| **Utility** | Transactional messages tied to a user action — order confirmations, receipts, alerts, OTPs. |
| **Marketing** | Promotional or engagement messages — offers, announcements, re-engagement. |
| **Authentication** | One-time passwords and verification codes. |

<Warning>
  Choose the category carefully. Meta reviews templates against their category definition. A mismatched category is a common reason for template rejection. Utility templates generally have higher deliverability and lower cost than Marketing.
</Warning>

### Type *(required)*

The media type of the message header — determines what appears at the top of the message:

| Type | Description |
| --- | --- |
| **Text** | Plain text header. |
| **Image** | Image displayed at the top of the message. |
| **Video** | Video displayed at the top of the message. |
| **Document** | A downloadable document (PDF, etc.) at the top. |

### Header

The topmost component of the message, displayed above the body. When **Type** is `Text`, this is a short text line used for a title or context (e.g. `Order Update`). When Type is Image, Video, or Document, this field accepts a media URL.

Supports Handlebars variables.

### Body *(required)*

The main content of the message.

- Maximum **1024 characters** — a live character counter is shown below the field.
- Supports Handlebars variables and emoji.
- Supports WhatsApp native text formatting: `*bold*`, `_italic_`, `~strikethrough~`, `` `monospace` ``.

### Footer

An optional short line displayed below the body in lighter text. Used for disclaimers or opt-out instructions (e.g. `Reply STOP to unsubscribe`).

- Maximum **60 characters** — a live character counter is shown.
- Does not support variables or rich formatting.

### Button Type

Optional interactive buttons. Select the type:

| Button Type | Description |
| --- | --- |
| **Quick Reply** | Tap-to-reply buttons — the recipient taps and a pre-defined message is sent back. Use for confirmations or simple choices. |
| **Call to Action** | Buttons that open a URL or dial a phone number. Use for "Track Order" or "Call Support". |

Button configuration fields appear below once a type is selected.

## Live Preview

The right panel shows a live WhatsApp conversation preview — rendered exactly as it appears on the recipient's device, with the SuprSend sender identity and green chat bubbles. Updates in real time as you fill in fields.

To preview with a specific user's data, search for a user in the **Recipient** section of the Variables panel.

## Variables

Header and Body support Handlebars syntax. Footer does not support variables.

| Source | Example | Description |
| --- | --- | --- |
| Trigger payload | `{{order_id}}` | Data sent when the workflow triggers |
| Recipient profile | `{{$recipient.first_name}}` | Properties from the user's SuprSend profile |
| Tenant | `{{$brand.brand_name}}` | Tenant branding properties |

<Info>
  When SuprSend submits your template to Meta for approval, named Handlebars variables like `{{order_id}}` are automatically converted to Meta's positional format (`{{1}}`, `{{2}}`). You always write named variables — SuprSend handles the conversion.
</Info>

For conditionals and helpers, see [Handlebars Helpers](/docs/handlebars-helpers).
