Adding Email to a SuprSend workspace is three steps:

1. **Configure an Email vendor** in the dashboard.
2. **Make sure your users have `$email`** set in their profile.
3. **Add an Email delivery node** to your workflow with an Email template.

---

## 1. Configure an Email vendor

SuprSend doesn't send email itself — it routes through your provider. Sandbox ships with a pre-configured vendor so you can test immediately. For Staging and Production, bring your own:

| Vendor | Setup guide |
|---|---|
| SendGrid | [Setup](/docs/sendgrid) |
| Amazon SES | [Setup](/docs/amazon-ses) |
| Mailgun | [Setup](/docs/mailgun) |
| Resend | [Setup](/docs/resend) |
| Postmark | [Setup](/docs/postmark) |
| Mailjet | [Setup](/docs/mailjet) |

Use [Vendor Fallback](/docs/vendor-fallback) if you want automatic failover between two providers (e.g. SendGrid → Mailgun).

## 2. Recipient identity field

The Email channel identity on a user profile is `$email`. It's an array of addresses — SuprSend will deliver to all of them.

```json
{
  "distinct_id": "user_123",
  "$email": ["primary@example.com", "secondary@example.com"]
}
```

You can either set this once via [user identify](/docs/users#creating-user-profile-on-suprsend), or pass it inline at trigger time:

```json
"recipients": [
  {
    "distinct_id": "user_123",
    "$email": ["recipient@example.com"]
  }
]
```

## 3. Email template

Use the [Email template editor](/docs/email-template) — drag-and-drop blocks, raw HTML, or AMP. Variables use [Handlebars](/docs/handlebars-helpers): `{{var}}` HTML-escapes; `{{{var}}}` is raw (use for URLs and special characters). **Publish** the template before saving the workflow.

For multi-language sends, see [Multi-lingual templates](/docs/multi-lingual-template).

---

## Email gotchas

- **Sandbox limitation:** Email can only be sent to verified addresses (anti-spam) during the trial.
- **Triple braces for URLs:** `{{{action_url}}}`, not `{{action_url}}` — otherwise special characters get HTML-escaped and the link breaks.
- **Track engagement:** add the SuprSend webhook URL in your vendor portal so opens, clicks, and bounces show up in [Logs and Analytics](/docs/logging).
- **Deliverability:** authenticate your sending domain (SPF, DKIM, DMARC) on your vendor before going live.
