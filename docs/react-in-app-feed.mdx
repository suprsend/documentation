The `Inbox` component renders a bell icon with an unread badge. Clicking it opens a popover containing the user's notification feed — complete with real-time updates, infinite scroll, and action buttons.

Try it live in the [Interactive Playground](https://inbox-playground.suprsend.com/).

## Prerequisites

Make sure you have [installed the SDK and set up `SuprSendProvider`](/docs/react-installation) before adding the Inbox component.

## Integration

The `Inbox` component must be rendered inside `SuprSendProvider`. It internally wraps `SuprSendFeedProvider`, so you don't need to add that separately.

```jsx
import { SuprSendProvider, Inbox } from "@suprsend/react";

function App() {
  return (
    <SuprSendProvider
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="YOUR_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <Inbox />
    </SuprSendProvider>
  );
}
```

## Configuration

Pass props to `Inbox` to control its behavior and appearance.

```typescript
interface InboxProps {
  tenantId?: string;
  stores?: IStore[] | null;
  host?: { socketHost?: string; apiHost?: string };
  pageSize?: number;
  pagination?: boolean;
  theme?: ITheme;
  themeType?: ThemeType;
  popperPosition?: Placement;
  hideAvatar?: boolean;
  showUnreadCountOnTabs?: boolean;
  notificationClickHandler?: (notification: IRemoteNotification) => void;
  primaryActionClickHandler?: (notification: IRemoteNotification) => void;
  secondaryActionClickHandler?: (notification: IRemoteNotification) => void;
  bellComponent?: React.FC;
  badgeComponent?: React.FC<{ count: number }>;
  loaderComponent?: React.FC;
  noNotificationsComponent?: React.FC;
  tabBadgeComponent?: React.FC<{ count: number }>;
  notificationComponent?: React.FC<CustomNotificationCard>;
  headerRightComponent?: React.FC<{
    markAllRead: () => void;
    closeInboxPopover: () => void;
  }>;
}
```

| Prop | Type | Description |
|------|------|-------------|
| `tenantId` | `string` | Filter notifications by tenant. Defaults to `"default"`. |
| `stores` | `IStore[]` | Define multiple tabs to group notifications. See [Adding tabs](/docs/react-customising-feed#adding-tabs). |
| `pageSize` | `number` | Notifications per page. Default `20`, max `100`. |
| `pagination` | `boolean` | Enable infinite scroll pagination. Default `true`. |
| `theme` | `ITheme` | CSS style overrides. See [Customising CSS styles](/docs/react-customising-feed#customising-css-styles). |
| `themeType` | `"dark" \| "light"` | Toggle dark or light mode. |
| `popperPosition` | `Placement` | Popover position relative to the bell (`"top"`, `"bottom"`, `"left"`, `"right"`). |
| `hideAvatar` | `boolean` | Hide notification avatars. |
| `showUnreadCountOnTabs` | `boolean` | Show unread count badge on tabs. |
| `notificationClickHandler` | `function` | Callback when a notification card is clicked. Overrides default URL navigation. |
| `primaryActionClickHandler` | `function` | Callback for the primary action button. |
| `secondaryActionClickHandler` | `function` | Callback for the secondary action button. |
| `bellComponent` | `React.FC` | Replace the default bell icon with a custom component. |
| `badgeComponent` | `React.FC` | Replace the default unread badge. |
| `notificationComponent` | `React.FC` | Replace the default notification card. See [Custom notification card](/docs/react-customising-feed#custom-notification-card-component). |
| `headerRightComponent` | `React.FC` | Replace the "Mark all as read" area in the header. See [Custom header](/docs/react-customising-feed#custom-header-component). |

<Note>
  **Toast notifications** are not included in `Inbox` by default. See the [Toast Notifications](/docs/react-toast-notifications) guide to add them.
</Note>
