Slack is a chat channel — you're delivering messages into a Slack workspace, channel, or DM. The setup has more moving pieces than Email/SMS because you need to register a Slack App and get the user (or tenant) to authorize it.

Setup is four steps:

1. **Create a Slack App** with the right OAuth scopes.
2. **Enable the Slack vendor** in SuprSend and link your App.
3. **Have users (or tenants) authorize your App** so SuprSend gets a Slack token.
4. **Add a Slack delivery node** with a Slack template.

---

## 1. Create a Slack App

Follow the [Slack vendor guide](/docs/slack):
- [Step 2 — Create a Slack App](/docs/slack#step-2-create-a-slack-app)
- [Step 3 — Assign OAuth scopes](/docs/slack#step-3-assigning-oauth-scopes-to-app)

Pick the scopes that match how you'll deliver — DM to users, post in channels, or both.

---

## 2. Enable the Slack vendor in SuprSend

Add your Slack App credentials on the [Slack vendor page](https://app.suprsend.com/en/sandbox/vendors/slack/slack-slack?brand_id=default). For multi-tenant B2B, set [per-tenant Slack vendors](/docs/tenant-vendor) so each customer connects their own workspace.

---

## 3. Authorize and store the Slack identity

There are two ways users can be reached on Slack — via OAuth (recommended) or via webhook URL.

**OAuth (recommended):** add a "Connect Slack" button in your product. After the user authorizes, store the resulting Slack identity on their SuprSend profile:

```json
{
  "distinct_id": "user_123",
  "$slack": {
    "access_token": "xoxb-...",
    "email": "user@example.com"
  }
}
```

**Webhook:** for one-off integrations, the Slack identity can be a channel webhook URL.

Full reference: [Slack vendor docs](/docs/slack).

---

## 4. Slack template

Use the [Slack template editor](/docs/slack-template) — supports plain text, rich formatting, blocks, and interactive elements (buttons, dropdowns). Variables in Handlebars `{{var}}`. **Publish** before saving the workflow.

---

## Slack gotchas

- **Per-tenant in B2B:** in B2B SaaS, every customer org should connect their own Slack workspace. Use [per-tenant vendors](/docs/tenant-vendor) — don't share one Slack App across customers.
- **Bot vs user-token scopes:** if you want to DM users, request `chat:write` with a bot token. To post as the user themselves, request user-token scopes.
- **Rate limits:** Slack rate limits per workspace. For high-volume sends, batch and use the [Throttle](/docs/throttle) workflow setting.
- **Block Kit:** for rich interactive messages, build with [Block Kit](https://api.slack.com/block-kit) JSON inside the template.
