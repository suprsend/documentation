## Overview

SuprSend uses an account-level roles model, where a given account member's role determines what they'll be able to do in your account. You set an account member's role when you invite them to the SuprSend dashboard. You can update their role on the [Team page](https://app.suprsend.com/en/account-settings/team) under Account Settings.

Here's an overview of the two roles available to SuprSend account members:

**Admin.** Can change user role and invite new members. Admins have full access to the platform, plus the ability to manage team membership.

**Member.** Have full access of the platform. Can't change user role. Members have the same platform access as admins but cannot manage team membership or change user roles.

## Accessing the Team page

To view and manage team members, go to [**Account Settings → Team**](https://app.suprsend.com/en/account-settings/team) tab.

The Team page displays a table of all account members, showing each member's name, email address, role, current status (active or deactivated), and the date they joined the account.

You can search by name or email address, with results updating as you type. You can also filter the list by role (Admin or Member) and by status (Active or Deactivated). Filters can be combined to narrow down the results.

## Permissions

| Action | Admin | Member |
|--------|-------|--------|
| Full platform access | ✓ | ✓ |
| View team members | ✓ | ✓ |
| Search and filter team members | ✓ | ✓ |
| Change user roles | ✓ | ✗ |
| Invite new members | ✓ | ✗ |
