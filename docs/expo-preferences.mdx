---
title: "Preferences"
description: "Read and update user notification preferences in your Expo app using the headless preference hooks re-exported from the SuprSend React core SDK."
---

Headless hooks for reading and updating a user's notification preferences, re-exported from `@suprsend/react-core`. The API is identical — follow the [React preferences guide](/docs/preference-react-sdk) to wire it up in Expo.

See a full example: [PreferenceScreen.tsx](https://github.com/suprsend/expo-example/blob/main/screens/PreferenceScreen.tsx).
