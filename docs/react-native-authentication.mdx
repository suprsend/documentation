---
title: "Authentication"
description: "How to authenticate users in React Native applications using SuprSend."
---

React Native applications use HMAC authentication to securely generate subscriber IDs for user authentication.

## Quick Setup

Authenticate users by passing the `subscriberId` prop to the `SuprSendProvider` component:

```javascript
import { SuprSendProvider } from "@suprsend/react-headless";

function App() {
  return (
    <SuprSendProvider
      workspaceKey="<workspace_key>"
      subscriberId="<subscriber_id>"
      distinctId="<distinct_id>"
    >
      <YourApp />
    </SuprSendProvider>
  );
}
```

## Learn More

For detailed information on generating HMAC subscriber IDs and implementing authentication in your React Native application, see the [complete HMAC authentication guide](/docs/hmac-authentication).
