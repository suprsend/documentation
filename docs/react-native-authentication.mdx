title: "Authentication"

---

React Native applications use **HMAC-based authentication** to securely identify users. Your backend generates a subscriber ID (HMAC hash), which the SDK uses to establish a trusted session.

## Quick setup

Pass the `subscriberId` to the `SuprSendProvider` component alongside the user's `distinctId`:

```javascript
import { SuprSendProvider } from "@suprsend/react-headless";

function App() {
  return (
    <SuprSendProvider
      workspaceKey="YOUR_WORKSPACE_KEY"
      subscriberId="HMAC_SUBSCRIBER_ID"
      distinctId="USER_DISTINCT_ID"
    >
      <YourApp />
    </SuprSendProvider>
  );
}
```

| Prop | Description |
|------|-------------|
| `workspaceKey` | Your workspace key from [Settings → API Keys](https://app.suprsend.com/en/sandbox/developers/api-keys). |
| `distinctId` | A unique identifier for the current user (e.g., user ID). |
| `subscriberId` | An HMAC hash generated on your backend using your workspace secret. |

## How it works

1. When the user logs in, your **backend** generates an HMAC hash of the `distinctId` using the workspace secret.
2. Your app passes this hash as `subscriberId` to `SuprSendProvider`.
3. The SDK authenticates the user and opens a real-time connection for live notification delivery.

<Info>
  The `subscriberId` should be generated server-side. Never expose your workspace secret in the mobile app.
</Info>

## Learn more

For detailed instructions on generating HMAC subscriber IDs on your backend, see the [complete HMAC authentication guide](/docs/hmac-authentication). You can manage your API keys from the [SuprSend Dashboard](https://app.suprsend.com/en/sandbox/developers/api-keys).
