## Creating a Tenant

You can create tenants using the [SuprSend Dashboard](https://app.suprsend.com/tenants) or via SDKs.

### Via Dashboard

<Steps>
  <Step title="Navigate to Tenants">
    Go to **Tenants** from the side navigation or visit the [Tenants page](https://app.suprsend.com/tenants)
  </Step>
  <Step title="Create New Tenant">
    Click **New Tenant**

    ![](/images/docs/new-tenant.png)
  </Step>
  <Step title="Enter Basic Information">
    Enter required fields:
    - **Tenant ID** — Use your customer ID from your system (e.g., if customer ID is `acme-corp-123`, use the same here). Max 64 characters, alphanumeric with `_` and `-`. Tenant ID is permanent. Updating or renaming tenant_id is not supported.
    - **Tenant Name** — Company or organization name

    ![](/images/docs/create-tenant.png)
  </Step>
  <Step title="Configure Properties">
    Configure tenant properties on the details page and save.

    ![](/images/docs/tenant-details.png)
  </Step>
</Steps>

### Via SDKs

<CodeGroup>
```python Python
from suprsend import Suprsend

supr_client = Suprsend("workspace_key", "workspace_secret")

tenant_payload = {
    "tenant_name": "ABC Company",
    "logo": "https://company_logo_image.png",
    "primary_color": "#ff0000",
    "secondary_color": "#00ff00",
    "tertiary_color": "#0000ff",
    "social_links": {
        "website": "https://example.com",
        "facebook": "https://facebook.com/example"
    }
}

response = supr_client.tenants.upsert("tenant_01", tenant_payload)
print(response)
```

```javascript Node.js
const { Suprsend } = require("@suprsend/node-sdk");

const supr_client = new Suprsend("workspace_key", "workspace_secret");

const tenant_payload = {
    tenant_name: "ABC Company",
    logo: "https://company_logo_image.png",
    primary_color: "#ff0000",
    secondary_color: "#00ff00",
    tertiary_color: "#0000ff",
    social_links: {
        website: "https://example.com",
        facebook: "https://facebook.com/example"
    }
};

const response = supr_client.tenants.upsert("tenant_01", tenant_payload);
response.then((res) => console.log("response", res));
```

```java Java
import com.suprsend.Suprsend;
import com.suprsend.models.Tenant;

Suprsend suprClient = new Suprsend("workspace_key", "workspace_secret");

Tenant tenant = new Tenant()
    .setTenantName("ABC Company")
    .setLogo("https://company_logo_image.png")
    .setPrimaryColor("#ff0000")
    .setSecondaryColor("#00ff00")
    .setTertiaryColor("#0000ff");

JSONObject response = suprClient.tenants.upsert("tenant_01", tenant);
System.out.println(response);
```

```go Go
package main

import (
  "context"
  "log"
  suprsend "github.com/suprsend/suprsend-go"
)

func main() {
  suprClient, err := suprsend.NewClient("workspace_key", "workspace_secret")
  if err != nil {
    log.Fatalln(err)
  }

  tenantPayload := &suprsend.Tenant{
    TenantName:    suprsend.String("ABC Company"),
    Logo:          suprsend.String("https://company_logo_image.png"),
    PrimaryColor:  suprsend.String("#ff0000"),
    SecondaryColor: suprsend.String("#00ff00"),
    TertiaryColor: suprsend.String("#0000ff"),
  }

  res, err := suprClient.Tenants.Upsert(context.Background(), "tenant_01", tenantPayload)
  if err != nil {
    log.Fatalln(err)
  }
  log.Println(res)
}
```
</CodeGroup>

<Note>
  **Upsert behavior:** The `upsert` method creates a new tenant if it doesn't exist, or updates an existing tenant if it does. The Tenant ID cannot be changed after creation.
</Note>

## Tenant Fields

| Field | Type | Description |
|-------|------|-------------|
| **Tenant ID** | string (max 64 chars) | Unique identifier. Allowed: lowercase letters, numbers, hyphens, underscores (`[a-z0-9_-]`). Map to customer ID from your system. Cannot be changed after creation |
| **Tenant Name** | text | Company or organization name |
| **Logo** | image | Logo displayed in email header |
| **Primary Color** | hex code | Used in buttons, headers, footer borders. Must be HEX values (e.g., #ff0000). Falls back to default if not set |
| **Secondary Color** | hex code | Additional color for customization. Must be HEX values (e.g., #ff0000) |
| **Tertiary Color** | hex code | Additional color for customization. Must be HEX values (e.g., #ff0000) |
| **Social Links** | URL | Social media URLs. Displayed in email footer |
| **Embedded Preference Page** | URL | Creates `{{$embedded_preference_url}}` variable |
| **Hosted Preference Domain** | URL | Creates `{{$hosted_preference_url}}` variable |
| **Custom Properties** | JSON | Custom JSON metadata accessible via SDKs and APIs. Not directly available in templates. Ideal for storing metadata required for backend logic |

## Managing Existing Tenants

<Note>
  Manage tenants programmatically using `.get()`, `.list()`, `.upsert()`, and `.delete()`.
</Note>

### View a Tenant

**Dashboard:** Go to [Tenants](https://app.suprsend.com/tenants) from the side navigation, then click on any tenant to view and edit its details.

**SDK:**

<CodeGroup>
```python Python
tenant = supr_client.tenants.get("tenant_01")
print(tenant)
```

```javascript Node.js
const tenant = await supr_client.tenants.get("tenant_01");
console.log(tenant);
```

```java Java
JSONObject tenant = suprClient.tenants.get("tenant_01");
System.out.println(tenant);
```

```go Go
tenant, err := suprClient.Tenants.Get(context.Background(), "tenant_01")
if err != nil {
    log.Fatalln(err)
}
log.Println(tenant)
```
</CodeGroup>

### Update a Tenant

**Dashboard:** Navigate to [Tenants](https://app.suprsend.com/tenants), click on the tenant you want to update, modify any field except Tenant ID, then save changes.

**SDK:**

<CodeGroup>
```python Python
tenant_payload = {
    "tenant_name": "Updated Company Name",
    "primary_color": "#00ff00",
}

response = supr_client.tenants.upsert("tenant_01", tenant_payload)
print(response)
```

```javascript Node.js
const tenant_payload = {
    tenant_name: "Updated Company Name",
    primary_color: "#00ff00",
};

const response = supr_client.tenants.upsert("tenant_01", tenant_payload);
response.then((res) => console.log("response", res));
```



</CodeGroup>

<Note>

</Note>

### Delete a Tenant

<Warning>
  Deleting a tenant is irreversible and removes all associated properties. It does not delete historical notification logs.
</Warning>

**Dashboard:** Navigate to [Tenants](https://app.suprsend.com/tenants), click on the tenant you want to delete, then click **Delete** and confirm.

**SDK:**

<CodeGroup>
```python Python
response = supr_client.tenants.delete("tenant_01")
print(response)
```

```javascript Node.js
const response = await supr_client.tenants.delete("tenant_01");
console.log(response);
```

```java Java
JSONObject response = suprClient.tenants.delete("tenant_01");
System.out.println(response);
```

```go Go
err := suprClient.Tenants.Delete(context.Background(), "tenant_01")
if err != nil {
    log.Fatalln(err)
}
```
</CodeGroup>
