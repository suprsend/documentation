## Prerequisites

- A SuprSend account — [sign up here](https://auth.suprsend.com/sign-up) if you don't have one
- Your **Public API Key** from [Settings → API Keys](https://app.suprsend.com/en/sandbox/developers/api-keys)
- A **user token** (JWT) generated on your backend for authentication — see the [authentication guide](/docs/client-authentication)

## Install the SDK

Choose the integration method that fits your project.

<Tabs>
  <Tab title="Script tag">
    Best for vanilla JS, Django, Laravel, Ruby, or any project without a JavaScript build step.

    ```html
    <script>
      window.suprsendConfig = {
        distinctId: "YOUR_DISTINCT_ID",
        publicApiKey: "YOUR_PUBLIC_API_KEY",
        userToken: "SIGNED_USER_TOKEN",
      };

      let scriptElem = document.createElement("script");
      scriptElem.async = 1;
      scriptElem.src =
        "https://web-components.suprsend.com/v0.3.0/bundle.umd.js";
      scriptElem.onload = () => {
        console.log("SuprSend SDK loaded", window.suprsend);
      };
      document.body.appendChild(scriptElem);
    </script>
    ```
  </Tab>
  <Tab title="npm package">
    Best for Angular, Vue, Next.js, Nuxt, or any framework-based project.

    ```bash
    npm install @suprsend/web-components@latest
    ```

    Then initialize in your application:

    ```javascript
    import { initSuprSend } from "@suprsend/web-components";

    const suprsendConfig = {
      distinctId: "YOUR_DISTINCT_ID",
      publicApiKey: "YOUR_PUBLIC_API_KEY",
      userToken: "SIGNED_USER_TOKEN",
    };

    initSuprSend(suprsendConfig);
    ```
  </Tab>
</Tabs>

### Config options

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `publicApiKey` | `string` | Yes | Your SuprSend public API key |
| `distinctId` | `string` | Yes | Unique identifier for the user |
| `userToken` | `string` | Yes | Signed JWT token for authentication |
| `host` | `string` | No | Custom API host URL |
| `refreshUserToken` | `function` | No | Callback to refresh expired tokens |
| `userAuthenticationHandler` | `function` | No | Callback after user authentication completes |

## Add your first component

### Using script tag

Add the inbox container element anywhere in your HTML:

```html
<div id="suprsend-inbox"></div>
```

The SDK automatically renders the Inbox component inside this element once loaded.

### Using npm package

Place a container div in your template and the SDK handles rendering:

```html
<!-- In your component template -->
<div id="suprsend-inbox"></div>
```

```javascript
import { initSuprSend } from "@suprsend/web-components";

initSuprSend({
  distinctId: "YOUR_DISTINCT_ID",
  publicApiKey: "YOUR_PUBLIC_API_KEY",
  userToken: "SIGNED_USER_TOKEN",
});
```

## Removing the instance

Components are removed automatically on page navigation. To remove them manually:

<CodeGroup>
  ```javascript Script tag
  window.suprsend.clearSuprSend();       // clear instance and remove all components
  window.suprsend.clearSuprSendInbox();  // unmount only the inbox component
  ```

  ```javascript npm package
  import { clearSuprSend, clearSuprSendInbox } from "@suprsend/web-components";

  clearSuprSend();       // clear instance and remove all components
  clearSuprSendInbox();  // unmount only the inbox component
  ```
</CodeGroup>

## Verify the integration

1. Trigger a test workflow from the [SuprSend dashboard](https://app.suprsend.com) targeting the same `distinctId` you used above.
2. You should see the notification appear in real time in the Inbox popover.
3. Check the browser console — the SDK logs connection status and any errors.
