---
title: "Multi-lingual Templates"
description: "Deliver notifications in each recipient's preferred language from a single template."
---

SuprSend allows you to create notifications in multiple languages in the same template. Once the languages are added, SuprSend picks the preferred language from the user's profile and sends the message accordingly. You can set a user's preferred language using the [Python](/docs/python-create-user-profile#set-preferred-language) or [Node](/docs/node-create-user-profile#set-preferred-language) SDK.

English is the default fallback language. Users with no language preference set — or whose preferred language has no content in the template — receive the notification in English.

## Adding languages

<Steps>
  <Step title="Open the language settings">
    In any template, English (en) is enabled by default. To add other languages, click the **Language** option from the top-right overflow menu (**⋮**) in the template editor.

    <Frame>
      <img src="/images/docs/900b12b-lang_button.png" />
    </Frame>

    This opens the language selection modal. Search for the required language, add it, and save.

    <Frame>
      <img src="https://files.readme.io/f3b4017-ezgif.com-gif-maker_5.gif" />
    </Frame>
  </Step>

  <Step title="Add content for each language">
    Once languages are added, you'll see them listed in the editor. Languages are set at the template group level — they are enabled for all channels at once. However, you can choose which languages to commit when publishing.

    Add content for each language in the respective editor tab.
  </Step>

  <Step title="Commit the template">
    After making changes, click **Commit**.

    <Frame>
      <img src="/images/docs/5fa1c5c-lang_publish.png" />
    </Frame>

    Add a relevant version name and click **Next**.

    <Frame>
      <img src="/images/docs/d2818ad-version_name.png" />
    </Frame>

    Select the languages you want to publish. English is committed by default.

    <Frame>
      <img src="/images/docs/0307e31-final_publish.png" />
    </Frame>

    <Warning>
      If you see an error below a language (e.g., Spanish in the screenshot above), it means there are missing required fields for that language. You cannot commit a language with incomplete content. Go back and fill in the missing fields, or skip that language and commit the rest.
    </Warning>

    Published languages are now live and will be used in subsequent workflow runs.
  </Step>
</Steps>

## How language selection works

At send time, SuprSend checks the recipient's `preferred_language` property from their user profile. If content exists for that language in the template, it is used. Otherwise, the English (en) fallback is sent.

For variant-based language targeting, see [Template Variants](/docs/template-variants).
