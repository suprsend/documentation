---

SuprSend In App Feed enables you to add real-time notification feeds directly into your web and mobile applications. Whether you need a simple bell icon with a popover, a full-screen notification center, or a completely custom design, SuprSend provides the tools and components to build it quickly—with no backend infrastructure required.

## Key features

- **Real-time updates** - Automatic notification delivery via WebSocket connections
- **Multiple layouts** - Popover feeds, full-screen views, side sheets, or custom designs
- **Full customization** - Themes, styles, languages, and component behavior
- **User interactions** - Handle clicks, actions, read/unread states, and multi-tab organization
- **Headless support** - Build completely custom UIs using hooks and SDK methods
- **Cross-platform** - React, JavaScript, React Native, and Flutter support
