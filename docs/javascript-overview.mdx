---

The SuprSend JavaScript SDK uses framework-agnostic Web Components to bring real-time notifications to Angular, Vue, vanilla JavaScript, or any web framework. Pre-built drop-in components for quick integration, plus a headless API for fully custom designs.

## Install

<CodeGroup>
  ```html Script tag
  <script src="https://web-components.suprsend.com/v1.0.0/suprsend-web-components.js"></script>
  ```

  ```bash npm
  npm install @suprsend/web-components
  ```
</CodeGroup>

## Quick look

```html
<suprsend-provider
  public-api-key="YOUR_PUBLIC_API_KEY"
  distinct-id="USER_DISTINCT_ID"
  user-token="SIGNED_USER_TOKEN"
>
  <suprsend-inbox></suprsend-inbox>
</suprsend-provider>
```

## Get started

<Steps>
  <Step title="Authenticate">
    Generate a JWT token on your backend and pass it to the `suprsend-provider` component. This securely connects the user to their notification feed.

    [Set up authentication →](/docs/javascript-authentication)
  </Step>
  <Step title="Add a component">
    Use `<suprsend-inbox>` for a popover feed or `<suprsend-feed>` for a full-screen layout. Works with Angular, Vue, or any HTML page.
  </Step>
  <Step title="Customize">
    Theme the components to match your app's design, add multi-language support, or go fully headless for complete control.
  </Step>
</Steps>

## Framework guides

Works out of the box with any JavaScript framework:

- **Angular** — Use Web Components directly in your Angular templates
- **Vue** — Register as custom elements in your Vue app
- **Vanilla JS** — Add via script tag to any HTML page
- **Next.js / Nuxt** — Compatible with SSR frameworks using client-side rendering
