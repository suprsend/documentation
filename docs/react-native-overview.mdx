The SuprSend React Native SDK provides headless hooks to build a native notification inbox in your mobile app. Connect to SuprSend's real-time feed and render notifications with your own UI — fully customized to match your app's design.

## Install

<CodeGroup>
  ```shell npm
  npm install @suprsend/react-headless
  ```

  ```shell yarn
  yarn add @suprsend/react-headless
  ```
</CodeGroup>

## Quick look

```jsx
import { SuprSendProvider, useNotifications } from "@suprsend/react-headless";

function App() {
  return (
    <SuprSendProvider
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="USER_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <NotificationFeed />
    </SuprSendProvider>
  );
}

function NotificationFeed() {
  const { notifications, markRead } = useNotifications();

  return notifications.map((n) => (
    <Text key={n.id} onPress={() => markRead(n.id)}>
      {n.message.header}
    </Text>
  ));
}
```

## Get started

<Steps>
  <Step title="Authenticate">
    Generate a JWT token on your backend and pass it to `SuprSendProvider`. This securely connects the user to their notification feed.

    [Set up authentication →](/docs/react-native-authentication)
  </Step>
  <Step title="Add a component">
    Use the `useNotifications` hook to fetch notifications and render them with your own React Native components.

    [Integration guide →](/docs/inbox-react-native)
  </Step>
  <Step title="Customize">
    Handle action button clicks, manage read/unread state, add toast alerts, and style your feed to match your app's design.
  </Step>
</Steps>
