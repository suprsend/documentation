The SuprSend Flutter SDK provides hooks to build a native notification inbox in your Flutter app. Connect to SuprSend's real-time feed and render notifications with your own widgets — fully customized to match your app's design.

## Install

Add the dependency to your `pubspec.yaml`:

```yaml
dependencies:
  suprsend_flutter_inbox: ^0.0.1
```

Then run:

```bash
flutter pub get
```

## Quick look

```dart
import 'package:suprsend_flutter_inbox/suprsend_flutter_inbox.dart';

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return SuprSendProvider(
      publicApiKey: "YOUR_PUBLIC_API_KEY",
      distinctId: "USER_DISTINCT_ID",
      userToken: "SIGNED_USER_TOKEN",
      child: NotificationFeed(),
    );
  }
}
```

## Get started

<Steps>
  <Step title="Authenticate">
    Generate a JWT token on your backend and pass it to `SuprSendProvider`. This securely connects the user to their notification feed.

    [Set up authentication →](/docs/flutter-authentication)
  </Step>
  <Step title="Build your feed UI">
    Use the provided hooks to fetch notifications and render them with your own Flutter widgets.

    [Integration guide →](/docs/inbox-flutter)
  </Step>
  <Step title="Handle interactions">
    Mark notifications as read/unread, handle action button clicks, and manage feed state with the provided hook methods.
  </Step>
</Steps>
