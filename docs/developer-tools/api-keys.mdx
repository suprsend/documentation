SuprSend provides three authentication methods. Choose the right one based on how you're integrating with SuprSend.

## Get Your Authentication Credentials

<Steps>
  <Step title="Go to API Keys settings">
    Navigate to your workspace → Settings → API Keys
  </Step>

  <Step title="Choose your method">
    **Server-Side Authentication**:
    - **Workspace Key & Secret**: For server-side SDKs
    - **API Keys**: For REST API calls
    
    **Client-Side Authentication**:
    - **Public Keys**: For client-side SDKs
    - **Signing Keys**: For enhanced security (production)
  </Step>

  <Step title="Get your credentials">
    **Server-Side**:
    - **Workspace Key & Secret**: Pre-generated, click to copy
    - **API Key**: Click "Generate Key" → Enter name → Copy token
    
    **Client-Side**:
    - **Public Key**: Click "Generate new key" → Enter name → Copy key
    - **Signing Key**: Click "Generate new key" → Copy key (for production)
  </Step>
</Steps>
