---
title: "Test Mode"
description: "Safely test notification flows without delivering to real users."
---

Set up Test Mode to redirect all notification deliveries to specified test channels instead of real user channels.

## Set Up Test Mode

<Steps>
  <Step title="Enable Test Mode">
    Go to your workspace → Developers → Test Mode → Toggle "Enable Test Mode" to ON
  </Step>

  <Step title="Select channels to block">
    Under "Block notification delivery for:", select the channels you want to redirect (Email, SMS, WhatsApp)
  </Step>

  <Step title="Add test users">
    For each selected channel, add test users who will receive all notifications instead of real users
  </Step>

  <Step title="Set catch-all users">
    Toggle ON "Catch-all" for one test user in each channel to handle any notifications sent to users not in your test list
  </Step>
</Steps>

## Add Test Users

For each channel you selected, add test users who will receive all notifications:

<CodeGroup>
```text Email
test1@yourcompany.com
qa-team@yourcompany.com
dev-team@yourcompany.com
```

```text SMS
+1234567890
+1987654321
+1555123456
```

```text WhatsApp
+1234567890
+1987654321
+1555123456
```
</CodeGroup>

## Troubleshooting

<Accordion title="Notifications not reaching test users">
- Verify Test Mode is enabled
- Check that the correct channels are selected
- Ensure test users are properly added
</Accordion>

<Accordion title="Real users receiving test notifications">
- Verify Test Mode is enabled in the correct workspace
- Ensure test channels are properly configured
- Ensure catch-all users are configured for each channel
</Accordion>
