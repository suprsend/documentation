Set up the SuprSend Management API to programmatically manage and deploy your notification assets across different environments.

## Set Up Management API

<Steps>
  <Step title="Get a Service Token">
    Go to your Account Settings → Service Tokens tab and generate a service token.
  </Step>

  <Step title="Test authentication">
    Verify your service token works with a test request:

    ```bash
    curl -H "Authorization: ServiceToken YOUR_SERVICE_TOKEN" \
         -H "Content-Type: application/json" \
         https://api.suprsend.com/v1/workflows
    ```
  </Step>

  <Step title="Start managing resources">
    Use the Management API to manage assets across environments.
  </Step>
</Steps>

## Management API reference

You can find a complete reference for all of the Management API endpoints and request/response schemas in our [Management API Reference](/docs/management-api-overview).
