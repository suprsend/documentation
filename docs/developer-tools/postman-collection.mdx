Set up our Postman collection to test and explore SuprSend APIs with pre-configured requests and examples.

## Set Up Postman Collection

<Steps>
  <Step title="Fork the collection">
    Go to [SuprSend Postman Workspace](https://www.postman.com/suprsend/workspace/suprsend/collection/27786422-d77a13c1-8f59-406d-9669-078a10d52521) and fork the collection to your workspace.
  </Step>

  <Step title="Create environment variables">
    In Postman, create a new environment and add these variables:

    | Variable | Description | Example Value |
    |----------|-------------|---------------|
    | `base_url` | SuprSend API base URL | `https://api.suprsend.com` |
    | `api_key` | Your API key | `your_api_key_here` |
    | `workspace_key` | Your workspace key | `your_workspace_key` |
    | `workspace_secret` | Your workspace secret | `your_workspace_secret` |
  </Step>

  <Step title="Get your credentials">
    Find your API credentials in SuprSend dashboard → Settings → API Keys and update the environment variables.
  </Step>

  <Step title="Start testing">
    Select the environment and start testing SuprSend APIs with pre-configured requests.
  </Step>
</Steps>
