If the drop-in [`suprsend-inbox`](/docs/web-components-popover-feed) and [`suprsend-feed`](/docs/web-components-fullscreen-feed) components don't fit your design, you can build your own UI from scratch using the headless API. The SDK gives you direct access to the feed data and actions — you control the rendering.

<Info>
  The headless API works with any framework — Angular, Vue.js, Vanilla JS, or React. For React-specific hooks, see the [React Headless Inbox](/docs/react-sdk-headless-feed) guide instead.
</Info>

For full type definitions, see the [source types](https://github.com/suprsend/suprsend-web-sdk/blob/main/src/interface.ts).

## Initialize the feed client

Create a feed client instance from your SuprSend client:

```typescript
const feedClient = suprSendClient.feed.initialize(options?: IFeedOptions);

interface IFeedOptions {
  tenantId?: string;
  pageSize?: number;
  stores?: IStore[] | null;
  host?: { socketHost?: string; apiHost?: string };
}
```

If you pass `tenantId`, make sure to include the scope key when creating the [userToken](/docs/client-authentication#2-creating-signed-user-jwt-token), otherwise you'll get a 403 error.

## Feed data

Access the current notification store at any time:

```typescript
const feedData = feedClient.data;
```

## Fetching notifications

```typescript
feedClient.fetch();         // fetch the first page
feedClient.fetchNextPage(); // fetch the next page (infinite scroll)
```

## Real-time updates

Open a WebSocket connection for live notification delivery:

```typescript
feedClient.initializeSocketConnection();
```

## Emitter events

### Store updates

Fires whenever the notification store changes (new notification, read state change, etc.). Use this to re-render your UI.

```typescript
feedClient.emitter.on("feed.store_update", (updatedStoreData) => {
  // update your local state to refresh UI
});
```

### New notification

Fires when a new notification arrives. Useful for showing toast notifications.

```typescript
feedClient.emitter.on("feed.new_notification", (notification) => {
  // show a toast with the new notification
});
```

## Available methods

| Method | Description |
|--------|-------------|
| `feedClient.fetch()` | Fetch the first page of notifications. |
| `feedClient.fetchNextPage()` | Fetch the next page. |
| `feedClient.markAsSeen(id)` | Mark a notification as seen. |
| `feedClient.markAsRead(id)` | Mark a notification as read. |
| `feedClient.markAsUnread(id)` | Mark a notification as unread. |
| `feedClient.markAsArchived(id)` | Archive a notification. |
| `feedClient.markAsInteracted(id)` | Mark as interacted. |
| `feedClient.markAllAsRead()` | Mark all notifications as read. |
| `feedClient.markBulkAsSeen(ids)` | Bulk mark as seen. |
| `feedClient.changeActiveStore(storeId)` | Switch the active store/tab. |
| `feedClient.resetBadgeCount()` | Reset the bell badge count (call on inbox open). |
| `feedClient.remove()` | Remove the feed client and close the socket. |

## Complete example

This example uses vanilla JavaScript patterns. Adapt it to your framework of choice.

```javascript
import { SuprSend } from "@suprsend/web-sdk";

const suprSendClient = new SuprSend("YOUR_PUBLIC_API_KEY");

async function initializeFeed() {
  await suprSendClient.identify("YOUR_DISTINCT_ID");

  const feedClient = suprSendClient.feed.initialize();

  feedClient.emitter.on("feed.store_update", (storeData) => {
    renderNotifications(storeData);
  });

  feedClient.emitter.on("feed.new_notification", (notification) => {
    showToast(notification.message.header);
  });

  feedClient.initializeSocketConnection();
  feedClient.fetch();
}

function renderNotifications(storeData) {
  const container = document.getElementById("notifications");
  if (!storeData?.notifications?.length) {
    container.innerHTML = "<p>No notifications</p>";
    return;
  }

  container.innerHTML = storeData.notifications
    .map((n) => `<div class="notification">${n.message.header}</div>`)
    .join("");
}

function showToast(message) {
  // Use your preferred toast library
  console.log("New notification:", message);
}

initializeFeed();
```

## Cleanup

Remove the feed client when the user logs out or the component unmounts:

```typescript
feedClient.remove();
suprSendClient.reset();
```
