This guide walks through creating a tenant, using tenant data in templates, and triggering a notification with tenant context.

## Step 1: Create a Tenant

<Tabs>
  <Tab title="MCP">
    With the [SuprSend MCP server](/reference/mcp-overview) configured in your AI assistant (Claude, Cursor, etc.), you can create a tenant using natural language:

    > *"Create a tenant with ID `acme-corp`, name `Acme Corp`, logo `https://acme.com/logo.png`, and primary color `#0055ff`"*

    The MCP server calls the `tenants.upsert` tool under the hood. You can also invoke it directly:

    ```json
    {
      "tool": "tenants.upsert",
      "tenant_id": "acme-corp",
      "tenant_properties": {
        "tenant_name": "Acme Corp",
        "logo": "https://acme.com/logo.png",
        "primary_color": "#0055ff"
      }
    }
    ```
  </Tab>

  <Tab title="Backend SDK">
    <CodeGroup>
      ```python Python
      from suprsend import Suprsend

      supr_client = Suprsend("workspace_key", "workspace_secret")

      response = supr_client.tenants.upsert("acme-corp", {
          "tenant_name": "Acme Corp",
          "logo": "https://acme.com/logo.png",
          "primary_color": "#0055ff",
          "social_links": {
              "website": "https://acme.com"
          }
      })
      print(response)
      ```

      ```javascript Node.js
      const { Suprsend } = require("@suprsend/node-sdk");

      const supr_client = new Suprsend("workspace_key", "workspace_secret");

      const response = supr_client.tenants.upsert("acme-corp", {
          tenant_name: "Acme Corp",
          logo: "https://acme.com/logo.png",
          primary_color: "#0055ff",
          social_links: {
              website: "https://acme.com"
          }
      });
      response.then((res) => console.log(res));
      ```

      ```java Java
      import com.suprsend.Suprsend;
      import com.suprsend.models.Tenant;

      Suprsend suprClient = new Suprsend("workspace_key", "workspace_secret");

      Tenant tenant = new Tenant()
          .setTenantName("Acme Corp")
          .setLogo("https://acme.com/logo.png")
          .setPrimaryColor("#0055ff");

      JSONObject response = suprClient.tenants.upsert("acme-corp", tenant);
      System.out.println(response);
      ```

      ```go Go
      suprClient, _ := suprsend.NewClient("workspace_key", "workspace_secret")

      tenantPayload := &suprsend.Tenant{
          TenantName:   suprsend.String("Acme Corp"),
          Logo:         suprsend.String("https://acme.com/logo.png"),
          PrimaryColor: suprsend.String("#0055ff"),
      }

      res, err := suprClient.Tenants.Upsert(context.Background(), "acme-corp", tenantPayload)
      if err != nil {
          log.Fatalln(err)
      }
      log.Println(res)
      ```
    </CodeGroup>

    <Note>
      `upsert` creates the tenant if it doesn't exist, or updates it if it does. The Tenant ID cannot be changed after creation.
    </Note>

## Step 2: Use Tenant Data in Templates

Open any template in the [template editor](https://app.suprsend.com/templates). Tenant variables follow the format `$tenant.<property>` and are replaced at send time based on the `tenant_id` you pass.

### Inserting tenant variables

Type `{` in the editor to see tenant variables in auto-suggestions. Here's a practical email template:

```handlebars Email template
<h2>Hello from {{$tenant.tenant_name}}!</h2>
<p>Your account is now active. Visit us at {{$tenant.social_links.website}}.</p>
<p style="color: {{$tenant.primary_color}};">We're glad to have you.</p>
```

When triggered with `tenant_id="acme-corp"`, the variables resolve to Acme Corp's actual values.

### Showing or hiding sections per tenant

Use custom properties to conditionally show content for specific tenants. Set a property (e.g., `show_trial_banner: true`) on the tenant, then reference it in the template:

```handlebars Email template
{% if $tenant.properties.show_trial_banner %}
  <div style="background: #fff3cd; padding: 12px;">
    🎉 You're on a free trial — <a href="{{$tenant.properties.upgrade_url}}">upgrade now</a>
  </div>
{% endif %}

<p>Welcome to {{$tenant.tenant_name}}!</p>
```

The banner only appears for tenants where `show_trial_banner` is `true`.

### Customizing header, footer, and buttons with tenant block

For email templates, use the built-in **Tenant block** to automatically apply a tenant's logo, primary color, and social links to your header, footer, or button—without hardcoding anything.

<Steps>
  <Step title="Add a tenant block">
    In the template editor, find **Tenant** in the right-side content panel and drag it into the email.
  </Step>
  <Step title="Choose block type">
    Select **Header**, **Footer**, or **Button** from the right panel. The block auto-applies the tenant's branding at send time.

    <Frame caption="Switch block type (header, footer, buttons)">
      ![](/images/docs/9bb5a1b-image.png)
    </Frame>
  </Step>
</Steps>

<Note>
  Tenant blocks are email-only. For SMS, Push, and other channels, use `$tenant.*` variables directly in the template body.
</Note>

## Step 3: Trigger a Workflow with tenant_id

Pass `tenant_id` when triggering a workflow. SuprSend applies the matching tenant's branding and preferences automatically.

<CodeGroup>
  ```python Python
  from suprsend import Suprsend, WorkflowTriggerRequest

  supr_client = Suprsend("workspace_key", "workspace_secret")

  w1 = WorkflowTriggerRequest(
      body={
          "workflow": "welcome_email",
          "recipients": [{"distinct_id": "user_123", "$email": ["user@example.com"]}],
      },
      tenant_id="acme-corp"
  )

  response = supr_client.workflows.trigger(w1)
  print(response)
  ```

  ```javascript Node.js
  const { Suprsend, WorkflowTriggerRequest } = require("@suprsend/node-sdk");

  const supr_client = new Suprsend("workspace_key", "workspace_secret");

  const w1 = new WorkflowTriggerRequest(
      {
          workflow: "welcome_email",
          recipients: [{ distinct_id: "user_123", $email: ["user@example.com"] }],
      },
      { tenant_id: "acme-corp" }
  );

  const response = supr_client.workflows.trigger(w1);
  response.then((res) => console.log(res));
  ```

  ```go Go
  w1 := &suprsend.WorkflowTriggerRequest{
      Body: map[string]interface{}{
          "workflow": "welcome_email",
          "recipients": []map[string]interface{}{
              {"distinct_id": "user_123", "$email": []string{"user@example.com"}},
          },
      },
      TenantId: "acme-corp",
  }

  resp, err := suprClient.Workflows.Trigger(w1)
  if err != nil {
      log.Fatalln(err)
  }
  log.Println(resp)
  ```
</CodeGroup>

SuprSend resolves all `$tenant.*` variables using the properties of `acme-corp` before sending.
