### Support Policy

- **Latest Version**: Full support with new features, bug fixes, and security updates
- **Previous Major Version**: Bug fixes and security updates for 6 months
- **End of Life**: Security updates only for 12 months after deprecation

## Configuration Examples

### Version Pinning

Pin to specific versions in production for stability:

**package.json**
```json
{
  "dependencies": {
    "@suprsend/node-sdk": "1.13.0"
  }
}
```

**requirements.txt**
```txt
suprsend-py-sdk==0.15.0
```

**pom.xml**
```xml
<dependency>
  <groupId>com.suprsend</groupId>
  <artifactId>suprsend-java-sdk</artifactId>
  <version>0.5.0</version>
</dependency>
```
