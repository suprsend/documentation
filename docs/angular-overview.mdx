SuprSend integrates with Angular through the [`@suprsend/web-components`](https://www.npmjs.com/package/@suprsend/web-components) package — framework-agnostic Web Components that work natively in Angular templates. No Angular-specific wrapper needed.

<Info>
  Angular uses the same JavaScript Web Components SDK under the hood. All component docs, customization options, and headless APIs in the **JavaScript** tab apply directly to Angular.
</Info>

## Install

```bash
npm install @suprsend/web-components
```

## Quick look

```typescript
import { Component, OnInit, OnDestroy } from "@angular/core";
import { initSuprSend, clearSuprSend } from "@suprsend/web-components";

@Component({
  selector: "app-root",
  template: `<div id="suprsend-inbox"></div>`,
})
export class AppComponent implements OnInit, OnDestroy {
  ngOnInit() {
    initSuprSend({
      publicApiKey: "YOUR_PUBLIC_API_KEY",
      distinctId: "USER_DISTINCT_ID",
      userToken: "SIGNED_USER_TOKEN",
    });
  }

  ngOnDestroy() {
    clearSuprSend();
  }
}
```

## Get started

<Steps>
  <Step title="Authenticate">
    Generate a JWT token on your backend and pass it to `initSuprSend`. This securely connects the user to their notification feed.

    [Set up authentication →](/docs/javascript-authentication)
  </Step>
  <Step title="Add a component">
    Use `<suprsend-inbox>` for a popover feed or `<suprsend-feed>` for a full-screen layout. Web Components work directly in Angular templates.
  </Step>
  <Step title="Customize">
    Theme the components to match your app's design, add multi-language support, or go fully headless for complete control.
  </Step>
</Steps>
