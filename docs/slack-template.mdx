## Overview

The Slack editor supports two authoring modes for the same notification: a simple **Text** editor for straightforward messages, and a **JSONNET** editor for rich, structured messages built with Slack's Block Kit. You can use either mode — or switch between them — depending on how much control you need over the message layout.

Both modes share the same Variables panel and live preview.

---

## Getting Started

To add Slack to a template, open the template in edit mode, click **+** in the channel tab row, select **Slack**, and click **Add Channels**.

To send Slack notifications, you need a Slack vendor configured in your workspace. See [Slack Vendor Integration](/docs/slack-vendor-integration).

---

## Editor Modes

Switch between modes using the **JSONNET** and **Text** tabs at the top of the editor.

### Text Mode

A plain text editor for writing simple Slack messages. Use this when you don't need rich formatting, blocks, or interactive components.

Supports **Handlebars** syntax for dynamic variables:
- Use `{{variable}}` for standard variables
- Use `{{{variable}}}` for variables containing special characters

The hint below the tab reads: *"Add variable in handlebars format as `{{...}}`. Enclose variable containing special characters in `{{{...}}}`"*

The preview panel on the right renders the message as it appears in Slack — showing the app name, timestamp, and message body in a real Slack message card.

### JSONNET Mode

A code editor for writing JSONNET that evaluates to a [Slack Block Kit](https://api.slack.com/block-kit) payload. Use this for rich messages with sections, images, buttons, dividers, context blocks, and interactive components.

Supports **JSONNET** syntax for dynamic variables:
- Use `data.key` for top-level payload keys
- Use `data["$batched_events"].key` for batched event data

The hint below the tab reads: *"Add variable in JSONNET as `data.key` or `data["$batched_events"].key`"*

**Preview note:** JSONNET preview is not available directly in the editor. The preview panel shows: *"Preview for JSONNET template is not available here. View it on Slack Block Kit Builder."* Click **View on Slack Builder** to open the Slack Block Kit Builder in a new tab where you can paste and render your JSONNET output.

<Info>
  If you want to design a rich Slack message visually, build it in the [Slack Block Kit Builder](https://app.slack.com/block-kit-builder) first, then adapt the resulting JSON payload into JSONNET syntax and paste it into the JSONNET editor.
</Info>

## Variables

### In Text mode (Handlebars)

| Source | Syntax | Description |
| --- | --- | --- |
| Trigger payload | `{{order_id}}` | Top-level key from workflow payload |
| Nested key | `{{order.status}}` | Nested object property |
| URL / special characters | `{{{tracking_url}}}` | Triple braces prevent HTML-escaping |
| Recipient profile | `{{$recipient.first_name}}` | From the user's SuprSend profile |
| Tenant property | `{{$brand.brand_name}}` | From the linked tenant |
| Batched event count | `{{$batched_events_count}}` | Number of batched events |

### In JSONNET mode

| Source | Syntax | Description |
| --- | --- | --- |
| Trigger payload | `data.order_id` | Top-level key from workflow payload |
| Nested key | `data.order.status` | Nested object property |
| Recipient profile | `data['$recipient'].first_name` | From the user's SuprSend profile |
| Tenant property | `data['$brand'].brand_name` | From the linked tenant |
| Batched events | `data['$batched_events'][0].key` | Individual batched event property |

For advanced Handlebars logic, see [Handlebars Helpers](/docs/handlebars-helpers).

## Live Preview

The preview panel on the right shows a simulated Slack message card — your app name, timestamp, and message body — rendered in real time as you type in Text mode.

In JSONNET mode, the preview panel prompts you to open the Slack Block Kit Builder for visual rendering. Click **View on Slack Builder** to open it.

To preview with a specific user's data, search for a user in the **Recipient** section of the Variables panel.
