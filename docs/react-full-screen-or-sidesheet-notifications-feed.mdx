If you need notifications in a dedicated page, side sheet, or any layout other than the bell-icon popover, use the `NotificationFeed` component wrapped inside `SuprSendFeedProvider`.

<Frame caption="Full-screen notification feed">
  ![Full-screen notification feed](https://files.readme.io/bb3ea43-image.png)
</Frame>

Try it live in the [Interactive Playground](https://inbox-playground.suprsend.com/).

## Prerequisites

Make sure you have [installed the SDK and set up `SuprSendProvider`](/docs/react-installation) before adding the feed components.

## Integration

Both `SuprSendFeedProvider` and `NotificationFeed` must be rendered inside `SuprSendProvider`.

```jsx
import {
  SuprSendProvider,
  SuprSendFeedProvider,
  NotificationFeed,
} from "@suprsend/react";

function NotificationsPage() {
  return (
    <SuprSendProvider
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="YOUR_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <SuprSendFeedProvider>
        <NotificationFeed />
      </SuprSendFeedProvider>
    </SuprSendProvider>
  );
}
```

<Warning>
  `NotificationFeed` uses infinite scroll. You must set a height on its container for scrolling to work properly.

  ```jsx
  <NotificationFeed
    theme={{ notificationsContainer: { container: { height: "100vh" } } }}
  />
  ```
</Warning>

## Configuration

### SuprSendFeedProvider props

`SuprSendFeedProvider` manages the feed connection and data fetching.

```typescript
interface SuprSendFeedProviderProps {
  tenantId?: string;
  pageSize?: number;
  stores?: IStore[] | null;
  host?: { socketHost?: string; apiHost?: string };
}
```

| Prop | Type | Description |
|------|------|-------------|
| `tenantId` | `string` | Filter notifications by tenant. Defaults to `"default"`. |
| `pageSize` | `number` | Notifications per page. Default `20`, max `100`. |
| `stores` | `IStore[]` | Define multiple tabs. See [Adding tabs](/docs/react-customising-feed#adding-tabs). |
| `host` | `object` | Override API and WebSocket endpoints. |

### NotificationFeed props

`NotificationFeed` renders the notification list and handles user interactions.

```typescript
interface NotificationFeedProps {
  pagination?: boolean;
  showUnreadCountOnTabs?: boolean;
  hideAvatar?: boolean;
  themeType?: ThemeType;
  theme?: INotificationFeedTheme;
  notificationClickHandler?: (notification: IRemoteNotification) => void;
  primaryActionClickHandler?: (notification: IRemoteNotification) => void;
  secondaryActionClickHandler?: (notification: IRemoteNotification) => void;
  loaderComponent?: React.FC;
  noNotificationsComponent?: React.FC;
  tabBadgeComponent?: React.FC<{ count: number }>;
  notificationComponent?: React.FC<CustomNotificationCard>;
  headerRightComponent?: React.FC<{
    markAllRead: () => void;
    closeInboxPopover: () => void;
  }>;
}
```

| Prop | Type | Description |
|------|------|-------------|
| `pagination` | `boolean` | Enable infinite scroll. Default `true`. |
| `showUnreadCountOnTabs` | `boolean` | Show unread count on tabs. |
| `hideAvatar` | `boolean` | Hide notification avatars. |
| `themeType` | `"dark" \| "light"` | Toggle dark or light mode. |
| `theme` | `INotificationFeedTheme` | CSS style overrides. See [Customising CSS styles](/docs/react-customising-feed#customising-css-styles) for full type definitions. |
| `notificationClickHandler` | `function` | Callback when a notification is clicked. |
| `primaryActionClickHandler` | `function` | Callback for primary action button. |
| `secondaryActionClickHandler` | `function` | Callback for secondary action button. |
| `notificationComponent` | `React.FC` | Replace the default notification card. |
| `headerRightComponent` | `React.FC` | Replace the header right area. |
