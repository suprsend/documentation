---

Flutter applications use HMAC authentication to securely generate subscriber IDs for user authentication.

## Quick Setup

Authenticate users by passing the `subscriberId` parameter to the `SuprSendProvider`:

```dart
import 'package:suprsend_flutter_inbox/main.dart';

SuprSendProvider(
  workspaceKey: <your workspace key>,
  workspaceSecret: <your workspace secret>,
  distinctId: distinct_id,
  subscriberId: subscriber_id,
  child: YourAppComponent()
)
```

## Learn More

For detailed information on generating HMAC subscriber IDs and implementing authentication in your Flutter application, see the [complete HMAC authentication guide](/docs/hmac-authentication).
