## Overview

Use tenant properties in templates to dynamically render tenant-specific content. One template works for all tenants—SuprSend replaces variables with tenant-specific values at runtime.

## Email Tenant Components

Ready-to-use components for email templates: headers, footers, buttons, etc. Components automatically use the tenant's logo, social links, and primary color. [Create or edit templates in the dashboard →](https://app.suprsend.com/templates)

### How to Use

<Steps>
  <Step title="Find and add tenant component">
    In the [template editor](https://app.suprsend.com/templates), find tenant components in the right side content menu and add it to your template.

    ![](/images/tenant.png)
  </Step>
  <Step title="Switch block type">
    Switch block type (header, footer, buttons) from the right panel.

    ![](/images/docs/9bb5a1b-image.png)
  </Step>
  <Step title="Customize">
    Customize using standard options like padding, background color, etc.
  </Step>
</Steps>

## Tenant Variables

Tenant variables let you insert tenant-specific properties (like name, logo, colors) into your templates. Use the format `$tenant.<property>` in any channel template.

### How to Use

1. In the [template editor](https://app.suprsend.com/templates), type `{`
2. Tenant variables appear in auto-suggestions
3. Select the variable you need (e.g., `$tenant.tenant_name`)

![](/images/docs/9d494a1-small-Screenshot_2023-05-09_at_10.17.27_PM.png)

## Common Mistakes

<AccordionGroup>
  <Accordion title="No tenant_id passed at trigger time">
    Template renders default tenant values instead of the intended tenant's properties. Always pass `tenant_id` when triggering workflows or events.
  </Accordion>

  <Accordion title="Wrong key name">
    Using incorrect property names will not resolve variables correctly.

    `$tenant.social.website` ❌

    `$tenant.social_links.website` ✔
  </Accordion>

  <Accordion title="Missing leading `$`">
    Tenant variables must start with `$` to be recognized by the template engine.

    `tenant.tenant_name` ❌

    `$tenant.tenant_name` ✔
  </Accordion>

  <Accordion title="Using components in non-email channels">
    Tenant components (header, footer, buttons) only work in email templates. Use tenant variables for SMS, Push, WhatsApp, and other channels.
  </Accordion>
</AccordionGroup>
