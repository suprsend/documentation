## Overview

The iOS Push editor lets you design push notifications delivered to Apple devices via APNs (Apple Push Notification service). The editor is a structured form with a live iPhone lock screen preview that updates as you type.

---

## Getting Started

To add iOS Push to a template, open the template in edit mode, click **+** in the channel tab row, select **iOS Push**, and click **Add Channels**.

To send iOS push notifications, you need an APNs vendor configured in your workspace. See [iOS Push Vendor Integration](/docs/ios-push-vendor-integration).

Your app must also integrate the SuprSend iOS SDK to receive and register device tokens. See [iOS SDK](/docs/ios-sdk).

---

## Fields

### Title *(required)*

The headline of the notification displayed in bold on the lock screen and in the notification centre. Keep it short — iOS truncates titles beyond approximately 50 characters on most devices.

Supports Handlebars variables and emoji.

### Body *(required)*

The main message body displayed below the title. This is where you provide context and the call to action.

Supports Handlebars variables and emoji.

### Image URL

An optional image displayed inside the notification as a rich media attachment. Appears as a thumbnail on the lock screen and expands when the user long-presses or swipes down the notification.

Provide a direct image URL. Supports Handlebars — e.g. `{{product.image_url}}`.

### Action URL

The deep link or URL that opens when the user taps the notification. Use a deep link scheme (e.g. `myapp://orders/{{order_id}}`) to navigate directly to the relevant screen in your app, or a standard HTTPS URL to open in the browser.

---

## Live Preview

The right panel shows a live iPhone lock screen preview — the notification card appears exactly as it would on a real device, with the title and body rendered in real time. Variables are substituted with values from the Variables panel.

To preview with a specific user's data, search for a user in the **Recipient** section of the Variables panel.

---

## Variables

All fields support Handlebars syntax. Define variables in the **Variables `{}`** panel before using them.

| Source | Example | Description |
| --- | --- | --- |
| Trigger payload | `{{order_id}}` | Data sent when the workflow triggers |
| Recipient profile | `{{$recipient.first_name}}` | Properties from the user's SuprSend profile |
| Tenant | `{{$brand.brand_name}}` | Tenant branding properties |

For conditionals and helpers, see [Handlebars Helpers](/docs/handlebars-helpers).

<Warning>
  Every variable in the template must have a corresponding value in the trigger payload or Variables panel. Missing values cause the notification to fail rendering and not be delivered.
</Warning>
