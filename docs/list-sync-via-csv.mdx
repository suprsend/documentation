---
title: "CSV upload from the dashboard"
description: "Create a list and upload a fixed set of users from a CSV in the SuprSend dashboard — best for one-off campaigns run without engineering involvement."
---

Best for one-off campaigns run by marketing or product teams without engineering involvement. The list is a snapshot at upload time — you re-upload to update it.

<Warning>
  CSV upload only syncs users that already exist in SuprSend. It does not create new user profiles. See [Creating user profiles](/docs/users#creating-user-profile-on-suprsend) to identify users first.
</Warning>

<Steps>
  <Step title="Create the list">
    Go to **Lists → + New List** and fill in:

    | Field | Rules |
    |---|---|
    | `list_id` | Required. Unique identifier within the workspace. Use lowercase letters, digits, and underscores. |
    | Name | Optional. Display name — defaults to `list_id` if omitted. |
    | Description | Optional. Free-form. |

    You can edit the name and description later from the kebab menu (**Modify List**).

    <Frame>
      <img src="/images/list-create-modal.png" alt="New List modal with list_id, name, and description fields" />
    </Frame>
  </Step>

  <Step title="Upload users">
    Open the kebab menu on the list and select **Update Users**. Pick how to apply the CSV:

    - **Add** — append new users to the existing membership. Use this to keep adding to a rolling list (e.g. today's signups).
    - **Replace** — swap the current membership out for exactly the users in the CSV. Use this when the CSV is your new source of truth.

    <Frame>
      <img src="/images/upload-list-users-via-csv-modal.png" alt="Update Users dialog with Add / Replace options and file picker" />
    </Frame>

    Upload a CSV where the user column is labeled **`distinct_id`**, then click **Update Users**. Track progress under **Import logs**.
  </Step>
</Steps>
