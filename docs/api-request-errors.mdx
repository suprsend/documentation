## Overview

Errors that occur **before** a workflow runs are recorded in **Request Logs**. Use the [idempotency key](/docs/logging) from the failed request to trace the call. A **`200`** response means the request was **accepted** only—not that a workflow ran. For failures after acceptance, see [Workflow Execution Errors](/docs/error-guides) or Message Logs.

## Errors

<span id="error-1"></span>

### workflow not found

**Cause:** Workflow does not exist or is not active.

**Fix:** Fix the slug or create the workflow. See [Workflows](https://app.suprsend.com/en/production/workflows), [Create workflow](/docs/workflows#create-workflow).

<span id="error-2"></span>

### no valid recipients found

**Cause:** No recipient could be resolved.

**Fix:** Create the user first or include recipient and channel data. See [Create user](/docs/users#creating-user-profile-on-suprsend), [Trigger workflow](/docs/trigger-workflow).

<span id="error-3"></span>

### N error(s) occurred:

```
N error(s) occurred:
	* [workflow: ...] no valid recipients found
```

**Cause:** No recipient could be resolved.

**Fix:** Create the user first or include recipient and channel data. See [Create user](/docs/users#creating-user-profile-on-suprsend), [Trigger workflow](/docs/trigger-workflow).

<span id="error-4"></span>

### user [distinct_id: '...'] not found

**Cause:** User does not exist.

**Fix:** Create the user via API/SDK or pass user channel info in the payload. See [Create user](/docs/users#creating-user-profile-on-suprsend).

<span id="error-5"></span>

### channel details missing for transient user

**Cause:** Transient user requires channel identities.

**Fix:** Set channel identities (e.g. $email) in the user object. See [Anonymous users](/docs/python-trigger-workflow-from-api#sending-notification-to-anonymous-user).

<span id="error-6"></span>

### one of [distinct_id, object_type/id] must be present

**Cause:** Recipient is missing required identifier.

**Fix:** Add either distinct_id or both object_type and id. See [Trigger workflow](/docs/trigger-workflow).

**Fix:** Create the tenant or use an existing tenant ID. See [Tenants](https://app.suprsend.com/en/production/tenants/), [Create tenant](/docs/tenants#creating--updating-tenant-on-suprsend-platform).
