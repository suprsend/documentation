The SuprSend Android SDK lets you build a native notification inbox in your Android app. Use SuprSend's REST APIs to fetch and manage notifications — all rendered with your own Jetpack Compose or XML views.

<Info>
  SuprSend does not provide a pre-built inbox UI component for Android. You'll use the [Notification Feed REST API](/reference/fetch-feed) to fetch notifications and build native Jetpack Compose or XML views.
</Info>

## Install

```groovy
// Add mavenCentral() to your root build.gradle
allprojects {
    repositories {
        mavenCentral()
    }
}

// Add dependency to app-level build.gradle
dependencies {
    implementation("com.suprsend:native:1.0.1")
}
```

## Quick look

```kotlin
import app.suprsend.SSApi

// Initialize in your Application class (inside onCreate, above super.onCreate())
SSApi.init(this, "WORKSPACE_KEY", "WORKSPACE_SECRET")

// Access the instance
val ssApi = SSApi.getInstance()
```

## Get started

<Steps>
  <Step title="Authenticate">
    Initialize the SuprSend SDK and create the user. The SDK handles token management and secure communication.

    [SDK Integration →](/docs/integrate-android-sdk)
  </Step>
  <Step title="Add a component">
    Use SuprSend's [Notification Feed API](/reference/fetch-feed) to fetch the user's notifications and render them using Jetpack Compose or XML layouts.
  </Step>
  <Step title="Customize">
    Style your native inbox views, manage read/unread state, handle action buttons, and add pagination using the REST API endpoints.
  </Step>
</Steps>
