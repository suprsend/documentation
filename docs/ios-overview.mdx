title: "Overview"
description: "Build a native in-app notification experience in your iOS (Swift) application with SuprSend."
---

The SuprSend iOS SDK lets you build a native notification inbox in your Swift app. Use SuprSend's REST APIs to fetch and manage notifications, and the Preferences API to let users control their notification settings — all rendered with your own SwiftUI or UIKit views.

<Info>
  SuprSend does not provide a pre-built inbox UI component for iOS. You'll use the [Notification Feed REST API](/reference/fetch-feed) to fetch notifications and build native SwiftUI or UIKit views.
</Info>

## Install

<CodeGroup>
```bash Swift Package Manager
# In Xcode: File → Add Packages → paste the URL below
https://github.com/suprsend/suprsend-swift-sdk
```

```ruby CocoaPods
pod "SuprSend"
```
</CodeGroup>

## Quick look

```swift
import SuprSend

// Initialize in AppDelegate
SuprSend.shared.configure(publicKey: "YOUR_PUBLIC_API_KEY")

// Authenticate user
await SuprSend.shared.identify(
  distinctID: "USER_DISTINCT_ID",
  userToken: userTokenData
)
```

## Get started

<Steps>
  <Step title="Authenticate">
    Initialize the SuprSend SDK and authenticate the user. The SDK handles token management and secure communication.

    [SDK Integration →](/docs/ios-integration)
  </Step>
  <Step title="Add a component">
    Use SuprSend's [Notification Feed API](/reference/fetch-feed) to fetch the user's notifications and render them using SwiftUI or UIKit views. Add [Preferences](/docs/ios-preferences) to let users control their notification settings.
  </Step>
  <Step title="Customize">
    Style your native inbox views, manage read/unread state, handle action buttons, and add pagination using the REST API endpoints.
  </Step>
</Steps>
