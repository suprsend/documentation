## Prerequisites

- A SuprSend account — [sign up here](https://auth.suprsend.com/sign-up) if you don't have one
- Your **Public API Key** from [Settings → API Keys](https://app.suprsend.com/en/sandbox/developers/api-keys)
- A **user token** (JWT) generated on your backend for authentication — see the [authentication guide](/docs/client-authentication)

## Install the SDK

<CodeGroup>
  ```bash npm
  npm install @suprsend/react
  ```

  ```bash yarn
  yarn add @suprsend/react
  ```

  ```bash pnpm
  pnpm add @suprsend/react
  ```
</CodeGroup>

## Set up the provider

Wrap your application (or the part that needs notifications) with `SuprSendProvider`. This initializes the SDK, authenticates the user, and establishes a real-time WebSocket connection.

```jsx
import { SuprSendProvider } from "@suprsend/react";

function App() {
  return (
    <SuprSendProvider
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="USER_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <YourApp />
    </SuprSendProvider>
  );
}
```

### Provider props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `publicApiKey` | `string` | Yes | Your SuprSend public API key |
| `distinctId` | `string` | Yes | Unique identifier for the user |
| `userToken` | `string` | Yes | Signed JWT token for authentication |
| `host` | `string` | No | Custom API host URL |
| `socketHost` | `string` | No | Custom WebSocket host URL |

## Add your first component

Once the provider is set up, drop in any SuprSend component as a child.

### Inbox (Popover)

```jsx
import { SuprSendProvider, Inbox } from "@suprsend/react";

function App() {
  return (
    <SuprSendProvider
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="USER_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <header>
        <Inbox />
      </header>
      <main>{/* Your app content */}</main>
    </SuprSendProvider>
  );
}
```

### Toast notifications

```jsx
import { SuprSendProvider, Inbox, Toast } from "@suprsend/react";

function App() {
  return (
    <SuprSendProvider
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="USER_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <Inbox />
      <Toast />
    </SuprSendProvider>
  );
}
```

## Verify the integration

1. Trigger a test workflow from the [SuprSend dashboard](https://app.suprsend.com) targeting the same `distinctId` you used above.
2. You should see the notification appear in real time in the Inbox popover.
3. Check the browser console — the SDK logs connection status and any errors.
