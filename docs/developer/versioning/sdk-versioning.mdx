SuprSend SDKs follow a comprehensive versioning strategy designed to provide predictable updates, maintain backward compatibility, and ensure smooth integration experiences across all supported platforms.

## SDK Versioning Strategy

<Tabs>
  <Tab title="Versioning Rules">
    ### Semantic Versioning (SemVer)
    SuprSend SDKs implement [Semantic Versioning (SemVer)](https://semver.org/) with the format `MAJOR.MINOR.PATCH`:

    - **MAJOR** (X.0.0): Breaking changes requiring code modifications
    - **MINOR** (X.Y.0): New features that are backward compatible  
    - **PATCH** (X.Y.Z): Bug fixes that are backward compatible

    ### Current Status
    - **Status**: Active Development
    - **Version Tags**: Implemented with semantic versioning
    - **API Compatibility**: v1.2.2 (Latest)

    ### Version Strategy
    - **Versioning**: Semantic Versioning (SemVer)
    - **Format**: MAJOR.MINOR.PATCH
    - **Implementation**: Currently active across all SDKs

    > **Important**: All SuprSend SDKs use semantic versioning with tagged releases. GitHub releases are the source of truth for SDK changes and updates.
