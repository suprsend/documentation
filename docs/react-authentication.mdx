---
title: "Authentication"
description: "How to authenticate users in React applications using SuprSend."
---

React applications use JWT-based authentication with signed user tokens for secure user authentication.

## Quick Setup

Authenticate users by passing the `userToken` prop to the `SuprSendProvider` component:

```javascript
import { SuprSendProvider } from '@suprsend/react';

function App() {
  return (
    <SuprSendProvider 
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="USER_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <YourApp />
    </SuprSendProvider>
  );
}
```
