## Overview
In SuprSend, you have a team page where you can see all the team members who are part of an account. You can access team page by clicking on the profile icon in the top nav bar and selecting **Account Settings** from the dropdown.
You can search members, change their roles, invite new members, and remove members from the team page. All actions performed on this page are logged in audit logs.

You can search by name or email address, with results updating as you type. You can also filter the list by role (Admin or Member) and by status (Active or Deactivated). Filters can be combined to narrow down the results.

## Permissions

| Action | Admin | Member |
|--------|-------|--------|
| Full platform access | ✓ | ✓ |
| View team members | ✓ | ✓ |
| Search and filter team members | ✓ | ✓ |
| Change user roles | ✓ | ✗ |
| Invite new members | ✓ | ✗ |
