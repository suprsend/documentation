---
title: "Authentication"
description: "How to authenticate users in JavaScript applications using SuprSend."
---

JavaScript applications use JWT-based authentication with signed user tokens for secure user authentication.

## Quick Setup

Authenticate users by passing the `userToken` in the configuration when initializing SuprSend:

```javascript
const suprsendConfig = {
  distinctId: "YOUR_DISTINCT_ID",
  publicApiKey: "YOUR_PUBLIC_API_KEY",
  userToken: "SIGNED_USER_TOKEN",
};

initSuprSend(suprsendConfig);
```

## Learn More

For detailed information on generating signing keys, creating JWT tokens, and implementing authentication in your JavaScript application, see the [complete authentication guide](/docs/client-authentication).
