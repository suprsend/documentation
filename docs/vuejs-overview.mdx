SuprSend integrates with Vue.js through the [`@suprsend/web-components`](https://www.npmjs.com/package/@suprsend/web-components) package — framework-agnostic Web Components that work seamlessly as custom elements in Vue templates. No Vue-specific wrapper needed.

  ![Popover inbox](https://files.readme.io/8134005a504eceaeeba615a8d9189cdc363e99a62f51be601e23177f8651c166-Screenshot_2025-01-14_at_5.50.46_PM.png)
</Frame>

<Info>
  Vue.js uses the same JavaScript Web Components SDK under the hood. All component docs, customization options, and headless APIs in the **JavaScript** tab apply directly to Vue.js.
</Info>

## Install

```bash
npm install @suprsend/web-components
```

## Quick look

```vue
<template>
  <div id="suprsend-inbox"></div>
</template>

<script setup>
import { onMounted, onUnmounted } from "vue";
import { initSuprSend, clearSuprSend } from "@suprsend/web-components";

onMounted(() => {
  initSuprSend({
    publicApiKey: "YOUR_PUBLIC_API_KEY",
    distinctId: "USER_DISTINCT_ID",
    userToken: "SIGNED_USER_TOKEN",
  });
});

onUnmounted(() => {
  clearSuprSend();
});
</script>
```

## Get started

<Steps>
  <Step title="Authenticate">
    Generate a JWT token on your backend and pass it to `initSuprSend`. This securely connects the user to their notification feed.

    [Set up authentication →](/docs/javascript-authentication)
  </Step>
  <Step title="Add a component">
    Use `<suprsend-inbox>` for a popover feed or `<suprsend-feed>` for a full-screen layout. Web Components work directly in Vue templates.
  </Step>
  <Step title="Customize">
    Theme the components to match your app's design, add multi-language support, or go fully headless for complete control.
  </Step>
</Steps>
