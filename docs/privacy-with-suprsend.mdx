## What does SuprSend do with your data?

SuprSend is a platform that allows you to send notifications to your users. It is built with privacy in mind, and we have a strict policy on how we handle your data.

## Data we collect

### User Profile Data and Its Benefits

When you sync user profiles with SuprSend, it enables several key capabilities:

1. **Seamless & Simple Workflow Triggers:**
   - Once a user profile is synced, you only need to reference their `distinct_id`
   - No need to repeatedly send entire user information with each trigger
   - This therefore, reduces payload size and simplifies integration

2. **Preference Management:**
   - Store and honor user notification preferences centrally on the SuprSend dashboard.
   - Set once, and store the channel opt-ins/opt-outs for every user.
   - Handle category-based preferences without additional logics.

3. **Advanced Capabilities:**
   - Create targeted user lists for Broadcast.
   - Support cross-user notifications with users profiles in-hand on SuprSend platform.

### Profile Creation using User Data

When you pass user information in a workflow trigger, SuprSend automatically:
- Creates or updates the user profile.
- Stores respectivechannel information securely
- Maintains preference settings for each user.
- Enables future reference via their `distinct_id`

### How to Send Notifications to Users Anonymously?

You can send notifications **without entering user data to SuprSend plaform.** This could be useful in case if you have PII restrictions (Personally Identifiable Information) or privacy concerns that prevent user data synchronization.
This could be achieved by the following steps:

- Use anonymous notifications by setting `is_transient=true` in workflow triggers.
- No persistent user profile is created
- Channel information is used only for the current notification trigger

[Learn more in detail.](/docs/users#anonymous-notifications)
