## What does SuprSend do with User Data?

SuprSend is a platform built with **strict privacy concerns** and allows you to send notifications to your users with industry-standard [suitable compliances](/docs/security).


## How do we use User Profile Data?

When you sync user profiles with SuprSend, it enables several key capabilities for you to seamlessly send notifications to your users no matter how complex your workflow is. 

This includes:

1. **Seamless & Simple Workflow Triggers:**
   - Once a user profile is synced, you only need to reference their `distinct_id`
   - No need to repeatedly send entire user information with each trigger
   - This therefore, reduces payload size and simplifies integration

2. **Preference Management:**
   - Store and honor user notification preferences centrally on the SuprSend dashboard.
   - Set once, and store the channel opt-ins/opt-outs for every user.
   - Handle category-based preferences without additional logics.

3. **Advanced Capabilities:**
   - Create targeted user lists for Broadcast.
   - Support cross-user notifications with users profiles in-hand on SuprSend platform.

## Is it possible to send notifications without entering user data to SuprSend?

Yes, you can opt to send notifications anonymously via SuprSend. It could be achieved **without entering user data** like usual. 

This feature has been developed considering a case of **PII restrictions** (Personally Identifiable Information) or privacy concerns for our clients.
