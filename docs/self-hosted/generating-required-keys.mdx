---
title: "Generating Required Keys"
description: "Generate deployment secret, NATS NKey pair, and AES cipher keys for SuprSend self-hosted installation."
---

Before installing SuprSend, generate **three keys**. They are used for authentication, messaging, and encryption across components.

| Key | Purpose |
|-----|---------|
| **Deployment secret** | Authenticates and secures your SuprSend installation |
| **NATS NKey pair** | Signs and validates messages (NATS) |
| **AES cipher secret + IV** | Encrypts sensitive payloads |

---

## Step 1: Deployment secret key

A unique random string that authenticates and secures your installation.

**Run a Python shell:**

```bash
python3
```

Then, in the interactive shell:

```python
import secrets
"".join(secrets.choice("abcdefghijklmnopqrstuvwxyz0123456789!@#$%^&*(-_=+)") for i in range(50))
```

Copy the **50-character** output and store it securely.

**Example output:**

```
x2#e9ahb!@1d3f_4g5jklmn6opq7rstuv8wxyz
```

<Tip>
Keep this key private. It should never be committed to version control or shared publicly.
</Tip>

---

## Step 2: NATS NKey pair

SuprSend uses **NATS** for messaging. Generate a **public/private key pair** for signing and validation.

**Step 1 — Install the `nk` CLI:**

   ```bash
   go install github.com/nats-io/nkeys/nk@latest
   ```

**Step 2 — Generate a user key pair:**

```bash
nk -gen user -pubout
```

You get two keys: **Private** (starts with `SU...`) and **Public** (starts with `U...`).

**Example output:**

```
SUAGC2U8QYUZ7A... (Private Key)
UAGB2UZJBNFJZ3... (Public Key)
```

<Warning>
**Important:**
- Store the private key securely — it must not be exposed or shared.
- The public key can be shared with your SuprSend deployment configuration.
</Warning>

---

## Step 3: AES cipher secret and vector

Used for AES encryption of sensitive payloads. Generate a **32-byte shared secret** and a **16-byte IV**.

**Run a Python shell:**

```bash
python3
```

Then, inside the interactive shell:

```python
def aes_cipher():
    import os
    shared_secret = os.urandom(32)
    iv = os.urandom(16)
    print("Shared Secret (AES Key):", shared_secret.hex())
    print("Vector (IV):", iv.hex())

aes_cipher()
```

**Example output:**

```
Shared Secret (AES Key): 3f2a9e5b1d0a6c4d4e7f9b1c2d3a4b5c6d7e8f90123456789abcdef1234567890
Vector (IV): 1a2b3c4d5e6f70819283746556473829
```

<Note>
Save both values safely. You'll add them to your SuprSend secrets when configuring the [SuprSend installation](/docs/byoc/suprsend-installation-guide) (Create SuprSend Secrets section).
</Note>
