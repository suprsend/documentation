<Warning>
**End of Support for [@suprsend/web-inbox](https://github.com/suprsend/suprsend-web-inbox). Migrate to `@suprsend/web-components`**

We have upgraded authentication of inbox from HMAC to JWT as it is more secure. Please migrate to newer SDK if you are on old one.

Development of the [@suprsend/web-inbox](https://github.com/suprsend/suprsend-web-inbox) SDK has been discontinued in favour of the new [@suprsend/web-components](https://docs.suprsend.com/docs/web-components-integration) SDK. Reason for this change is to bring all drop-in components for inbox and preferences, under one SDK with improved security through JWT authentication.
</Warning>

## Migrating from @suprsend/web-inbox to @suprsend/web-components

Most of the features that inbox component supports remain unchanged. Following are the main changes that happened in the new SDK.

### Authentication changes

Authentication mechanism has been changed from [HMAC authentication](/docs/hmac-authentication) to [JWT authentication](/docs/client-authentication) because HMAC authentication (subscriberId) is not as secure as JWT authentication. The new SDK uses signed user tokens (JWT) for secure user authentication.

## Steps to migrate

<Steps>
<Step title="Remove existing `@suprsend/web-inbox` and install `@suprsend/web-components`">

```shell npm
npm uninstall @suprsend/web-inbox

npm install @suprsend/web-components@latest
```

```shell yarn
yarn remove @suprsend/web-inbox

yarn add @suprsend/web-components@latest
```

Install the package from [npm](https://www.npmjs.com/package/@suprsend/web-components).
</Step>

<Step title="Update Integration Code">

Replace the old integration code with the new `@suprsend/web-components` integration. Refer to the [integration guide](/docs/web-components-integration) for detailed setup instructions.

The main changes:
- Use `initSuprSend()` instead of the old initialization method
- Pass `userToken` for authentication instead of `subscriberId`
- Update configuration structure to match the new SDK format

</Step>

<Step title="Update Authentication">

For authenticating users, follow the [authentication guide](/docs/javascript-authentication) to implement JWT-based authentication with signed user tokens.

</Step>
</Steps>

Please reach out to us if you face any issues during migration.
