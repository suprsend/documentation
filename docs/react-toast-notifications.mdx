---
title: "Toast Notifications"
description: "Show a real-time toast popup when a new notification arrives in your React app."
---

Toast notifications let you surface new messages the moment they arrive — even when the user hasn't opened the inbox. The [`@suprsend/react`](https://www.npmjs.com/package/@suprsend/react) SDK exposes a `feed.new_notification` event you can hook into with any toast library.

<Note>
  In `@suprsend/react`, toast functionality is **not** built into the `Inbox` component by default. You implement it separately, giving you full control over the toast library and design.
</Note>

## How it works

1. Wrap your component in [`SuprSendFeedProvider`](/docs/react-sdk-headless-feed#suprsendfeedprovider) (or use [`Inbox`](/docs/react-in-app-feed), which wraps it internally).
2. Access the `feedClient` via the [`useFeedClient`](/docs/react-sdk-headless-feed#usefeedclient) hook.
3. Listen to the `feed.new_notification` event.
4. Show a toast using your preferred library (the example below uses [react-hot-toast](https://react-hot-toast.com/)).

## Integration

### With the Inbox component

```jsx
import { SuprSendProvider, Inbox } from "@suprsend/react";

function App() {
  return (
    <SuprSendProvider
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="YOUR_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <Inbox>
        <ToastHandler />
      </Inbox>
    </SuprSendProvider>
  );
}
```

### With SuprSendFeedProvider (headless or full-screen)

```jsx
import { SuprSendProvider, SuprSendFeedProvider } from "@suprsend/react";

function App() {
  return (
    <SuprSendProvider
      publicApiKey="YOUR_PUBLIC_API_KEY"
      distinctId="YOUR_DISTINCT_ID"
      userToken="SIGNED_USER_TOKEN"
    >
      <SuprSendFeedProvider>
        <ToastHandler />
        {/* your feed UI */}
      </SuprSendFeedProvider>
    </SuprSendProvider>
  );
}
```

### ToastHandler component

```jsx
import { useEffect } from "react";
import toast, { Toaster } from "react-hot-toast";
import { useFeedClient, ToastNotificationCard } from "@suprsend/react";

function ToastHandler() {
  const feedClient = useFeedClient();

  useEffect(() => {
    if (!feedClient) return;

    const handler = (data) => {
      toast.custom(<ToastNotificationCard notificationData={data} />);
      feedClient.markAsSeen(data.n_id);
    };

    feedClient.emitter.on("feed.new_notification", handler);
    return () => feedClient.emitter.off("feed.new_notification", handler);
  }, [feedClient]);

  return <Toaster />;
}
```

## ToastNotificationCard props

The SDK exports a lightweight `ToastNotificationCard` component designed for use inside toast popups.

```typescript
interface ToastNotificationProps {
  notificationData: IRemoteNotification;
  hideAvatar?: boolean;
  themeType?: ThemeType;
  theme?: ToastNotificationCardTheme;
}

interface ToastNotificationCardTheme {
  avatar?: React.CSSProperties;
  headerText?: React.CSSProperties;
  bodyText?: NotificationCardBodyTextThemeProps;
  container?: React.CSSProperties;
}
```
