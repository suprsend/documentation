---
title: "Internationalization"
description: "Translate inbox UI strings into your user's language in React."
---

The `SuprSendI18nProvider` component translates inbox UI labels — such as "Notifications", "Mark all as read", and time-relative strings — into the user's locale. Wrap your inbox components with this provider to enable translations.

## Setup

Wrap `Inbox` or `NotificationFeed` with `SuprSendI18nProvider` and pass the desired `locale` code.

<CodeGroup>
```jsx Inbox
<SuprSendI18nProvider locale="fr">
  <Inbox />
</SuprSendI18nProvider>
```

```jsx Feed
<SuprSendI18nProvider locale="fr">
  <NotificationFeed />
</SuprSendI18nProvider>
```
</CodeGroup>

`SuprSendI18nProvider` is available in both `@suprsend/react` and `@suprsend/react-core`.

## Supported languages

The following languages are supported out of the box:

| Code | Language |
|------|----------|
| `en` | [English](https://github.com/suprsend/suprsend-react-core/blob/main/src/i18n/languages/en.ts#L5) (default) |
| `fr` | [French](https://github.com/suprsend/suprsend-react-core/blob/main/src/i18n/languages/fr.ts#L5) |
| `de` | [German](https://github.com/suprsend/suprsend-react-core/blob/main/src/i18n/languages/de.ts#L5) |
| `es` | [Spanish](https://github.com/suprsend/suprsend-react-core/blob/main/src/i18n/languages/es.ts#L5) |
| `ar` | [Arabic](https://github.com/suprsend/suprsend-react-core/blob/main/src/i18n/languages/ar.ts#L5) |

## Custom translations

To add a language that isn't listed above, or to override specific strings, pass a `translations` object.

```typescript
interface ITranslations {
  notifications?: string;
  markAllAsRead?: string;
  noNotificationsTitle?: string;
  noNotificationsDescription?: string;
  pinned?: string;
  markAsUnread?: string;
  markAsRead?: string;
  archive?: string;
  expiresIn?: string;
  minute?: string;
  minutes?: string;
  hour?: string;
  hours?: string;
  day?: string;
  days?: string;
  week?: string;
  weeks?: string;
  month?: string;
  months?: string;
  year?: string;
  years?: string;
}
```

```jsx
<SuprSendI18nProvider
  locale="fr"
  translations={{ notifications: "Mes notifications", markAllAsRead: "Tout marquer comme lu" }}
>
  <Inbox />
</SuprSendI18nProvider>
```
