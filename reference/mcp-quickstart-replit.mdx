## Set up the connection

<Steps>
  <Step title="Open your integrations">
    In Replit, go to **Integrations** in your workspace settings and open **Your integrations**. Next to **Connectors**, click **Add custom** → **Add personal MCP server**.

    <Frame>
      <img src="/images/mcp-replit-add-custom.png" alt="Replit Integrations page with the Add custom menu open and Add personal MCP server shown" />
    </Frame>
  </Step>

  <Step title="Add the SuprSend MCP server">
    Enter `SuprSend` as the **Display name** and `https://mcp.suprsend.com/mcp` as the **MCP Server URL**.

    Keep **Scan tool output for prompt injection** on, and leave **Advanced settings** as they are.

    <Frame>
      <img src="/images/mcp-replit-connect.png" alt="Replit Connect SuprSend form with Display name SuprSend, MCP Server URL https://mcp.suprsend.com/mcp and a note that the server requires authentication" />
    </Frame>
  </Step>

  <Step title="Sign in with your SuprSend account">
    Replit shows that the server requires authentication. Continue, and Replit opens the sign-in. Sign in with your SuprSend account. The agent gets the same permissions your role has in the SuprSend dashboard.
  </Step>

  <Step title="Verify the connection">
    In Replit Agent, ask:

    ```
    List my SuprSend workspaces.
    ```

    The agent answers with your SuprSend workspaces.
  </Step>
</Steps>

## Pin a workspace and restrict tools

By default, Replit Agent can use every workspace and tool your role allows. To keep it on one workspace, or to give it only the tools a job needs, use one of these URLs as the **MCP Server URL**:

- **Pin a workspace** by adding its slug to the path. The agent then can't switch to another workspace:

  ```
  https://mcp.suprsend.com/mcp/staging
  ```

- **Restrict tools** with `?tools=`, a comma-separated list of tool names or groups:

  ```
  https://mcp.suprsend.com/mcp/staging?tools=users_*,data_*
  ```

See [Scope the connection](/reference/mcp-overview#scope-the-connection) for every URL pattern, and the [tool list](/reference/mcp-tool-list) for every tool.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Server shows disconnected or refuses the connection">
    Check the workspace slug in the URL. It must match a workspace in your SuprSend account exactly, for example `staging`, not the workspace's display name. A slug that doesn't exist fails with `403 workspace_forbidden`. To see your slugs, remove the slug, reconnect, and ask: "List my SuprSend workspaces."
  </Accordion>
</AccordionGroup>
