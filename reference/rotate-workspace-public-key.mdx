sidebarTitle: Rotate Public Key
---

<Info>
  Rotation issues a new `api_key` value for the same public key record. The request body is optional — include `is_secure_mode_enabled` to update secure mode in the same call. Update your SDK configuration with the new value returned in the response.
</Info>
