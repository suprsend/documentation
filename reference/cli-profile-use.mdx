<Info>
Profiles are only required for **self-hosted and BYOC deployments**. SaaS users can authenticate using [environment variables or command-line flags](/reference/cli-authentication).
</Info>

## Syntax

```bash
suprsend profile use [flags]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `--name string` | Profile name to set as active (required) | – |

## Example

```bash
suprsend profile use --name default
```
