Set the active profile configuration for all subsequent CLI commands.

## Syntax

```bash
suprsend profiles use [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `--name string` | Profile name to set as active (required) | – |

## Examples

<CodeGroup>

```bash Basic Usage
# Set a profile as active
suprsend profiles use --name my-profile

# Set default profile as active
suprsend profiles use --name default

# Set development profile as active
suprsend profiles use --name dev-profile
```

```bash Advanced Usage
# Set profile with JSON output
suprsend profiles use --name production-profile --output json

# Set profile with YAML output
suprsend profiles use --name staging-profile --output yaml

# Set profile with verbose logging
suprsend profiles use --name test-profile --verbosity debug
```

</CodeGroup>
