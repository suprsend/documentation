The active profile determines which credentials and environment are used by default in CLI commands.

```bash
suprsend profile use [flags]
```

## Options

| Flag         | Description                   | Default |
| ------------ | ----------------------------- | ------- |
| `--name`     | Profile name to set as active | –       |
| `-h, --help` | Show help for the command     | –       |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--config` – Config file (default: `$HOME/.suprsend.yaml`)
* `--no-color` – Disable color output
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--service-token` – Service token for authentication
* `--verbosity` – Logging level

## Examples

Set the `production` profile as active:

```bash
suprsend profile use --name production
```

Set the `staging` profile as active with JSON output:

```bash
suprsend profile use --name staging --output json
```
