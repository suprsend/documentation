<Note>
**Bulk trigger** uses this same endpoint (`POST /trigger/`). Send a JSON **array** of workflow objects instead of a single JSON **object**.

In the API examples here, open the **Bulk workflow trigger** request body tab, use the **Bulk Trigger Workflows** cURL example, and see the responses.
</Note>
