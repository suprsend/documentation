---
title: Roll Workspace Signing Key
openapi: "POST /v1/{workspace}/ws_signing_key/{signing_key_uid}/roll/"
sidebarTitle: Roll Signing Key
---

<Warning>
  Rolling a signing key marks the previous active key as `rolled` and issues a new active key. The new `private_key_pem` / `private_key_base64` values are returned **only** in this response — save them immediately.
</Warning>

<Info>
  The path parameter is the signing key `uid` (for example `signing_key_20260101T000000`), not the `id`.
</Info>
