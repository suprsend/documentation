---
title: Delete Workspace Signing Key
openapi: "DELETE /v1/{workspace}/ws_signing_key/{signing_key_uid}/"
sidebarTitle: Delete Signing Key
---

<Warning>
  Deleting a signing key is irreversible. Clients validating signatures against this key will fail once the delete completes.
</Warning>

<Info>
  The path parameter is the signing key `uid` (for example `signing_key_20260101T000000`), not the `id`.
</Info>
