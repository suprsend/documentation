<Note>
**Early access.** Triggering a workflow on a list is a closed feature. [Contact us](mailto:support@suprsend.com) to get early access for your workspace. Until it's on, requests return `202` but no workflow runs.
</Note>

<Warning>
Use this API for lists of up to **1,000 users**. If the list has more, only the first 1,000 users (in the order they were added) get a run, and the rest are skipped without an error. To notify a larger list, use a [broadcast](/reference/trigger-broadcast).
</Warning>
