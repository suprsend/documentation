<Note>
**Early access.** Triggering a workflow on a list is a closed feature. [Contact us](mailto:support@suprsend.com) to get early access for your workspace. Until it's on, requests return `202` but no workflow runs.
</Note>

<Warning>
Use this API for lists of up to **1,000 users**. To notify a larger list, use a [broadcast](/reference/trigger-broadcast).
</Warning>
