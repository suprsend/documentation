Retrieve and display workflows from your SuprSend workspace with pagination and filtering capabilities. This command fetches workflow data from the management API, supporting mode-based filtering (live/draft), pagination controls, and multiple output formats.

## Syntax

```bash
suprsend workflow list [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `-l, --limit int` | Number of workflows to list | `20` |
| `-f, --offset int` | Starting position for pagination | `0` |
| `-m, --mode string` | Workflow mode (`live` or `draft`) | `live` |

## Examples

<CodeGroup>

```bash Basic Usage
# List live workflows (default)
suprsend workflow list

# List with custom limit
suprsend workflow list --limit 50

# List draft workflows
suprsend workflow list --mode draft
```

```bash Advanced Usage
# Pagination example
suprsend workflow list --limit 50 --offset 20

# Different workspace
suprsend workflow list --workspace production

# JSON output
suprsend workflow list --output json
```

</CodeGroup>
