Supports pagination, modes (live/draft), and environment selection.

```bash
suprsend workflow list [flags]
```

## Options

| Flag                | Description                           | Default |
| ------------------- | ------------------------------------- | ------- |
| `-h, --help`        | Show help for the command             | –       |
| `-l, --limit int`   | Limit the number of workflows to list | `20`    |
| `-f, --offset int`  | Starting position for pagination      | `0`     |
| `-m, --mode string` | Workflow mode (`live` or `draft`)     | `live`  |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file path

## Examples

List workflows in your default (staging) workspace:

```bash
suprsend workflow list
```

List 50 workflows, skipping the first 20:

```bash
suprsend workflow list --limit 50 --offset 20
```

List workflows in **draft mode** from production:

```bash
suprsend workflow list --mode draft --workspace production
```
