Retrieve a specific event by its slug. Returns the event definition including name, description, and payload schema. Pass the slug as a positional argument or via `--slug`.

## Syntax

```bash
suprsend event get [<slug>] [flags]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `-o, --output string` | Output format (`json`, `yaml`) | `json` |
| `-g, --slug string` | Event slug (alternative to the positional argument) | – |

<Tip>
Use `-o json` for machine-readable JSON output, `-o yaml` for YAML.
</Tip>

## Example

```bash
# Get a specific event by slug
suprsend event get ORDER_RECEIVED

# Get using the flag form
suprsend event get --slug ORDER_RECEIVED

# Get an event in YAML format
suprsend event get ORDER_RECEIVED --output yaml

# Get an event from production workspace
suprsend event get ORDER_RECEIVED --workspace production
```
