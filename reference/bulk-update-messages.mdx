<Note>
**Channel applicability for `action`**

- `seen`, `clicked` — all channels
- `dismissed` — push only (`androidpush`, `iospush`, `webpush`, `whatsapp`, `slack`, `ms_teams`)
- `read`, `unread`, `archived`, `unarchived` — `inbox` only
</Note>
