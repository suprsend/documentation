Create a new profile configuration to store workspace credentials and API endpoints.

## Syntax

```bash
suprsend profiles add [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `--name string` | Name of the profile (required) | – |
| `--token string` | Service token (required) | – |
| `--base-url string` | Base URL | – |
| `--mgmnt-url string` | Management URL | – |

## Examples

<CodeGroup>

```bash Basic Usage
# Add a new profile with required fields
suprsend profiles add --name staging --token your-staging-token

# Add profile with custom name
suprsend profiles add --name production --token your-prod-token
```

```bash Advanced Usage
# Add profile with custom API endpoints
suprsend profiles add \
  --name production \
  --token your-prod-token \
  --base-url https://hub.suprsend.com/ \
  --mgmnt-url https://api.suprsend.com/

# Add profile with all options
suprsend profiles add \
  --name staging \
  --token staging-token \
  --base-url https://staging-hub.suprsend.com/ \
  --mgmnt-url https://staging-api.suprsend.com/
```

</CodeGroup>
