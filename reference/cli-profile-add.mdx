Profiles store credentials, environment URLs, and workspace settings to simplify switching between multiple accounts or environments.

```bash
suprsend profile add [flags]
```

## Options

| Flag                     | Description                      | Default                     |
| ------------------------ | -------------------------------- | --------------------------- |
| `--name string`          | Name of the profile (required)   | –                           |
| `--service-token string` | Authentication token (required)  | –                           |
| `--base-url string`      | SuprSend Hub API endpoint        | `https://hub.suprsend.com/` |
| `--mgmnt-url string`     | SuprSend Management API endpoint | `https://api.suprsend.com/` |
| `-h, --help`             | Show help for the command        | –                           |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--config` – Config file (default: `$HOME/.suprsend.yaml`)
* `--no-color` – Disable color output
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level

## Examples

Add a new profile named `staging`:

```bash
suprsend profile add --name staging --service-token your-staging-token
```

Add a new profile with custom API endpoints:

```bash
suprsend profile add \
  --name production \
  --service-token your-prod-token \
  --base-url https://hub.suprsend.com/ \
  --mgmnt-url https://api.suprsend.com/
```
