Follow the steps below to set up the SuprSend MCP Server and start integrating SuprSend using your favourite AI assistant.

## Step 1: Get Your Service Token

You'll need a service token from SuprSend to authenticate the MCP Server.
Get your service token from [SuprSend Dashboard → **Account Settings** → **Service Tokens**](https://app.suprsend.com/en/account-settings/service-tokens).

## Step 2: Configure the MCP Server

The MCP server runs through the SuprSend CLI. With [`npx`](https://docs.npmjs.com/cli/v10/commands/npx), your AI client launches it on demand - no install step, always the latest version. Requires [Node.js](https://nodejs.org/) 18+.

Paste the configuration below into your AI client's MCP settings (see client-specific steps further down):

```json
{
  "mcpServers": {
    "suprsend": {
      "command": "<your-npx-path>",
      "args": ["-y", "suprsend", "start-mcp-server"],
      "env": {
        "SUPRSEND_SERVICE_TOKEN": "your_token_here"
      }
    }
  }
}
```

<Note>
  Prefer a managed install over npx? Install the CLI via [Homebrew, binary, or source build](/reference/cli-installation), then use `"command": "suprsend"` with `"args": ["start-mcp-server"]` instead.
</Note>

## Step 3: Set Up MCP in your AI coding assistants

### Cursor
Click the button below to install the SuprSend MCP server in Cursor (version 1.0 or higher is required). The link uses Cursor’s app protocol and will open Cursor to add the server. If it does not open Cursor or you see an error, add the MCP configuration manually using the steps below.

[![Add to Cursor](https://cursor.com/deeplink/mcp-install-dark.svg)](cursor://anysphere.cursor-deeplink/mcp/install?name=suprsend&config=eyJjb21tYW5kIjoibnB4IiwiYXJncyI6WyIteSIsInN1cHJzZW5kIiwic3RhcnQtbWNwLXNlcnZlciJdLCJlbnYiOnsiU1VQUlNFTkRfU0VSVklDRV9UT0tFTiI6InlvdXJfc2VydmljZV90b2tlbl9oZXJlIn19)

Or, add the MCP configuration manually to your Cursor settings.

1. Go to Cursor -> Settings -> Cursor Settings
2. On the settings modal, Go to MCP & Integrations and click on “New MCP Server”.
3. Inside mcp.json file, add below code:
    ```json
    {
      "mcpServers": {
        "suprsend": {
          "command": "<your-npx-path>",
          "args": ["-y", "suprsend", "start-mcp-server"],
          "env": {
            "SUPRSEND_SERVICE_TOKEN": "your_token_here"
          }
        }
      }
    }
    ```

### Claude Desktop
1. Open Claude Settings → Developer Section.
2. Click Edit Config under Local MCP Servers.
3. Add the following snippet:
    ```json
    {
      "mcpServers": {
        "suprsend": {
          "command": "<your-npx-path>",
          "args": ["-y", "suprsend", "start-mcp-server"],
          "env": {
            "SUPRSEND_SERVICE_TOKEN": "your_token_here"
          }
        }
      }
    }
    ```

### Windsurf
1. Go to Windsurf settings → Extensions
2. Add the SuprSend MCP configuration
    ```json
    {
      "suprsend": {
        "command": "<your-npx-path>",
        "args": ["-y", "suprsend", "start-mcp-server"],
        "env": {
          "SUPRSEND_SERVICE_TOKEN": "your_token_here"
        },
        "name": "SuprSend MCP Server"
      }
    }
    ```
  Refresh the MCP Settings by clicking the refresh button.
