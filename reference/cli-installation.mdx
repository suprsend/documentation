## Prerequisites

Before installing, ensure you have:

* A [SuprSend workspace account](https://app.suprsend.com)  
* Basic familiarity with using the terminal  
* **Node.js v18+** (required for type generation features)  
* (Optional, for source builds) [Go](https://go.dev/dl/) **1.24.0+** and [Git](https://git-scm.com/)

## Install with Homebrew (Recommended)

For macOS and Linux users:

```bash
brew tap suprsend/tap
brew install suprsend
```

Upgrade later with:

```bash
brew upgrade suprsend
```

<Note>
**Recommended for most users.** Handles path setup and easy upgrades.
</Note>

## Install from Binary Releases

Pre-built binaries are available on the [GitHub Releases](https://github.com/suprsend/cli/releases) page.

### Supported Platforms

| Platform | Architectures              | Format    | Binary Name    |
| -------- | -------------------------- | --------- | -------------- |
| Linux    | x86_64, ARM64             | `.tar.gz` | `suprsend`     |
| macOS    | x86_64, ARM64 (Universal) | `.tar.gz` | `suprsend`     |
| Windows  | x86_64, ARM64             | `.zip`    | `suprsend.exe` |

### Linux/macOS Installation

```bash
# Make binary executable
chmod +x suprsend
# Move to system path
sudo mv suprsend /usr/local/bin/
```

### Windows Installation

```powershell
# Extract suprsend.exe
# Move it into a folder in your PATH
```

<Note>
**Security:** Each release includes a `checksums.txt` file for verifying binary integrity.
</Note>

## Build from Source

For developers who need the latest features:

```bash
# Clone and build
git clone https://github.com/suprsend/cli.git
cd cli/cmd/suprsend
go build -o suprsend

# Install to system path
sudo mv suprsend /usr/local/bin/
```

## Verify Installation

Run:

```bash
suprsend --help
```

Expected output:

```
SuprSend CLI - Command-line tool for managing SuprSend resources

Usage:
  suprsend [command]

Available Commands:
  workflow    Manage workflows
  schema      Manage schemas
  profile     Manage profiles
  ...
```

If you see this, installation was successful! 🎉

## Enable Shell Completion (Optional)

Set up shell completion for better CLI experience:

### Quick Setup

**Bash:**
```bash
source <(suprsend completion bash)
```

**Zsh:**
```bash
source <(suprsend completion zsh)
```

**Fish:**
```bash
suprsend completion fish | source
```

**PowerShell:**
```powershell
suprsend completion powershell | Out-String | Invoke-Expression
```

### Permanent Setup

For permanent completion, run the appropriate command for your shell:

**Bash (Linux):**
```bash
suprsend completion bash > /etc/bash_completion.d/suprsend
```

**Bash (macOS):**
```bash
suprsend completion bash > $(brew --prefix)/etc/bash_completion.d/suprsend
```

**Zsh (Linux):**
```bash
suprsend completion zsh > "${fpath[1]}/_suprsend"
```

**Zsh (macOS):**
```bash
suprsend completion zsh > $(brew --prefix)/share/zsh/site-functions/_suprsend
```

**Fish:**
```bash
suprsend completion fish > ~/.config/fish/completions/suprsend.fish
```

<Note>
**Restart Required:** After permanent setup, start a new shell session for completion to take effect.
</Note>
