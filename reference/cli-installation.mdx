## Prerequisites

* [SuprSend account](https://app.suprsend.com)
* Node.js v18+ (for type generation)

## Installation

### Homebrew (Recommended)

For macOS and Linux users with automatic dependency management:

```bash
brew tap suprsend/tap
brew install suprsend
```

### Binary Releases

For users requiring pre-compiled binaries without package managers:

Download from [GitHub Releases](https://github.com/suprsend/cli/releases).

```bash
# Linux/macOS
chmod +x suprsend
sudo mv suprsend /usr/local/bin/

# Windows: Extract suprsend.exe to your PATH
```

### Source Build

For development environments requiring latest features:

```bash
git clone https://github.com/suprsend/cli.git
cd cli/cmd/suprsend
go build -o suprsend
sudo mv suprsend /usr/local/bin/
```

## Verify Installation

```bash
suprsend --help
suprsend version
```

<Note>
When you run `suprsend version`, you should see the latest version (currently **v1.0.0**). If you see an older version, you may need to update your installation.
</Note>
