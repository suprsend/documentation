---

## Drop-in Inbox Popover Feed

```
Add SuprSend in-app inbox to this React app. Show a notification bell or inbox
where users can see their notifications. Use my API key from env
(SUPRSEND_PUBLIC_API_KEY) and get login tokens from my backend so it knows who
the user is.
```

---

## Toast Notifications

```
Add SuprSend toast notifications to this React app. When a new notification
arrives, show a small popup toast (e.g. with react-hot-toast). Use the SDK's
"new notification" event and their ToastNotification component to show the
notification in the toast. The app should already have SuprSendProvider and
Inbox set up.
```

## Notification Preferences Page

**Prerequisite:** Create notification categories in the [SuprSend dashboard](https://app.suprsend.com) first so the preferences page can load and display them.

```
Add a SuprSend notification preferences page to this React app. Let users see and
change which notification categories they're subscribed to (e.g. marketing,
product updates) and which channels they want (email, push, in-app). Use
SuprSendProvider with my API key from env (SUPRSEND_PUBLIC_API_KEY) and
login tokens from my backend. Use useSuprSendClient to load preferences and
update them when the user toggles categories or channels.
```
