## Overview

The `suprsend-docs-support` skill gives your agent a structured map of where to find SuprSend documentation and how to reach the support team. It also provides LLM-optimized documentation endpoints that your agent can fetch directly at runtime — so instead of relying on training data, your agent can look up current SuprSend docs on demand.

---

## Installation

```bash
npx skills add https://github.com/suprsend/skills --skill suprsend-docs-support
```

Or install all SuprSend skills at once:

```bash
npx skills add suprsend/skills
```

---

## What your agent can do

- Fetch up-to-date SuprSend documentation using LLM-optimized endpoints rather than relying on training data
- Find the right docs page for any SuprSend concept, API, or feature
- Look up current SDK methods, configuration options, and integration guides
- Direct you to the fastest support channel for your situation

---

## Documentation endpoints

SuprSend exposes documentation endpoints optimized for programmatic and LLM access:

| Endpoint | What it is |
|---|---|
| `https://docs.suprsend.com/llms.txt` | Lightweight page index with descriptions — fast lookup for agents |
| `https://docs.suprsend.com/llms-full.txt` | Complete documentation in a single file — full content for deep lookups |
| `https://docs.suprsend.com` | Main documentation site for human browsing |

<Tip>
  When your agent needs to look up a SuprSend concept, it can fetch `llms.txt` first to find the right page, then fetch that specific page directly — rather than guessing from potentially outdated training data.
</Tip>

## Support channels

| Channel | How to access | Best for |
|---|---|---|
| **AI Copilot** | Open [app.suprsend.com](https://app.suprsend.com) — click the orb in the bottom-right corner. Shortcut: `Cmd+/` on macOS, `Ctrl+/` on Windows/Linux | Instant answers, workflow debugging, feature questions |
| **In-app chat** | In the dashboard, click **?** in the top nav → **"Chat with us"** (login required) | Fast human support |
| **Slack Community** | [Join here](https://join.slack.com/t/suprsendcommunity/shared_invite/zt-3932rw936-XNWY1RC8bsffh4if4ZyoXQ) | Community Q&A, product announcements |
| **Email** | [support@suprsend.com](mailto:support@suprsend.com) | Detailed bug reports, account-specific questions |
