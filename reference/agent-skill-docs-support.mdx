The `suprsend-docs-support` skill gives your agent a structured map of SuprSend documentation and support channels. It also provides LLM-optimized endpoints your agent can fetch directly at runtime — so instead of relying on training data, your agent looks up current docs on demand.

---

## Installation

```bash
npx skills add https://github.com/suprsend/skills --skill suprsend-docs-support
```

Or install all SuprSend skills at once:

```bash
npx skills add suprsend/skills
```

---

## Advantages

- **Real-time documentation access**: Fetch current SuprSend docs at runtime using LLM-optimized endpoints ([`llms.txt`](https://docs.suprsend.com/llms.txt), [`llms-full.txt`](https://docs.suprsend.com/llms-full.txt)) instead of relying on potentially outdated training data.
- **Precise page discovery**: Find the exact docs page for any concept — workflows, SDK methods, API endpoints, channel configuration, preferences — without guessing at URLs.
- **SDK and integration lookups**: Look up current methods, configuration options, and integration guides across all [backend](https://docs.suprsend.com/docs/developer/sdk-overview.md) (Python, Node.js, Java, Go) and [client](https://docs.suprsend.com/docs/client-authentication.md) (React, JavaScript, Android, iOS, Flutter, React Native) SDKs.
- **Support channel routing**: Direct you to the fastest support channel for your situation — AI copilot for instant answers, in-app chat for human support, Slack community for Q&A, or email for detailed bug reports.

---

## Documentation endpoints

| Endpoint | What it is |
|---|---|
| `https://docs.suprsend.com/llms.txt` | Lightweight page index with descriptions — fast lookup to find the right page |
| `https://docs.suprsend.com/llms-full.txt` | Complete documentation in a single file — for deep or broad lookups |
| `https://docs.suprsend.com` | Main documentation site |

<Tip>
  Have your agent fetch `llms.txt` first to locate the right page, then fetch that page directly — rather than guessing from potentially outdated training data.
</Tip>

| **In-app chat** | Dashboard → **?** → **Chat with us** (login required) | Human support |
