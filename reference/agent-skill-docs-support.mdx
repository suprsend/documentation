**Use this skill when** you want your AI agent to answer SuprSend questions accurately - pulling from live docs instead of guessing from training data - and to know exactly where to point you for human help when needed.

The skill teaches your agent two things:

<CardGroup cols={2}>
  <Card title="Map of SuprSend docs" icon="map">
    A structured map of SuprSend documentation, including LLM-optimized `.md` endpoints it can fetch on demand.
  </Card>
  <Card title="Right support channel" icon="life-ring">
    Which support channel to point you at for each kind of question - Agent, in-app chat, Slack, or email.
  </Card>
</CardGroup>

<Card title="Install" icon="download">
  ```bash
  npx skills add https://github.com/suprsend/skills --skill suprsend-docs-support
  ```
</Card>

## Try it

<Steps>
  <Step title="Ask a question it wouldn't know offhand">
    ```text
    What's the difference between batch and digest nodes in
    SuprSend workflows? When should I use each?
    ```
  </Step>

  <Step title="Your agent fetches live docs">
    The skill activates and your agent finds the batch and digest pages through the guides index, [`docs.suprsend.com/_llms/documentation.txt`](https://docs.suprsend.com/_llms/documentation.txt). It fetches [`docs.suprsend.com/docs/batch.md`](https://docs.suprsend.com/docs/batch.md) and [`docs.suprsend.com/docs/digest.md`](https://docs.suprsend.com/docs/digest.md), then answers from the live docs - not from possibly stale training data.
  </Step>
</Steps>

## Documentation endpoints

The skill teaches your agent to find the right page first, then fetch only that page.

1. **Find the page in an index.** `llms.txt` is the top-level index. It lists mostly API reference pages and links to sub-indexes. Guide pages, such as batch and digest, appear only in the guides index. For a how-to question, the agent starts there.
2. **Fetch that page as Markdown.** Every SuprSend docs page is available as plain Markdown - append `.md` to its URL.

<AccordionGroup>
  <Accordion title="llms.txt - top-level index" icon="list">
    [`docs.suprsend.com/llms.txt`](https://docs.suprsend.com/llms.txt)

    Mostly API reference pages, plus links to the sub-indexes below.
  </Accordion>
  <Accordion title="_llms/documentation.txt - guides index" icon="book-open">
    [`docs.suprsend.com/_llms/documentation.txt`](https://docs.suprsend.com/_llms/documentation.txt)

    Product guide pages, such as batch and digest. Start here for how-to questions.
  </Accordion>
  <Accordion title="_llms/developer-resources.txt - SDK and developer index" icon="code">
    [`docs.suprsend.com/_llms/developer-resources.txt`](https://docs.suprsend.com/_llms/developer-resources.txt)

    SDK and developer guide pages.
  </Accordion>
  <Accordion title="llms-full.txt - everything in one file" icon="book">
    [`docs.suprsend.com/llms-full.txt`](https://docs.suprsend.com/llms-full.txt)

    Every doc page in one file, several MB. Use it only for broad sweeps, never for a single lookup.
  </Accordion>
  <Accordion title="Any specific page" icon="file-lines">
    [`docs.suprsend.com/<path>.md`](https://docs.suprsend.com)

    Any specific page in plain Markdown.
  </Accordion>
</AccordionGroup>

<Tip>
  For a how-to question, the agent looks up the page in the guides index, then fetches only that page with `.md`. This keeps context lean and answers accurate.
</Tip>

## With the SuprSend MCP server

When your agent is connected to the hosted [SuprSend MCP server](/reference/mcp-overview) (`https://mcp.suprsend.com/mcp`), it uses the server's `docs_search` tool to look up docs.

The server also serves the SuprSend skills. Your agent loads them the first way its client supports:

1. The MCP Skills extension.
2. The server's `skill://` resources.
3. The `docs_get_skill` tool.

All three return the same files. See the [MCP tool list](/reference/mcp-tool-list) for the docs tools.
