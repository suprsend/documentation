Enables local development and version control of schema definitions.

```bash
suprsend schema pull [flags]
```

## Options

| Flag               | Description                         | Default              |
| ------------------ | ----------------------------------- | -------------------- |
| `-m, --mode`       | Mode of schemas (`live`/`draft`)    | `live`               |
| `-d, --output-dir` | Directory to save schema JSON files | `./suprsend/schema/` |
| `-h, --help`       | Show help for the command           | –                    |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file path

## Examples

Pull live schemas:

```bash
suprsend schema pull
```

Pull draft schemas to a specific folder:

```bash
suprsend schema pull --mode draft --output-dir ./my-schemas
```

Pull schemas from production:

```bash
suprsend schema pull --workspace production --output-dir ./prod-schemas
```
