Pull schema definitions from your SuprSend workspace to the local file system. This command retrieves all schemas from the specified workspace, handles automatic pagination, and saves them as individual JSON files in the local directory structure.

## Syntax

```bash
suprsend schema pull [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |


## Examples

<CodeGroup>

```bash Basic Usage
# Pull schemas from staging workspace (default)
suprsend schema pull

# Pull schemas in JSON format
suprsend schema pull --output json
```

```bash Advanced Usage
# Pull schemas from production workspace
suprsend schema pull --workspace production

# Pull schemas with YAML output
suprsend schema pull --workspace staging --output yaml

# Pull schemas with verbose logging
suprsend schema pull --verbosity debug
```

</CodeGroup>
