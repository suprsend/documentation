Commit a draft schema to live status in your SuprSend workspace. This command transitions the specified schema from draft to live state, making it active for notification validation and production use.

<Note>
To revert a live schema back to draft, use [`schema reset`](/reference/cli-schema-reset).
</Note>

## Syntax

```bash
suprsend schema commit <schema-slug> [flags]
```

**Arguments:**
- `<schema-slug>` - Name of the schema to commit (required)

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |


## Examples

<CodeGroup>

```bash Basic Usage
# Commit a schema to live status
suprsend schema commit my-schema

# Commit schema in staging workspace (default)
suprsend schema commit notification-schema
```

```bash Advanced Usage
# Commit schema in production workspace
suprsend schema commit my-schema --workspace production

# Commit schema with JSON output
suprsend schema commit notification-schema --output json

# Commit schema with verbose logging
suprsend schema commit my-schema --verbosity debug
```

</CodeGroup>
