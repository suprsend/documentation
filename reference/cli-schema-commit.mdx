Once committed, the schema becomes active for template validation.

```bash
suprsend schema commit [flags]
```

## Options

| Flag         | Description               | Default |
| ------------ | ------------------------- | ------- |
| `-h, --help` | Show help for the command | –       |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file path

## Examples

Commit a schema to live in staging:

```bash
suprsend schema commit --workspace staging
```

Commit a schema to live in production:

```bash
suprsend schema commit --workspace production
```
