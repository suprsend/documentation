Kai is SuprSend’s Slack agent. It connects to your workspace so you can look up profiles, adjust preferences, trigger workflows, track events, pull delivery analytics, and ask product questions — without opening the dashboard.

<Warning>
  Kai is in **beta**. Behavior, channels, and availability may change. Use **`#kai-test`** for experiments before relying on Kai in production channels.
</Warning>

---

## Where to talk to Kai

| Surface | How to use it |
| --- | --- |
| **Direct messages** | Open a DM with **`@Suprsend-Kai`** and send your request. Best for private lookups and changes tied to a specific person or object. |
| **Channels** | Mention **`@Suprsend-Kai`** in a channel (for example **`#kai-test`**) when you want the thread visible to the team. |

Invite or install the Slack app for your workspace using the link your SuprSend admin shares. After it is installed, the bot user appears like any other member you can DM or `@mention`.

## What Kai can help with

<CardGroup cols={2}>
  <Card title="Data and lookups" icon="magnifying-glass" iconType="solid">
    Fetch user profiles, preferences, and object or tenant configuration. List workflows, templates, and events.
  </Card>
  <Card title="User and object management" icon="users" iconType="solid">
    Create or update users and objects. Manage channel addresses (email, SMS, push, Slack, and others). Update notification preferences (opt in or out, channel restrictions). Add or remove users from subscriber lists or object subscriptions.
  </Card>
  <Card title="Workflows and events" icon="diagram-project" iconType="solid">
    Trigger API-triggered workflows. Track events so event-triggered workflows can run.
  </Card>
  <Card title="Analytics" icon="chart-line" iconType="solid">
    Query notification delivery stats, engagement rates, and workflow execution counts. Ask Kai to summarize trends or produce charts for breakdowns over time.
  </Card>
  <Card title="Documentation" icon="book" iconType="solid">
    Get answers about how SuprSend works — APIs, SDKs, channels, templates, workflows, preferences, and related concepts.
  </Card>
</CardGroup>

## Example prompts

Use clear identifiers (user distinct ID, object ID, workflow slug, tenant key) so Kai can call the right tools.

```text
Show the profile and preferences for user distinct_id "user_123".

List workflows in this workspace and summarize what each one does.

Trigger the "order-confirmation" workflow for user "jane@acme.com" with a sample payload.

What were our email delivery and open rates last week?

How do tenant default preferences interact with user-level overrides?
```
