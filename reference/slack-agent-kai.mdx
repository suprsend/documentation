Slack Agent is SuprSend's chat surface inside Slack. It connects to your workspace so you can look up profiles, adjust preferences, trigger workflows, track events, pull delivery analytics, and ask product questions — without opening the dashboard.

<Warning>
  Slack Agent is in **beta**. Behavior, channels, and availability may change. Use a private test channel (for example **`#suprsend-test`**) for experiments before relying on it in production channels.
</Warning>

---

## Where to talk to Slack Agent

| Surface | How to use it | Privacy |
| --- | --- | --- |
| **Direct messages** | Open a DM with **`@SuprSend`** and send your request. Best for private lookups and changes tied to a specific person, identifier, or object. | Full access — Slack Agent can return PII (email addresses, phone numbers, device tokens, raw identifiers). |
| **Channels** | Mention **`@SuprSend`** in a channel when you want the thread visible to the team. | Protective layer — Slack Agent masks PII in responses (emails, phone numbers, tokens) so sensitive identifiers aren't pasted into shared channels. |

Invite or install the Slack app for your workspace using the link your SuprSend admin shares. After it is installed, the bot user appears like any other member you can DM or `@mention`.

<Note>
  **PII in channels vs. DMs** — channel responses go through a redaction layer that masks email addresses, phone numbers, device tokens, and similar identifiers before posting. The same prompt in a DM returns the raw values. Use DMs for anything user-specific, channels for collaborative or non-sensitive work.
</Note>

## Example prompts

Use clear identifiers (user distinct ID, object ID, workflow slug, tenant key) so Slack Agent can call the right tools.

```text
Show the profile and preferences for user distinct_id "user_123".

List workflows in this workspace and summarize what each one does.

Trigger the "order-confirmation" workflow for user "jane@acme.com" with a sample payload.

What were our email delivery and open rates last week?

How do tenant default preferences interact with user-level overrides?
```
