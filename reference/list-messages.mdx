<Note>
**Pagination notes**

- **Default limit:** `10`. **Maximum:** `1000`.
- If both `before` and `after` are supplied, **`after` takes precedence** — `before` is silently ignored.
- `created_at_gte` and `created_at_lte` use **second-level precision** — sub-second components are truncated. For example, `2026-04-26T21:34:32.500Z` and `2026-04-26T21:34:32.700Z` resolve to the same boundary.
</Note>
