Add the hosted SuprSend MCP server to ChatGPT and manage your SuprSend workspace in natural language — users, workflows, templates, broadcasts, preferences, and delivery analytics.

## Add the server as a custom MCP plugin

<Steps>
  <Step title="Open the custom MCP flow">
    1. In ChatGPT, open **Plugins**.
    2. Click **+** → **Add custom MCP server**.

    See OpenAI's [MCP guide](https://developers.openai.com/api/docs/mcp) for the generic steps.
  </Step>

  <Step title="Paste the SuprSend MCP URL">
    ```
    https://mcp.suprsend.com/mcp
    ```

    To pin a workspace, use `https://mcp.suprsend.com/mcp/staging` instead. To scope to specific tool groups, append `?tools=users.*,data.*`.

    The SuprSend server speaks Streamable HTTP at `/mcp`. ChatGPT connects over the same transport.
  </Step>

  <Step title="Accept the risk warning">
    ChatGPT shows a warning that custom MCP servers can run arbitrary tool calls on your account. Click **I understand and want to continue**, then **Create as a plugin**.
  </Step>

  <Step title="Sign in with your SuprSend account">
    ChatGPT opens a WorkOS sign-in popup. Sign in with the SuprSend account that has access to the workspace you want to reach. Your role (admin or member) decides which tools you see.
  </Step>

  <Step title="Verify the connection">
    Start a new chat and try:

    ```
    Search the SuprSend docs for how preference categories work.
    ```

    ChatGPT calls `docs.search` and shows the results.
  </Step>
</Steps>

<Warning>
  **Admins can send real notifications from ChatGPT.** Tools like `broadcasts.trigger`, `workflows.trigger`, `workflows.test_run`, `events.track`, and `templates.send_test` deliver to real recipients. ChatGPT prompts for confirmation before each call, but confirm against the right workspace (pin one with `/mcp/<workspace>`) before you approve.
</Warning>

<Tip>
  Scope the agent's reach by appending `?tools=` to the URL — for example `https://mcp.suprsend.com/mcp?tools=users.*,data.*`. See the [tool list](/reference/mcp-tool-list) for group names.
</Tip>
