## Get Your Service Token

1. Log in to your [SuprSend dashboard](https://app.suprsend.com)
2. Go to **Account Settings → Service Tokens**
3. Create a new service token or copy an existing one

## Authentication Methods

The CLI resolves authentication using this priority order:

| Priority | Method | When to Use | Duration |
|----------|--------|-------------|----------|
| 1 | Environment Variable | Development, CI/CD, scripts | Session-based |
| 2 | Command-Line Flag | One-off commands, testing | One-time |
| 3 | Active Profile | Multiple environments, team workflows | Persistent |


### Environment Variable

For development environments and CI/CD pipelines:

```bash
export SUPRSEND_SERVICE_TOKEN="your_service_token_here"
export SUPRSEND_BASE_URL="https://hub.suprsend.com/"
export SUPRSEND_MGMNT_URL="https://api.suprsend.com/"
```

### Command-Line Flag

For one-off commands and testing:

```bash
suprsend workflow list --service-token "your_service_token_here"
```

### Active Profile

For managing multiple environments and team workflows:

```bash
suprsend profiles add --name production --token "your_token_here"
suprsend profiles use production
```
