Add the hosted SuprSend MCP server to Codex CLI so your agent can drive your SuprSend account from the terminal — manage workflows, templates, broadcasts, preferences, and query delivery analytics in natural language.

## Install via the SuprSend agent plugin

The SuprSend agent plugin ships a Codex-ready MCP config and runs the WorkOS sign-in handshake for you.

<Steps>
  <Step title="Add the SuprSend marketplace">
    ```bash
    codex plugin marketplace add suprsend/agent-plugin
    ```
  </Step>

  <Step title="Install the SuprSend plugin">
    From the marketplace, install **suprsend**. The plugin registers the hosted MCP server (`https://mcp.suprsend.com/mcp`) under the name `suprsend`.
  </Step>

  <Step title="Sign in with your SuprSend account">
    ```bash
    codex mcp login suprsend
    ```

    Codex opens a browser window for WorkOS sign-in. Sign in with the SuprSend account that has access to the workspace you want to reach. Your role (admin or member) decides which tools you see.
  </Step>

  <Step title="Verify the connection">
    In a Codex session, try:

    ```
    List all workflows in my SuprSend workspace.
    ```

    If the server is connected and signed in, Codex calls `workflows.list` and returns your workflows.
  </Step>
</Steps>

See [Agent plugin](/reference/agent-plugin) for the full plugin install matrix. For details on Codex's MCP support, see [learn.chatgpt.com/docs/extend/mcp?surface=cli](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).

<Tip>
  Scope the agent's reach by appending `?tools=` to the URL — the plugin reads this from the server URL it ships with, or you can override it when re-registering the server. See the [tool list](/reference/mcp-tool-list) for group names.
</Tip>
