## Overview

The `suprsend-cli` skill gives your agent the complete SuprSend CLI reference, pulled directly from the [suprsend/cli](https://github.com/suprsend/cli) source. With this skill installed, your agent can run CLI commands correctly on the first try — without guessing at flag names or subcommand structure.

---

## Installation

```bash
npx skills add https://github.com/suprsend/skills --skill suprsend-cli
```

Or install all SuprSend skills at once:

```bash
npx skills add suprsend/skills
```

---

## What your agent can do

- Pull, edit, and push workflows, schemas, events, categories, and translations
- Sync assets between staging and production workspaces
- Set up CI/CD pipelines for notification changes
- Generate type definitions from event schemas in 7 languages
- Start the SuprSend MCP server from the terminal

---

## Notes

**Output formats** — Commands that return data support three output modes:
- `-o pretty` (default) — human-friendly table
- `-o json` — machine-readable, ideal for scripts and CI/CD
- `-o yaml` — YAML output

**Workspace vs profile** — Use `--workspace` to switch between workspaces within the same account. The `profile` command is only for self-hosted/BYOC instances or managing multiple separate accounts. SaaS users on a single account do not need it.
