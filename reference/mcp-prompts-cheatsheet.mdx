## Tips for Using These Prompts

- **Use MCP Server:** If using Cursor or other MCP-compatible tools, the [SuprSend MCP Server](/reference/mcp-overview) provides direct access to our APIs and documentation automatically.
- **Work Sequentially:** Each prompt builds on the previous one. Complete them in order for best results.
- **Reference Documentation:** The AI will automatically reference SuprSend docs when using MCP. For manual step-by-step implementation, see the detailed guides.
- **Customize as Needed:** These prompts are templates. Adjust requirements to match your specific use case.
