SuprSend exposes its full notification infrastructure through AI-native interfaces. Any AI client, such as Claude, ChatGPT, VS Code with GitHub Copilot, Codex, Cursor or Gemini, can drive your SuprSend account in natural language over the hosted MCP server, without opening the dashboard or writing SDK code.

## Which AI tool should I use?

| You want to | Use | Notes |
|---|---|---|
| Connect Claude, VS Code, GitHub Copilot CLI, Codex, Kiro, or Cursor (Teams and Enterprise plans) to your SuprSend account | [Plugin](/reference/agent-plugin) (recommended) | One install adds the hosted MCP server and a skill that tells the agent which tools to use. |
| Connect any other MCP client, such as ChatGPT, Gemini CLI, Cursor on other plans, Devin, Replit or Lovable | [MCP server](/reference/mcp-overview) | Add `https://mcp.suprsend.com/mcp` and sign in with your SuprSend account. SuprSend's skills come from the server. |
| Have a coding agent run the SuprSend CLI: CI/CD, workspace sync, notification files in Git, type generation | [`suprsend-cli` skill](/reference/agent-skill-cli) | The one skill the MCP server doesn't serve. Only useful for agents that can run shell commands. |
| Work with an agent inside the SuprSend dashboard | [SuprSend Agent](/reference/agent) | Click the **Agent** button in the top bar, or press `Cmd+/` (`Ctrl+/` on Windows) to jump to the chat bar. Uses AI credits. |
| Work with your team in Slack | [Slack Agent](/reference/slack-agent) | Mention @SuprSend in a DM or channel. Shares the AI credit pool. |
| Let a production AI agent send notifications at runtime | [Agent SDK](/reference/agent-sdk) | Early access. |

You don't need to install the [Agent Skills](/reference/agent-skills) package when you use the plugin or the MCP server. The server already serves the workflow, template, SQL and docs skills.
