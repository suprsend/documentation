SuprSend exposes its full notification infrastructure through AI-native interfaces. Any AI client — Claude, ChatGPT, VS Code with GitHub Copilot, Codex, Gemini, Windsurf — can now drive your SuprSend account in natural language over the hosted MCP server, without opening the dashboard or writing SDK code.

  <Card title="MCP Server" icon="server" iconType="solid" href="/reference/mcp-overview">

</CardGroup>
