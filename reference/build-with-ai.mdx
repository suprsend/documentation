## MCP Server

Connect SuprSend to any MCP-compatible agent — Cursor, Claude Desktop, Windsurf, and more. Your agent gets live access to your workspace: it can trigger workflows, inspect users, manage preferences, and search docs without you writing any API code.

```json
{
  "mcpServers": {
    "suprsend": {
      "command": "suprsend",
      "args": ["start-mcp-server"],
      "env": {
        "SUPRSEND_SERVICE_TOKEN": "your_service_token_here"
      }
    }
  }
}
```

### What can you do with MCP?

- **Debug notification delivery** — Pull a user's profile, check their registered channel addresses (email, push tokens, phone), inspect category and channel-level preferences, and pinpoint exactly why a notification isn't arriving — all in one conversation.
- **Manage user preferences** — Opt users in or out of notification categories, restrict specific channels (e.g. disable SMS but keep email), and verify the changes — without opening the dashboard.
- **Set up and configure tenants** — Create tenants, set branding properties (logo, colors), and configure tenant-level default preferences that override individual user settings.
- **Audit list and object subscriptions** — Check which lists a user belongs to and which objects they're subscribed to — useful for debugging why a broadcast or object-scoped notification reached (or missed) someone.
- **Bootstrap a test environment** — Create test users with channel addresses, set up tenants, upsert objects, and configure preferences — get an entire test workspace ready from a single prompt.
- **Inspect workflows** — List all workflows in your workspace, check which are enabled or disabled, and verify your notification pipeline is configured correctly before going live.
- **Configure object-level notifications** — Set up preferences on objects (like projects or channels) so all subscribers inherit the right notification behaviour without per-user configuration.
- **Search docs in real time** — Your agent can search and fetch any SuprSend documentation page on demand, so it works with current API surfaces instead of outdated training data.

## Agent Skills

Install SuprSend knowledge directly into your coding agent. Skills are Markdown files that teach your agent the workflow node schema, every CLI command and flag, and where to find SuprSend docs — so it stops hallucinating APIs.

```bash
npx skills add suprsend/skills
```

Works with Cursor, Claude Code, GitHub Copilot, Amp, Cline, Warp, and 40+ others.
