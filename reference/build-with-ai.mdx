SuprSend exposes its full notification infrastructure through AI-native interfaces. Any AI client, such as Claude, ChatGPT, VS Code with GitHub Copilot, Codex, Cursor or Gemini, can drive your SuprSend account in natural language over the hosted MCP server, without opening the dashboard or writing SDK code.

## Which AI tool should I use?

| You want to | Use | Notes |
|---|---|---|
| Connect Claude, ChatGPT, VS Code, Codex, Cursor, Kiro, Gemini CLI or any other MCP client to your SuprSend account | [MCP server](/reference/mcp-overview) | Add `https://mcp.suprsend.com/mcp` and sign in with your SuprSend account. SuprSend's skills come from the server. |
| Have a coding agent run the SuprSend CLI: CI/CD, workspace sync, notification files in Git, type generation | [`suprsend-cli` skill](https://github.com/suprsend/skills/tree/main/skills/suprsend-cli) | The one skill the MCP server doesn't serve. Only useful for agents that can run shell commands. |
| Work with an agent inside the SuprSend dashboard | [In-product Agent](/reference/agent) | Click **Agent** in the left side panel for the full page, or press `Cmd+/` (`Ctrl+/` on Windows) to open a side chat next to the page you're on. Uses AI credits. |
| Work with your team in Slack | [Slack Agent](/reference/slack-agent) | Mention @SuprSend in a DM or channel. Shares the AI credit pool. |
| Let a production AI agent send notifications at runtime | [Agent SDK](/reference/agent-sdk) | Early access. |

SuprSend's workflow, template, SQL and docs [skills](/reference/mcp-overview#agent-skills) come with the MCP server, so there's nothing extra to install.
