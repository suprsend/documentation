Use SuprSend from AI tools. Connect any MCP client, such as Claude, ChatGPT, VS Code with GitHub Copilot, Codex, Cursor or Gemini, to the hosted MCP server and manage your SuprSend account in plain English. Inside SuprSend, chat with the In-product Agent in the dashboard or the Slack Agent in Slack. To let your own production agents send notifications, use the Agent SDK.

## Which AI tool should I use?

| You want to | Use | Notes |
|---|---|---|
| Connect Claude, ChatGPT, VS Code, Codex, Cursor, Kiro, Gemini CLI or any other MCP client to your SuprSend account | [MCP server](/reference/mcp-overview) | Beta. Add `https://mcp.suprsend.com/mcp` and sign in with your SuprSend account. SuprSend's workflow, template, SQL and docs [skills](/reference/mcp-overview#agent-skills) come from the server, so there's nothing extra to install. |
| Have a coding agent run the SuprSend [CLI](/reference/cli-intro): CI/CD, workspace sync, notification files in Git, type generation | [`suprsend-cli` skill](https://github.com/suprsend/skills/tree/main/skills/suprsend-cli) | The one skill the MCP server doesn't serve. Only useful for agents that can run shell commands. |
| Work with an agent inside the SuprSend dashboard | [In-product Agent](/reference/agent) | Click **Agent** in the left side panel for the full page, or press `Cmd+/` (`Ctrl+/` on Windows / Linux) to open a side chat next to the page you're on. Uses AI credits. |
| Work with your team in Slack | [Slack Agent](/reference/slack-agent) | Mention @SuprSend in a DM or channel. Shares the AI credit pool. |
| Let a production AI agent send notifications at runtime | [Agent SDK](/reference/agent-sdk) | Early access. |
