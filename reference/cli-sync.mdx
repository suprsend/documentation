Transfer SuprSend assets between different workspaces with filtering and mode options. This command fetches assets from the source workspace, validates them, and deploys them to the destination workspace, supporting asset-specific filtering, mode-based synchronization, and multiple output formats.

## Syntax

```bash
suprsend sync [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-a, --assets string` | Assets to sync (`all`, `workflows`, `schemas`) | `all` |
| `-f, --from string` | Source workspace (required) | `staging` |
| `-m, --mode string` | Mode to sync assets (`draft`, `live`) | `live` |
| `-t, --to string` | Destination workspace (required) | `production` |
| `-h, --help` | Show help for the command | – |

## Examples

<CodeGroup>

```bash Basic Usage
# Sync all assets from staging to production
suprsend sync --from staging --to production

# Sync only workflows
suprsend sync --from staging --to production --assets workflows

# Sync only schemas
suprsend sync --from staging --to production --assets schemas
```

```bash Advanced Usage
# Sync draft schemas
suprsend sync --from staging --to production --assets schemas --mode draft

# Different workspaces
suprsend sync --from development --to staging

# JSON output
suprsend sync --from staging --to production --output json
```

</CodeGroup>
