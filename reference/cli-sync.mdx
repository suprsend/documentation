Transfer SuprSend assets (workflows and schemas) between different workspaces.  
Enables environment promotion, backup strategies, and collaborative development workflows.

```bash
suprsend sync [flags]
```

## Options

| Flag           | Description                                    | Default       |
| -------------- | ---------------------------------------------- | ------------- |
| `-a, --assets string` | Assets to sync (`all`, `workflows`, `schemas`) | `all`         |
| `-f, --from string`   | Source workspace (required)                    | `staging`     |
| `-m, --mode string`   | Mode to sync assets (`draft`, `live`)          | `live`        |
| `-t, --to string`     | Destination workspace (required)               | `production`  |
| `-h, --help`          | Show help for the command                      | –             |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--config` – Config file (default: `$HOME/.suprsend.yaml`)
* `--no-color` – Disable color output
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--service-token` – Service token for authentication
* `--verbosity` – Logging level

## Examples

Sync all assets from staging to production:

```bash
suprsend sync --from staging --to production
```

Sync only workflows from staging to production:

```bash
suprsend sync --from staging --to production --assets workflows
```

Sync draft schemas between workspaces:

```bash
suprsend sync --from staging --to production --assets schemas --mode draft
```
