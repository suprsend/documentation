<Warning>
  The `private_key_pem` and `private_key_base64` values are returned **only in this response**. Save them securely at creation time — they cannot be retrieved again.
</Warning>

<Note>
  Each workspace can have at most **one active signing key**. If one already exists, this endpoint returns a `400 ValidationError`. Use the [Roll Signing Key](/reference/roll-workspace-signing-key) endpoint to replace an existing active key; rolling retires the previous key (`status: rolled`) and issues a new one.
</Note>
