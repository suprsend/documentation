Upload local workflow definitions from your environment to a SuprSend workspace.  
Useful for deploying changes, keeping workspaces in sync, or version-controlled workflow management.

```bash
suprsend workflow push [flags]
```

## Options

| Flag                      | Description                          | Default                |
| ------------------------- | ------------------------------------ | ---------------------- |
| `-h, --help`              | Show help for the command            | –                      |
| `-d, --output-dir string` | Directory containing local workflows | `./suprsend/workflow/` |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file path

## Examples

Push workflows from the default directory to the staging workspace:

```bash
suprsend workflow push
```

Push workflows from a specific directory:

```bash
suprsend workflow push --output-dir ./my-workflows
```

Push workflows to the production workspace:

```bash
suprsend workflow push --workspace production --output-dir ./my-workflows
```
