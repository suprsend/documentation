Upload workflow JSON files from your local `./suprsend/workflow/` directory to a SuprSend workspace. This command validates the local directory, processes all JSON workflow files, and uploads them via the management API.

## Syntax

```bash
suprsend workflow push [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `-d, --force-dir` | Create workflow directory without permission prompt | `false` |

## Examples

<CodeGroup>

```bash Basic Usage
# Push workflows from default directory
suprsend workflow push

# Push workflows and create directory if needed
suprsend workflow push --force-dir
```

```bash Advanced Usage
# Push workflows to production workspace
suprsend workflow push --workspace production --force-dir

# Push with custom workspace and force directory creation
suprsend workflow push --workspace staging --force-dir
```

</CodeGroup>
