<Note>
  **Beta — launched 2026-10-08.** The hosted SuprSend MCP server is in Beta. The endpoint, auth flow, and tool list may still change before general availability.
</Note>

<Warning>
  **Cursor sign-in: not yet.** Cursor currently signs in to remote MCP servers only through Dynamic Client Registration (DCR). The SuprSend MCP server uses Client ID Metadata Documents (CIMD), so native OAuth sign-in from Cursor is not yet available. Install via the SuprSend agent plugin below — the plugin handles the sign-in flow for you.
</Warning>

## Install the SuprSend agent plugin

The SuprSend agent plugin is the only supported way to connect the hosted MCP server to Cursor today. It ships a Cursor-ready MCP config and handles the sign-in handshake.

<Steps>
  <Step title="Add the SuprSend marketplace in Cursor">
    Open **Dashboard → Plugins & MCPs → Add Marketplace → Import from Repo** and paste:

    ```
    https://github.com/suprsend/agent-plugin
    ```
  </Step>

  <Step title="Install the SuprSend plugin">
    From the marketplace, install **suprsend**. The plugin registers the hosted MCP server (`https://mcp.suprsend.com/mcp`) under the name `suprsend`.
  </Step>

  <Step title="Sign in with your SuprSend account">
    On the first tool call, Cursor opens a browser window for WorkOS sign-in. Sign in with the SuprSend account that has access to the workspace you want to reach.
  </Step>
</Steps>

See [Agent plugin](/reference/agent-plugin) for the full plugin install matrix.

<Note>
  **Why no direct `mcp.json` config?** Cursor's remote MCP sign-in uses Dynamic Client Registration (DCR), and the SuprSend MCP server authenticates with Client ID Metadata Documents (CIMD). Hand-editing `~/.cursor/mcp.json` can register the server, but sign-in fails before the first tool call. We'll document a native config path as soon as Cursor adds CIMD support; until then, the plugin above is the only working route.
</Note>

<Tip>
  Scope the agent's reach by appending `?tools=` to the URL — for example `https://mcp.suprsend.com/mcp?tools=users.*,data.*`. See the [tool list](/reference/mcp-tool-list) for group names.
</Tip>

## Verify the connection

In a new Cursor Agent chat, try:

```
List all workflows in my SuprSend workspace.
```

If the server is connected and signed in, Cursor calls `workflows.list` and returns your workflows.
