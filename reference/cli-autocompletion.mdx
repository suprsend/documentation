## Supported Shells

The CLI provides tab completion for:
- Command names and subcommands
- Flag names and values  
- Workspace names
- Output formats (pretty, json, yaml)

## Shell Setup

<CodeGroup>

```bash bash
# Quick setup for current session
source <(suprsend completion bash)

# Linux permanent setup
suprsend completion bash > /etc/bash_completion.d/suprsend

# macOS permanent setup
suprsend completion bash > $(brew --prefix)/etc/bash_completion.d/suprsend
```

```bash zsh
# Quick setup for current session
source <(suprsend completion zsh)

# Linux permanent setup
suprsend completion zsh > "${fpath[1]}/_suprsend"

# macOS permanent setup
suprsend completion zsh > $(brew --prefix)/share/zsh/site-functions/_suprsend
```

```bash fish
# Quick setup for current session
suprsend completion fish | source

# Permanent setup
suprsend completion fish > ~/.config/fish/completions/suprsend.fish
```

```powershell pwsh
# Quick setup for current session
suprsend completion powershell | Out-String | Invoke-Expression

# Permanent setup - add to PowerShell profile
suprsend completion powershell >> $PROFILE
```

</CodeGroup>

<Note>
**Bash:** Requires `bash-completion` package. Install via your OS package manager if not already installed.

**Zsh:** Enable completion if not already enabled: `echo "autoload -U compinit; compinit" >> ~/.zshrc`
</Note>

## Options

| Flag | Description |
|------|-------------|
| `--no-descriptions` | Disable completion descriptions |
| `-h, --help` | Show help for the specific shell completion |

## Verification

Test autocompletion after setup:

```bash
suprsend <TAB>
suprsend workflow <TAB>
suprsend --<TAB>
```
