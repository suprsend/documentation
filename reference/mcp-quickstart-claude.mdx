## Set up the connection

<Tabs>

<Tab title="Claude Code">

<Steps>
  <Step title="Add the SuprSend MCP server">
    From your **regular terminal** (not inside a running `claude` session):

    ```bash
    claude mcp add --transport http suprsend https://mcp.suprsend.com/mcp
    ```
  </Step>

  <Step title="Sign in with your SuprSend account">
    On first connect, Claude Code opens your browser. Sign in with your SuprSend account. The agent gets the same permissions your role has in the SuprSend dashboard.
  </Step>

  <Step title="Verify the connection">
    Start `claude` and ask:

    ```
    List my SuprSend workspaces.
    ```

    Claude answers with your SuprSend workspaces.
  </Step>
</Steps>

</Tab>

<Tab title="Claude Desktop / Claude.ai">

<Steps>
  <Step title="Open the connectors settings">
    In Claude Desktop or at [claude.ai](https://claude.ai), go to **Settings → Connectors**. On Team and Enterprise plans, an owner may need to allow the connector first.
  </Step>

  <Step title="Add a custom connector">
    1. Click **Add** → **Add custom connector**.
    2. Paste `https://mcp.suprsend.com/mcp` as the URL.
    3. Save.
  </Step>

  <Step title="Sign in with your SuprSend account">
    Claude prompts a browser sign-in on the first tool call. Sign in with your SuprSend account. The agent gets the same permissions your role has in the SuprSend dashboard.
  </Step>

  <Step title="Verify the connection">
    In a new conversation, ask:

    ```
    List my SuprSend workspaces.
    ```

    Claude answers with your SuprSend workspaces.
  </Step>
</Steps>

</Tab>

</Tabs>

## Pin a workspace and restrict tools

By default, Claude can use every workspace and tool your role allows. To keep it on one workspace, or to give it only the tools a job needs, change the URL when you add the server:

- **Pin a workspace** by adding its slug to the path. The agent then can't switch to another workspace:

  ```bash
  claude mcp add --transport http suprsend https://mcp.suprsend.com/mcp/staging
  ```

- **Restrict tools** with `?tools=`, a comma-separated list of tool names or groups:

  ```bash
  claude mcp add --transport http suprsend https://mcp.suprsend.com/mcp/staging?tools=users.*,data.*
  ```

See [Scope the connection](/reference/mcp-overview#scope-the-connection) for every URL pattern, and the [tool list](/reference/mcp-tool-list) for every tool.

## Troubleshooting

<AccordionGroup>
  <Accordion title="OAuth sign-in loop">
    If the browser keeps redirecting without completing sign-in, close every Claude window, clear your SuprSend session at [app.suprsend.com](https://app.suprsend.com), and reconnect. For Claude Code, run `claude mcp remove suprsend` and re-add the server.
  </Accordion>

  <Accordion title="Server shows disconnected">
    Check the workspace slug in the URL. It must match a workspace in your SuprSend account exactly, for example `staging`, not the workspace's display name. A slug that doesn't exist fails with `403 workspace_forbidden`. To see your slugs, re-add the server without a slug and ask: "List my SuprSend workspaces."
  </Accordion>

  <Accordion title="Tools icon missing after restart on Claude Desktop">
    Fully quit the app (⌘Q on macOS, Quit from the tray on Windows) and reopen it. Custom connectors only reload on a full restart; closing the window isn't enough.
  </Accordion>
</AccordionGroup>
