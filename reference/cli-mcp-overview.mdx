Manage SuprSend **MCP Tools**.  
The MCP interface exposes SuprSend functionality as callable tools for AI agents and automated systems.

```bash
suprsend start-mcp-server [flags]
```

## Available Commands

| Command | Description |
|---------|-------------|
| `start-mcp-server` | Start the MCP server for SuprSend |
| `list-tools` | List all available MCP tools |

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for MCP tools | – |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--config` – Config file (default: `$HOME/.suprsend.yaml`)
* `--no-color` – Disable color output
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--service-token` – Service token for authentication
* `--verbosity` – Logging level

## Examples

Start the MCP server with default settings:

```bash
suprsend start-mcp-server
```

List available tools in JSON format:

```bash
suprsend list-tools --output json
```
