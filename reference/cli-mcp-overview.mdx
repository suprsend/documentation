MCP provides a standardized interface that allows AI agents and automated systems to interact with SuprSend's notification infrastructure programmatically. The MCP framework in SuprSend CLI serves as a bridge between AI agents and SuprSend's core functionality.

## Syntax

```bash
suprsend start-mcp-server [flags]
```

## Tool Categories

The MCP framework organizes tools into four main categories:

| Category | Description |
|----------|-------------|
| **User Management** | Handle user lifecycle operations like creating, updating, and managing user preferences |
| **Tenant Management** | Manage multi-tenant configurations, branding, and tenant-specific preferences |
| **Object Management** | Handle generic entity management and subscription operations |
| **Documentation** | Provide AI-powered access to SuprSend's knowledge base through search and retrieval |

## Commands

| Command | Description |
|---------|-------------|
| `start-mcp-server` | Start the MCP server for SuprSend |
| `start-mcp-server list-tools` | List all available MCP tools (subcommand) |

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for MCP tools | – |
| `-T, --tools string` | Types of tools to use (`all` or comma-separated list) | `all` |
| `-t, --transport string` | Transport type (`stdio` or `sse`) | `stdio` |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--config` – Config file (default: `$HOME/.suprsend.yaml`)
* `--no-color` – Disable color output
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--service-token` – Service token for authentication
* `--verbosity` – Logging level
