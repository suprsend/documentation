Profiles allow you to switch between multiple accounts or workspaces easily without repeatedly entering credentials.

## Syntax

```bash
suprsend profiles [flags]
```

## Commands

| Command          | Description                |
| ---------------- | -------------------------- |
| `profiles add`    | Add a new profile          |
| `profiles list`   | List all saved profiles    |
| `profiles modify` | Update an existing profile |
| `profiles remove` | Delete a profile           |
| `profiles use`    | Set the active profile     |

## Options

| Flag         | Description               | Default |
| ------------ | ------------------------- | ------- |
| `-h, --help` | Show help for the command | –       |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file (default: `$HOME/.suprsend.yaml`)
* `--no-color` – Disable color output
