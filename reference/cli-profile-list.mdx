<Info>
Profiles are only required for **self-hosted and BYOC deployments**. SaaS users can authenticate using [environment variables or command-line flags](/reference/cli-authentication).
</Info>

List all configured profiles in your local configuration file. 
You can also check and edit profiles from config file. Default file path is `$HOME/.suprsend.yaml`.

## Syntax

```bash
suprsend profile list
```
