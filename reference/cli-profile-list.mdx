List all configured profiles in your SuprSend CLI setup.

## Syntax

```bash
suprsend profiles list [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |

## Examples

<CodeGroup>

```bash Basic Usage
# List all profiles
suprsend profiles list

# List profiles in pretty format
suprsend profiles list --output pretty
```

```bash Advanced Usage
# List profiles in JSON format
suprsend profiles list --output json

# List profiles in YAML format
suprsend profiles list --output yaml
```

</CodeGroup>
