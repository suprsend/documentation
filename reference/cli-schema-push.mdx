Push local schema definitions to your SuprSend workspace for testing or production use. This command processes schema files from your local directory and synchronizes them with the target workspace, enabling schema deployment and version management workflows.

## Syntax

```bash
suprsend schema push [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |


## Examples

<CodeGroup>

```bash Basic Usage
# Push schemas to staging workspace (default)
suprsend schema push

# Push schemas in JSON format
suprsend schema push --output json
```

```bash Advanced Usage
# Push schemas to production workspace
suprsend schema push --workspace production

# Push schemas with YAML output
suprsend schema push --workspace staging --output yaml

# Push schemas with verbose logging
suprsend schema push --verbosity debug
```

</CodeGroup>
