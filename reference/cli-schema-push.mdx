Updates draft schemas in the target workspace with your local schema definitions.

```bash
suprsend schema push [flags]
```

## Options

| Flag               | Description                            | Default              |
| ------------------ | -------------------------------------- | -------------------- |
| `-d, --output-dir` | Directory containing schema JSON files | `./suprsend/schema/` |
| `-h, --help`       | Show help for the command              | –                    |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file path

## Examples

Push all schemas from default directory:

```bash
suprsend schema push
```

Push schemas from a specific directory:

```bash
suprsend schema push --output-dir ./my-schemas
```

Push schemas to production workspace:

```bash
suprsend schema push --workspace production --output-dir ./schemas
```
