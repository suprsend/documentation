Remove a profile configuration from your SuprSend CLI setup.

## Syntax

```bash
suprsend profiles remove [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `--name string` | Name of the profile to remove (required) | – |

## Examples

<CodeGroup>

```bash Basic Usage
# Remove a profile by name
suprsend profiles remove --name my-profile

# Remove default profile
suprsend profiles remove --name default

# Remove development profile
suprsend profiles remove --name dev-profile
```

```bash Advanced Usage
# Remove profile with JSON output
suprsend profiles remove --name old-profile --output json

# Remove profile with YAML output
suprsend profiles remove --name unused-profile --output yaml

# Remove profile with verbose logging
suprsend profiles remove --name test-profile --verbosity debug
```

</CodeGroup>
