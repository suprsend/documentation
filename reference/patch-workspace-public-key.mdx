---
title: Enable or Disable Secure Mode
openapi: "PATCH /v1/{workspace}/ws_public_key/{public_key_id}/"
sidebarTitle: Toggle Secure Mode
---

<Info>
  Use this endpoint to enable or disable **secure mode** for a workspace public key by setting `is_secure_mode_enabled`. When secure mode is enabled, clients using this key must present a signed request payload verified by an active [signing key](/reference/list-workspace-signing-keys).
</Info>
