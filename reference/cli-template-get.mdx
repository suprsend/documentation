Retrieve a specific template by slug, including all its channel variants and mock data. Use `--mode` to switch between draft and live versions.

The slug can be passed as a positional argument or via the `-g, --slug` flag.

## Syntax

```bash
suprsend template get [<slug>] [flags]
```

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `-h,`<br />`--help` | Show help for the command | – |
| `-g,`<br />`--slug string` | Template slug. Alternative to passing the slug as a positional argument. | – |
| `-m,`<br />`--mode string` | Version mode: `draft` or `live` | `live` |
| `-o,`<br />`--output string` | Output format: `json`, `yaml`, or `pretty` | `json` |

## Example

```bash
# Get a template by slug (positional)
suprsend template get order-shipped

# Get using the flag form
suprsend template get --slug order-shipped

# Get the current draft version
suprsend template get order-shipped --mode draft

# Get from production workspace
suprsend template get order-shipped --workspace production

# Output as YAML
suprsend template get order-shipped --output yaml
```
