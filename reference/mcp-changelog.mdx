The SuprSend MCP server is hosted, so every client connected to `https://mcp.suprsend.com/mcp` gets each release as soon as it's out. There's nothing to update. This page lists what changed in each version. For how versions are numbered, see [Versioning](/reference/mcp-versioning). For the current tools, see the [tool list](/reference/mcp-tool-list).
