You can change credentials, API endpoints, or other profile settings without creating a new profile.

```bash
suprsend profile modify [flags]
```

## Options

| Flag                 | Description                       | Default |
| -------------------- | --------------------------------- | ------- |
| `--name string`      | Name of the profile to modify     | –       |
| `--token string`     | New service token for the profile | –       |
| `--base-url string`  | New Hub API endpoint              | –       |
| `--mgmnt-url string` | New Management API endpoint       | –       |
| `-h, --help`         | Show help for the command         | –       |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--config` – Config file (default: `$HOME/.suprsend.yaml`)
* `--no-color` – Disable color output
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--service-token` – Service token for authentication
* `--verbosity` – Logging level

## Examples

Modify the service token of a profile named `staging`:

```bash
suprsend profile modify --name staging --token new-staging-token
```

Update both Hub and Management endpoints for a profile:

```bash
suprsend profile modify \
  --name production \
  --base-url https://hub.suprsend.com/ \
  --mgmnt-url https://api.suprsend.com/
```
