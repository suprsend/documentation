Update an existing profile's credentials, API endpoints, or other settings without creating a new profile.

## Syntax

```bash
suprsend profiles modify [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `--name string` | Name of the profile to modify | – |
| `--token string` | New service token for the profile | – |
| `--base-url string` | New Hub API endpoint | – |
| `--mgmnt-url string` | New Management API endpoint | – |

## Examples

<CodeGroup>

```bash Basic Usage
# Update service token for a profile
suprsend profiles modify --name my-profile --token new-token

# Update base URL for a profile
suprsend profiles modify --name default --base-url https://hub.suprsend.com/

# Update management URL for a profile
suprsend profiles modify --name dev-profile --mgmnt-url https://api.suprsend.com/
```

```bash Advanced Usage
# Update multiple fields at once
suprsend profiles modify \
  --name production-profile \
  --token new-prod-token \
  --base-url https://hub.suprsend.com/ \
  --mgmnt-url https://api.suprsend.com/

# Update all profile settings
suprsend profiles modify \
  --name staging-profile \
  --token new-staging-token \
  --base-url https://staging-hub.suprsend.com/ \
  --mgmnt-url https://staging-api.suprsend.com/

# Interactive mode (no flags provided)
suprsend profiles modify
```

</CodeGroup>
