Start the MCP server for SuprSend to enable AI agents and automated systems to interact with SuprSend platform functionality.

```bash
suprsend start-mcp-server [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-T, --tools string` | Types of tools to load (`all` or comma-separated list) | `all` |
| `-t, --transport string` | Transport to use (`stdio`, `sse`, `http`) | `stdio` |
| `-h, --help` | Show help for the command | – |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--config` – Config file (default: `$HOME/.suprsend.yaml`)
* `--no-color` – Disable color output
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--service-token` – Service token for authentication
* `--verbosity` – Logging level

## Examples

Start MCP server with all tools using stdio transport:

```bash
suprsend start-mcp-server
```

Start MCP server with specific tools using HTTP transport:

```bash
suprsend start-mcp-server --tools "users,tenants" --transport http
```

Start MCP server with SSE transport for web applications:

```bash
suprsend start-mcp-server --transport sse
```
