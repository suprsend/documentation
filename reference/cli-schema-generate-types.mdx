The `generate-types` command converts all enabled SuprSend schemas from a specified workspace into strongly-typed programming language interfaces. This command processes all enabled schemas with meaningful content from the workspace, not just a single schema.

## Syntax

```bash
suprsend generate-types <language> --output-file <output-file> [flags]
```

**Arguments:**
- `<language>` - The programming language to generate types for (e.g., `typescript`, `go`, `python`, `java`, `kotlin`, `swift`, `dart`)
- `--output-file` - Path to the output file where types will be generated (required)

**Supported Languages:**
We currently support `typescript`, `go`, `python`, `kotlin`, `swift`, `java`, and `dart`.

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `--output-file string` | Output file for generated types | – |
| `--build-flags string` | Flags to generate types in a certain way | – |
| `--mode string` | Mode of schema to fetch (draft, live) | `live` |
| `--workspace string` | Workspace to get schemas from | `staging` |

## Examples

<CodeGroup>

```bash Basic Usage
# Generate TypeScript types from all enabled schemas in staging workspace
suprsend generate-types typescript --output-file types.ts

# Generate Go types from all enabled schemas in staging workspace
suprsend generate-types go --output-file types.go
```

```bash Advanced Usage
# Generate types from production workspace
suprsend generate-types typescript --output-file types.ts --workspace production

# Generate Go types with custom build flags
suprsend generate-types go --output-file types.go --build-flags "flag1,flag2"

# Generate Python types from staging workspace
suprsend generate-types python --output-file types.py --workspace staging

# Generate Kotlin types
suprsend generate-types kotlin --output-file types.kt --workspace production

# Generate Swift types
suprsend generate-types swift --output-file types.swift --workspace staging
```

</CodeGroup>
