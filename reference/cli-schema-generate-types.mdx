Generate strongly-typed programming language interfaces from SuprSend JSON schemas.  
Converts schemas into TypeScript, Go, Python, Kotlin, or Swift type definitions for type-safe development.

```bash
suprsend generate-types [flags] <output-file>
```

## Options

| Flag                | Description                                    | Default   |
| ------------------- | ---------------------------------------------- | --------- |
| `--build-flags string` | Flags to generate types in a certain way      | –         |
| `--mode string`     | Mode of schema to fetch                        | `live`    |
| `--workspace string` | Workspace to get schemas from                  | `staging` |
| `-h, --help`        | Show help for the command                      | –         |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--config` – Config file (default: `$HOME/.suprsend.yaml`)
* `--no-color` – Disable color output
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--service-token` – Service token for authentication
* `--verbosity` – Logging level

## Examples

Generate TypeScript types from live schemas:

```bash
suprsend generate-types types.ts
```

Generate Go types from staging workspace:

```bash
suprsend generate-types --workspace staging types.go
```

Generate Python types with custom build flags:

```bash
suprsend generate-types --build-flags "flag1,flag2" types.py
```
