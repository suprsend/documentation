The SuprSend CLI provides command-line tools for managing notification infrastructure. Use it to manage workflows, schemas, profiles, and integrate with AI agents.

## What You Can Do

* **Workflows** – Create, list, enable, disable, and sync notification workflows
* **Schemas** – List, pull, push, reset, commit, and generate types from schemas  
* **Profiles** – Manage multiple environments and authentication
* **AI Integration** – Use MCP tools for AI agent integration
* **Asset Sync** – Transfer assets between workspaces
