The **SuprSend CLI** is a command-line tool that enables developers to interact with SuprSend's notification infrastructure directly from the terminal. It provides programmatic access to SuprSend's management APIs, allowing you to manage workflows, schemas, users, and other resources within your SuprSend workspace.

## What the CLI Does

The SuprSend CLI helps you:

* **Manage Workflows** – Deploy, configure, and control notification workflows
* **Handle Schemas** – Manage notification template schemas with draft/live lifecycle
* **Configure Environments** – Switch between staging, production, and other workspaces
* **Synchronize Assets** – Transfer resources between different SuprSend workspaces
* **Generate Types** – Create programming language types from JSON schemas
* **Integrate with AI** – Use MCP tools for AI agent integration

## Key Benefits

* **Local Development** – Work with notification templates locally before deploying
* **Version Control** – Track changes to notification configurations in Git
* **CI/CD Integration** – Automate deployment of notification changes
* **Team Collaboration** – Share and review notification configurations
* **Environment Management** – Easily manage different configurations for staging and production
