---
title: Create or Update Preference Category
openapi: "POST /v1/{workspace}/preference_category/"
sidebarTitle: Create/Update Category
---

⚠️ This API call will **override existing categories** with whatever is passed in the request body. Recommended approach is to first fetch the current categories using (GET method)[(/reference/get-category)], modify the response as needed, and then send it back in the request body.
