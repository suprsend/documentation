Retrieve and display all notification schemas from your SuprSend workspace. This command fetches schema metadata from the management API, including schema definitions, enabled status, and validation rules. Provides visual loading feedback and supports multiple output formats for both interactive use and programmatic integration.

## Syntax

```bash
suprsend schema list [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |


## Examples

<CodeGroup>

```bash Basic Usage
# List schemas in staging workspace (default)
suprsend schema list

# List schemas in JSON format
suprsend schema list --output json
```

```bash Advanced Usage
# List schemas in production workspace
suprsend schema list --workspace production

# List schemas with YAML output
suprsend schema list --workspace staging --output yaml

# List schemas with verbose logging
suprsend schema list --verbosity debug
```

</CodeGroup>
