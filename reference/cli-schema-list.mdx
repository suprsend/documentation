Shows schema names, modes (draft/live), and other configuration details.

```bash
suprsend schema list [flags]
```

## Options

| Flag           | Description                         | Default |
| -------------- | ----------------------------------- | ------- |
| `-l, --limit`  | Max schemas to list                 | `20`    |
| `-m, --mode`   | Mode of schemas (`live` or `draft`) | `live`  |
| `-f, --offset` | Offset for pagination               | `0`     |
| `-h, --help`   | Show help for the command           | –       |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file path

## Examples

List first 20 schemas in staging workspace:

```bash
suprsend schema list
```

List schemas in JSON format:

```bash
suprsend schema list --output json
```

List draft schemas with pagination:

```bash
suprsend schema list --mode draft --limit 50 --offset 20
```
