Reset a live schema back to draft status in your SuprSend workspace. This command transitions the specified schema from live to draft state, deactivating it for production use while keeping it available for further development and testing.

<Note>
To promote a draft schema to live, use [`schema commit`](/reference/cli-schema-commit).
</Note>

## Syntax

```bash
suprsend schema reset <schema-slug> [flags]
```

**Arguments:**
- `<schema-slug>` - Name of the schema to reset (required)

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |

## Examples

<CodeGroup>

```bash Basic Usage
# Reset a schema to draft status
suprsend schema reset my-schema

# Reset schema in staging workspace (default)
suprsend schema reset notification-schema
```

```bash Advanced Usage
# Reset schema in production workspace
suprsend schema reset my-schema --workspace production

# Reset schema with JSON output
suprsend schema reset notification-schema --output json

# Reset schema with verbose logging
suprsend schema reset my-schema --verbosity debug
```

</CodeGroup>
