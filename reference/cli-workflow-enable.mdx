Set a workflow's activation status to enabled in a SuprSend workspace. This command makes a PATCH request to the management API endpoint to activate the specified workflow.

<Note>
To disable a workflow, use [`workflow disable`](/reference/cli-workflow-disable).
</Note>

## Syntax

```bash
suprsend workflow enable <workflow-key> [flags]
```

**Arguments:**
- `<workflow-key>` - Name of the workflow to enable (required)

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |

## Examples

<CodeGroup>

```bash Basic Usage
# Enable workflow in default workspace
suprsend workflow enable my-workflow-key

# Enable workflow with specific key
suprsend workflow enable user-signup
```

```bash Advanced Usage
# Enable workflow in production workspace
suprsend workflow enable my-workflow-key --workspace production

# Enable workflow in staging workspace
suprsend workflow enable order-confirmation --workspace staging
```

</CodeGroup>
