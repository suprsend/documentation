Activate a workflow in a SuprSend workspace.  
Enabling a workflow makes it active so it can start processing notifications.

```bash
suprsend workflow enable WORKFLOW_KEY [flags]
```

## Options

| Flag         | Description               | Default |
| ------------ | ------------------------- | ------- |
| `-h, --help` | Show help for the command | –       |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file path

## Examples

Enable a workflow in your default (staging) workspace:

```bash
suprsend workflow enable my-workflow-key
```

Enable a workflow in the production workspace:

```bash
suprsend workflow enable my-workflow-key --workspace production
```
