Agent lives on your SuprSend dashboard. Open it with `Cmd+/` (or `Ctrl+/`), ask in plain language, and it calls the right APIs against your workspace — looking up users, building templates, generating schemas, tracing a failed delivery, or pulling delivery analytics.

It's scoped to your workspace and SuprSend docs. Threads persist, so follow-ups don't need re-explanation.

<Warning>
  Agent is in **beta**. It's currently free - no usage limits, no charges. We'll announce pricing before moving to general availability.
</Warning>

---

## What Agent can do

<CardGroup cols={2}>
  <Card title="Query your workspace" icon="magnifying-glass">
    Ask anything about your data — users, preferences, workflows, tenants, lists, objects, events. Agent fetches the live state directly from your workspace.
  </Card>
  <Card title="Create assets" icon="plus">
    Build users, tenants, objects, lists, preference categories, and templates from a conversation. Wire channels and identities in the same thread you're prototyping in.
  </Card>
  <Card title="Generate schemas" icon="code">
    Describe an event payload in English and Agent drafts the schema, validates it against existing usage, and saves it to your workspace.
  </Card>
  <Card title="Debug delivery" icon="bug">
    Trace why a notification didn't land — channel availability, preference opt-outs, tenant overrides, category defaults, and execution logs all in one explanation.
  </Card>
  <Card title="Pull analytics" icon="chart-line">
    Delivery rates, engagement metrics, channel performance, segment breakdowns — ask and Agent returns the numbers with context.
  </Card>
  <Card title="Ask anything about SuprSend" icon="book">
    Concepts, integration steps, error meanings, best practices — Agent answers from the full SuprSend documentation without sending you to a different tab.
  </Card>
</CardGroup>

Agent also handles **translations**: update your English locale file and ask Agent to translate it into every configured language — it fetches the file, runs the translations, and commits the result without manual editing.

## What you can ask

A starter set of prompts, grouped by what you're trying to do. These work as-is — paste, edit identifiers, send.

### Analytics

```text
What were our email delivery and open rates last week?

Break down WhatsApp delivery by tenant for the last 30 days.

Which workflow had the highest unsubscribe rate this month?

Show me push notification engagement for tenant "acme-corp".
```

### Workflows and events

```text
Is the "payment-reminder" workflow active? What category does it use?

List all workflows in this workspace and summarize what each does.

Show me the schema for the "user-signed-up" event.

Trigger the "order-confirmation" workflow for user "jane@acme.com" with a sample payload.

Create a workflow that sends an email and falls back to SMS after 10 minutes.
```

### Users, preferences, and lists

```text
Show me the full profile of user "jane@acme.com".

Why isn't user "john@acme.com" getting emails?

Opt user "sarah@acme.com" out of the "product-updates" category.

What lists is "john@acme.com" part of?

Add "jane@acme.com" to "beta-testers" and subscribe her to "project-updates".
```

### Tenants and objects

```text
Show branding and config for tenant "enterprise-client".

Create tenant "Globex Corp" with logo and primary color "#1E40AF".

For tenant "acme-corp", turn off WhatsApp for all categories.

Who is subscribed to the "project-atlas" object?
```

### Templates and schemas

```text
Create an email template for "order-confirmation" with order ID, items, and total.

Generate an event schema for "subscription-renewed".

Draft a WhatsApp template body for payment failure with a retry link.
```

### Debugging

```text
Trace the last delivery to "john@acme.com" and explain what happened.

Why did this workflow execution stop at the digest node?

Which preference rule is blocking SMS for tenant "acme-corp"?
```

## Skills

Agent ships with built-in skills for the workflows you build most often. Each skill is a guided, multi-step interaction — Agent collects what it needs, drafts the asset, and commits on confirmation.

| Skill | What it does |
| --- | --- |
| **Workflow creation** | Ask for an outcome ("remind users 24h before trial ends, escalate to SMS if email bounces") and Agent assembles the workflow — channels, branches, delays, fallbacks — and lets you tweak before saving. |
| **Schema generation** | Describe an event in English; Agent infers the JSON schema, checks it against existing event payloads, and registers it. |
| **Template creation** | Draft email, SMS, push, WhatsApp, and inbox templates from a prompt. Agent fills variables, previews rendering, and saves to your workspace. |

## Bring your own token (BYOToken)

Prefer to run Agent on your own LLM bill? Add an OpenAI or Anthropic API key in **Settings → Agent → BYOToken**. Once configured, Agent uses your key for inference and you pay the provider directly — SuprSend credits cover only the workspace tool calls.

<Frame caption="Add your OpenAI or Anthropic API key under Settings → Agent → BYOToken.">
  {/* TODO: replace with screenshot of the BYOToken settings panel */}
  <img src="/images/agent-byotoken.png" alt="BYOToken settings" />
</Frame>

- Keys are encrypted at rest and never logged or shared across workspaces.
- Switch back to SuprSend-managed credits at any time — Agent falls back automatically if your key is removed or rate-limited.
- Provider model selection (e.g. GPT-4.1, Claude Opus) is configurable per workspace.

## Disabling Agent

Workspace admins can turn Agent off entirely from **Settings → Agent → Enable**. While disabled:

- The chat orb is hidden for every member of the workspace.
- All Agent tool calls are blocked at the API layer — including from MCP clients that share the same surface.
- Saved threads and history are preserved and reappear when Agent is re-enabled.

Use this to pause access during audits, sensitive launches, or while evaluating BYOToken setup.

## Tool reference

### Users

| Tool | Example prompt |
|---|---|
| `get_user` | Show me the full profile of user **jane@acme.com** |
| `create_user` | Create user **test-1** with email **test@demo.com** and name **joe** |
| `update_user` | Add email to user **jane@acme.com** and set her timezone to **America/New_York** |
| `get_user_preference` | Show me the notification preferences for **jane@acme.com** |
| `update_user_preference_category` | Opt user **sarah@acme.com** out of the **product-updates** category |
| `update_user_preference_channel` | Turn off SMS notifications entirely for **john@acme.com** |
| `get_user_list_subscriptions` | What lists is **john@acme.com** part of? |
| `get_user_object_subscriptions` | What objects is **john@acme.com** subscribed to? |

### Tenants

| Tool | Example prompt |
|---|---|
| `get_tenant` | Show me branding and config for tenant **enterprise-client** |
| `upsert_tenant` | Create tenant "Globex Corp" with logo `https://globex.com/logo.png` and primary color `#1E40AF` |
| `get_tenant_preference` | What are the default preferences for tenant **acme-corp**? |
| `update_tenant_preference_category` | For tenant **acme-corp**, turn off WhatsApp for all categories and disable **product-updates** entirely |

### Objects

| Tool | Example prompt |
|---|---|
| `get_object` | Show me the `project-atlas` object and how many subscribers it has |
| `create_object` | Create object `design-reviews` and subscribe user `jane@acme.com` to it |
| `update_object` | Set the description of `project-atlas` to "Atlas project notifications" |
| `get_object_preference` | What are the notification preferences for the `alerts-channel` object? |
| `update_object_preference_category` | Turn off push notifications for the `alerts-channel` object and opt it out of the `marketing` category |
| `update_object_preference_channel` | Disable email for the `alerts-channel` object |
| `get_object_subscriptions` | Who is subscribed to the `project-atlas` object? |
| `add_object_subscription` | Subscribe user `jane@acme.com` to `design-reviews` and set role `project manager` |

### Workflows and events

| Tool | Example prompt |
|---|---|
| `get_workflow` | Is the `payment-reminder` workflow active? What category does it use? |
| `list_workflows` | What workflows do I have? Summarize each one |
| `get_event_details` | Show me the schema for the `user-signed-up` event |

### Categories

| Tool | Example prompt |
|---|---|
| `get_preference_categories` | What categories do I have and what are their defaults? |
| `update_preference_category` | Add a new `product-updates` category with default opt-in settings for email and inbox channels |
| `commit_preference_category` | Commit the category changes to make them live |

### Translations

| Tool | Example prompt | Purpose |
|---|---|---|
| `get_translation` | Show me the French translation file | Fetch file by locale |
| `update_translation` | Add French translations for the `weekly-digest` category name and description | Upload or update file |
| `commit_translation` | Commit the translation updates | Commit draft changes to make them live |

### Lists

| Tool | Example prompt | Purpose |
|---|---|---|
| `add_user_to_list` | Add user `jane@acme.com` to the `beta-testers` list | Add user to list |
| `remove_user_from_list` | Remove `john@acme.com` from the `inactive-users` list | Remove user from list |

### Multi-step prompts

Agent handles multi-step tasks in a single conversation — chain actions together naturally.

| Example prompt |
|---|
| Create user `test-1` with email and SMS, add them to `beta-testers`, and subscribe them to `project-updates` |
| Give me a full audit of tenant `enterprise-client` - branding, preference overrides, and which categories are turned off |
| Move all subscribers from `old-project` object to `new-project` |
| Create a `weekly-digest` category under Promotional with opt-in default, then add French and Spanish translations |
| User `john@acme.com` says he's not getting emails. What's wrong? |
| Check if `payment-reminder` is active, what category it's linked to, and what the default preference is |
