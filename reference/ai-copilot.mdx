AI Copilot lives on your SuprSend dashboard. Ask it to look up a user, trace a missing notification, configure tenant preferences, or seed test data — it calls the right APIs and shows you the result.

It's scoped to your workspace and SuprSend docs. Each thread retains full conversation history, so follow-ups work without re-explaining context.

<Warning>
  Copilot is in **beta**. It's currently free — no usage limits, no charges. We'll announce pricing before moving to general availability.
</Warning>

---

## Copilot capabilities

<CardGroup cols={2}>
  <Card title="Manage users" icon="user">
    Look up profiles, create users with channels, update properties, check list and object memberships.
  </Card>
  <Card title="Configure preferences" icon="sliders">
    Read and update preferences at every level — category defaults, tenant overrides, user choices, object settings.
  </Card>
  <Card title="Set up tenants and objects" icon="building">
    Create tenants with branding, create subscribable objects, manage subscribers, inspect config.
  </Card>
  <Card title="Inspect workflows and events" icon="diagram-project">
    List workflows, check status, view linked categories, pull up event schemas.
  </Card>
  <Card title="Manage translations and lists" icon="language">
    Fetch, update, and commit locale files. Add or remove users from subscriber lists.
  </Card>
  <Card title="Debug delivery" icon="bug">
    Trace why a notification was suppressed — check channels, preference opt-outs, tenant overrides, and category defaults.
  </Card>
</CardGroup>

## Example prompts

### Users

| | Prompt |
|---|---|
| **Look up profile** | Show me the full profile of user `jane@acme.com` |
| **Create user** | Create user `test-1` with email `test@demo.com` and SMS `+14155551234` |
| **Update properties** | Add Slack channel `@jane-smith` to user `jane@acme.com` and set her timezone to `America/New_York` |
| **Check memberships** | What lists and objects is `john@acme.com` part of? |

### Preferences

| | Prompt |
|---|---|
| **View user preferences** | Show me the notification preferences for `jane@acme.com` |
| **Opt out of a category** | Opt user `sarah@acme.com` out of the `product-updates` category |
| **Block a channel** | Turn off SMS notifications entirely for `john@acme.com` |
| **Set category defaults** | Set the `product-updates` category default to opt-in with only email and inbox channels |
| **Tenant overrides** | For tenant `acme-corp`, turn off WhatsApp for all categories and disable `product-updates` entirely |
| **Object preferences** | Turn off push notifications for the `alerts-channel` object and opt it out of the `marketing` category |

### Tenants and objects

| | Prompt |
|---|---|
| **Look up tenant** | Show me branding and config for tenant `enterprise-client` |
| **Create tenant** | Create tenant "Globex Corp" with logo `https://globex.com/logo.png` and primary color `#1E40AF` |
| **Look up object** | Show me the `project-atlas` object and how many subscribers it has |
| **Create object** | Create object `design-reviews` and subscribe user `jane@acme.com` to it |
| **Update object** | Set the description of `project-atlas` to "Atlas project notifications" |
| **List subscribers** | Who is subscribed to the `project-atlas` object? |

### Workflows and events

| | Prompt |
|---|---|
| **List workflows** | What workflows do I have? Summarize each one |
| **Inspect workflow** | Is the `payment-reminder` workflow active? What category does it use? |
| **Event schema** | Show me the schema for the `user-signed-up` event |
| **Verify chain** | Check if `payment-reminder` is active, what category it's linked to, and what the default preference is |

### Translations and lists

| | Prompt |
|---|---|
| **Fetch translation** | Show me the French translation file |
| **Update translations** | Add French translations for the `weekly-digest` category name and description |
| **Add to list** | Add user `jane@acme.com` to the `beta-testers` list |
| **Remove from list** | Remove `john@acme.com` from the `inactive-users` list |

### Multi-step

| | Prompt |
|---|---|
| **Onboard test user** | Create user `test-1` with email and SMS, add them to `beta-testers`, and subscribe them to `project-updates` |
| **Audit tenant** | Give me a full audit of tenant `enterprise-client` — branding, preference overrides, and which categories are turned off |
| **Migrate subscribers** | Move all subscribers from `old-project` object to `new-project` |
| **Category + translations** | Create a `weekly-digest` category under Promotional with opt-in default, then add French and Spanish translations |
| **Debug delivery** | User `john@acme.com` says he's not getting emails. What's wrong? |

## Tool reference

<Tabs>
  <Tab title="Users">
    | Tool | Purpose |
    |---|---|
    | `get_user` | Fetch profile, channels, properties |
    | `create_user` | Create user with channels |
    | `update_user` | Update profile or channels |
    | `get_user_preference` | Get category and channel preferences |
    | `update_user_preference_category` | Opt in/out of a category |
    | `update_user_preference_channel` | Restrict a channel globally |
    | `get_user_list_subscriptions` | Lists the user belongs to |
    | `get_user_object_subscriptions` | Objects the user subscribes to |
  </Tab>

  <Tab title="Tenants">
    | Tool | Purpose |
    |---|---|
    | `get_tenant` | Fetch config and branding |
    | `upsert_tenant` | Create or update tenant |
    | `get_tenant_preference` | Tenant default preferences |
    | `update_tenant_preference_category` | Override category default for tenant users |
  </Tab>

  <Tab title="Objects">
    | Tool | Purpose |
    |---|---|
    | `get_object` | Fetch profile and subscriber count |
    | `create_object` | Create object |
    | `update_object` | Update properties or channels |
    | `get_object_preference` | Object preferences across categories |
    | `update_object_preference_category` | Update preference for a category |
    | `update_object_preference_channel` | Restrict a channel for object |
    | `get_object_subscriptions` | List subscribers |
    | `add_object_subscription` | Subscribe user to object |
  </Tab>

  <Tab title="Workflows">
    | Tool | Purpose |
    |---|---|
    | `get_workflow` | Fetch config and status |
    | `list_workflows` | List all workflows |
    | `get_event_details` | Event schema and metadata |
  </Tab>

  <Tab title="Categories">
    | Tool | Purpose |
    |---|---|
    | `get_preference_categories` | All categories and defaults |
    | `update_preference_category` | Update category default |
    | `commit_preference_category` | Commit draft changes to make them live |
  </Tab>

  <Tab title="Translations">
    | Tool | Purpose |
    |---|---|
    | `get_translation` | Fetch file by locale |
    | `update_translation` | Upload or update file |
    | `commit_translation` | Commit draft changes to make them live |
  </Tab>

  <Tab title="Lists">
    | Tool | Purpose |
    |---|---|
    | `add_user_to_list` | Add user to list |
    | `remove_user_from_list` | Remove user from list |
  </Tab>
</Tabs>
