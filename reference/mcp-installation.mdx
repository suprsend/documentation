<Note>
**The SuprSend MCP server is in Beta**. We recommend starting with a development workspace before rolling it out in production.
</Note>

## Step 1: Get Your Service Token

Before setting up MCP, you need a service token from SuprSend:

1. Go to **[SuprSend Dashboard → Service Tokens](https://app.suprsend.com/en/account-settings/service-tokens)**
2. Create a new service token
3. Copy the token for use in the next steps

## Step 2: Choose Your Setup Method

<Tabs>
  <Tab title="🎯 IDE Setup (Recommended)">
    The IDE manages the MCP server automatically. No CLI installation required.

    <Tabs>
      <Tab title="🎯 Cursor">
        ## Cursor Setup

        <Card title="Option 1: One-Click Install (Recommended)" icon="rocket">
          [![Install MCP Server](https://cursor.com/deeplink/mcp-install-dark.svg)](https://cursor.com/install-mcp?name=suprsend&config=eyJjb21tYW5kIjoic3VwcnNlbmQgc3RhcnQtbWNwLXNlcnZlciAtLXNlcnZpY2UtdG9rZW4gWU9VUi1TRVJWRVItVE9LRU4ifQ%3D%3D)

          <br/>

          Once you click, you'll be taken to the Cursor MCP settings.

          Click "Install" and you'll see the SuprSend MCP server installed.

          You can start using the SuprSend MCP.
        </Card>

        <Card title="Option 2: Manual Setup" icon="wrench">
          <Steps>
            <Step title="Open Cursor Settings">
              Go to Cursor → Settings → MCP and Integrations
            </Step>
            <Step title="Add MCP Server">
              Click "New MCP Server" and add this configuration:

              ```json
              {
                "mcpServers": {
                  "suprsend": {
                    "command": "suprsend",
                    "args": ["start-mcp-server"],
                    "env": {
                      "SUPRSEND_SERVICE_TOKEN": "your_service_token_here"
                    }
                  }
                }
              }
              ```

              Replace `your_service_token_here` with your token from Step 1.
            </Step>
            <Step title="Complete Setup">
              Restart Cursor to activate the MCP server.
            </Step>
          </Steps>
        </Card>
      </Tab>

      <Tab title="🤖 Claude">
        ## Claude Desktop Setup

        <Steps>
          <Step title="Open Claude Settings">
            Go to Claude Settings → Developer Section
          </Step>
          <Step title="Edit MCP Config">
            Click Edit Config under Local MCP Servers
          </Step>
          <Step title="Add Configuration">
            Add this configuration:

            ```json
            {
              "mcpServers": {
                "suprsend": {
                  "command": "suprsend",
                  "args": ["start-mcp-server"],
                  "env": {
                    "SUPRSEND_SERVICE_TOKEN": "your_service_token_here"
                  }
                }
              }
            }
            ```

            Replace `your_service_token_here` with your token from Step 1.
          </Step>
          <Step title="Complete Setup">
            Refresh the MCP Settings by clicking the refresh button.
          </Step>
        </Steps>
      </Tab>

      <Tab title="🌊 Windsurf">
        ## Windsurf Setup

        <Steps>
          <Step title="Open Windsurf Settings">
            Go to Windsurf settings → Extensions
          </Step>
          <Step title="Add MCP Configuration">
            Add this configuration:

            ```json
            {
              "suprsend": {
                "command": "suprsend",
                "args": ["start-mcp-server"],
                "env": {
                  "SUPRSEND_SERVICE_TOKEN": "your_service_token_here"
                },
                "name": "SuprSend MCP Server"
              }
            }
            ```

            Replace `your_service_token_here` with your token from Step 1.
          </Step>
          <Step title="Complete Setup">
            Refresh the MCP Settings by clicking the refresh button.
          </Step>
        </Steps>
      </Tab>
    </Tabs>
  </Tab>

  <Tab title="💻 CLI Setup">
    You manually run the MCP server from command line, then connect your AI assistant to the running server.

    <Steps>
      <Step title="Install SuprSend CLI">
        **macOS (Homebrew):**
        ```bash
        brew tap suprsend/tap
        brew install --cask suprsend
        ```

        See other installation methods: **[<u>CLI Installation Guide</u>](/reference/cli-installation)**
      </Step>
      <Step title="Authenticate with SuprSend">
        Choose your preferred authentication method:

        **Option 1: Environment Variable (Best for CI/CD and scripts)**
        ```bash
        export SUPRSEND_SERVICE_TOKEN="your_service_token_here"
        ```

        **Option 2: CLI Profile (Best for local development)**
        ```bash
        suprsend profile add --name default --service-token "your_service_token_here"
        suprsend profile use --name default
        ```

        See all methods: **[CLI Authentication Guide](/reference/cli-authentication)**
      </Step>
      <Step title="Start MCP Server">
        **Basic Start:**
        ```bash
        suprsend start-mcp-server
        ```

        **Advanced Options (Optional):**
        ```bash
        # Start with specific tools using SSE transport
        suprsend start-mcp-server --tools "users,tenants" -t sse
        ```

        **Available Flags:**
        - `--tools` – restricts which tools are available (recommended)
        - `--transport` – transport to use (stdio or sse)
      </Step>
      <Step title="Connect AI Assistant">
        Configure your AI assistant to connect to the running MCP server.
      </Step>
    </Steps>
  </Tab>
</Tabs>
