The SuprSend plugin is the recommended way to connect an AI client to SuprSend. One install adds the hosted [MCP server](/reference/mcp-overview) (`https://mcp.suprsend.com/mcp`) and a small `suprsend` skill that tells the agent which tool to call, and when to read SuprSend's detailed skills from the server. Nothing runs on your machine; you sign in with your SuprSend account.

<Note>
  You don't need to install [Agent Skills](/reference/agent-skills) as well. The server serves the workflow, template, SQL and docs skills, and the plugin tells the agent to read them. The only skill the server doesn't serve is [`suprsend-cli`](/reference/agent-skill-cli). Add it only if your agent runs the SuprSend CLI:

  ```bash
  npx skills add https://github.com/suprsend/skills --skill suprsend-cli
  ```
</Note>

Two plugin packages cover every supported client:

| Plugin | Clients |
|---|---|
| **`suprsend/claude-plugin`** | Claude on the web, Desktop, mobile, Cowork, and Claude Code. |
| **`suprsend/agent-plugin`** | VS Code, GitHub Copilot CLI, Codex, Cursor, Kiro, and other [Agent Plugins 1.0.0](https://agent-plugins.org) clients. |

<Tip>
  No API key, no service token: you sign in with your SuprSend account (OAuth). Admins get every tool; members get the read-only tools. The agent sees only the workspaces your account can open.
</Tip>

## Install

<Tabs>

<Tab title="Claude Code">
```
/plugin marketplace add suprsend/claude-plugin
/plugin install suprsend@suprsend
```

Then sign in once: run `/mcp`, select **suprsend**, and choose **Authenticate**.

A plugin that you install on claude.ai also appears in Claude Code as a synced plugin.
</Tab>

<Tab title="Claude on web / Desktop / mobile / Cowork">
1. Open **Customize → Plugins → Add → Add marketplace**, and enter `suprsend/claude-plugin`.
2. Install the **suprsend** plugin.
3. Open the plugin's **Connectors** tab, and connect **suprsend**. Sign in with your SuprSend account.

On Team and Enterprise plans, an owner may need to allow the connector first.
</Tab>

<Tab title="VS Code">
<Note>
  VS Code [Agent Plugins](https://code.visualstudio.com/docs/copilot/customization/agent-plugins) need the `chat.plugins.enabled` setting to be on. Your organization may manage this setting.
</Note>

1. Open the Command Palette (`Cmd/Ctrl + Shift + P`).
2. Run **`Chat: Install Plugin From Source`**.
3. Enter the URL:

```
https://github.com/suprsend/agent-plugin
```

VS Code asks you to sign in when the server starts.
</Tab>

<Tab title="GitHub Copilot CLI">
Requires Copilot CLI 1.0.83 or later.

```bash
copilot plugin install suprsend/agent-plugin
```

Copilot CLI asks you to sign in on first use.
</Tab>

<Tab title="Codex">
```bash
codex plugin marketplace add suprsend/agent-plugin
```

Install **suprsend** from the marketplace, then sign in:

```bash
codex mcp login suprsend
```
</Tab>

<Tab title="Cursor">
On Cursor's Teams and Enterprise plans, an admin adds the plugin as a team marketplace: **Dashboard** → **Plugins & MCPs** → **Add Marketplace** → **Import from Repo**, and paste:

```
https://github.com/suprsend/agent-plugin
```

Then install **suprsend** from **Customize**. Cursor asks you to sign in when the server first connects.

On other Cursor plans, add the MCP server directly. See the [Cursor quickstart](/reference/mcp-quickstart-cursor).
</Tab>

<Tab title="Kiro">
**Powers** → **Add Custom Power** → **Import power from GitHub** →

```
https://github.com/suprsend/agent-plugin
```

Kiro asks you to sign in on first use.
</Tab>

</Tabs>

## Limit the scope

The plugin always connects to the default URL, which can reach every workspace and tool your role allows. To pin one workspace or a set of tool groups, add the server yourself with a custom URL instead of installing the plugin:

- `https://mcp.suprsend.com/mcp/staging` — only the `staging` workspace.
- `https://mcp.suprsend.com/mcp?tools=users_*,lists_*` — only the listed tool groups.

See the [tool list](/reference/mcp-tool-list) for the full group reference.

## Moving from `suprsend/claude-code-plugin`

`suprsend/claude-plugin` replaces the older `suprsend/claude-code-plugin` marketplace. The old marketplace forwards to the new plugin, so existing users can move with:

```
/plugin marketplace update suprsend-marketplace
```

For a clean setup, remove the old marketplace and add `suprsend/claude-plugin`. The old repository is archived.

## Updates

The detailed skills live on the server, so the agent always reads the current version. The plugin itself changes only when a new version is published. In Claude Code, third-party marketplaces don't update automatically by default; run `/plugin marketplace update suprsend` to get a new version.

## Usage examples

Once the plugin is installed and signed in, prompt the agent in natural language:

```
List my SuprSend workspaces.

Why did user usr_8f3k2m not get the "order-confirmed" email yesterday?

How many emails did we send per day last week, in production?

Opt user usr_8f3k2m out of the newsletter category and stop SMS for them.

Make the static list beta-testers exactly the users in this CSV.

Create a workflow that sends the "welcome" email when the event USER_SIGNUP comes in.
```

### Workflow management

```
> List all my workflows

> Show the "order-confirmed" workflow and explain each node

> Which workflows are currently disabled?

> Create a workflow called "welcome-series" that:
  1. Sends a welcome email immediately
  2. Waits 24 hours
  3. Sends a follow-up SMS if the email wasn't opened
  4. Falls back to push notification after 2 more hours
```

### Delivery analytics

```
> Show me the email delivery rate by tenant for the last 7 days as a line chart.

> Which workflows failed most often this week?
```

### Template management

```
> What email templates do I have?

> Show me the variables used in the "welcome-email" template

> Publish the "quote-expiring" template so the new email variant goes live.
```

### Debugging

```
> Why might my "payment-reminder" workflow not be triggering?

> Check if the "welcome-series" workflow is enabled

> What events are configured in my workspace? I think I might be
  missing the "user-signup" event.
```

## CI/CD

The plugin and MCP server are for interactive sessions with a person signed in. For CI/CD pipelines, use the [SuprSend CLI](/reference/cli-intro) with a service token; see [CI/CD with the SuprSend CLI](/reference/cli-ci-cd). If a coding agent writes or runs those CLI commands for you, add the [`suprsend-cli`](/reference/agent-skill-cli) skill.

## Troubleshooting

<AccordionGroup>
  <Accordion title="OAuth sign-in loop">
    If the browser keeps redirecting without completing sign-in, close every AI-client window, clear your SuprSend session at [app.suprsend.com](https://app.suprsend.com), and reconnect. For Claude Code, run `/mcp`, select **suprsend**, and re-authenticate.
  </Accordion>

  <Accordion title="Plugin marketplace not found">
    Add the marketplace from the repository `suprsend/claude-plugin` or `suprsend/agent-plugin`. In Claude Code, the marketplace is named `suprsend` (the old one was `suprsend-marketplace`). The old `suprsend/claude-code-plugin` marketplace forwards to the new one; if you still see 404s, remove the old marketplace and add the new one directly.
  </Accordion>

  <Accordion title="Server shows disconnected">
    Check the workspace slug in the URL. It must match a workspace in your SuprSend account exactly, for example `staging`, not the workspace's display name. A slug that doesn't exist fails with `403 workspace_forbidden`. To see your slugs, re-add the server without a slug and ask: "List my SuprSend workspaces."
  </Accordion>
</AccordionGroup>

## Uninstall

<Tabs>
  <Tab title="Claude Code">
    ```
    /plugin uninstall suprsend@suprsend
    /plugin marketplace remove suprsend
    ```
  </Tab>

  <Tab title="VS Code">
    Right-click the `suprsend` plugin in **Agent Plugins → Installed** and choose **Uninstall**.
  </Tab>

  <Tab title="Other clients">
    Remove the plugin from the client's plugin or MCP settings. Removing the plugin does not sign you out of SuprSend; sign out at [app.suprsend.com](https://app.suprsend.com) if you need to end the OAuth session too.
  </Tab>
</Tabs>
