## Available Tools

Here's a complete list of all tools available in the MCP server. You can use these to query documentation, manage users, objects, tenants, preferences, and workflows.

<Note>
All tools listed below are also available in the SuprSend AI Copilot.
</Note>

| Type | Tool Name | Description |
|------|-----------|-------------|
| documentation | `documentation.search` | Search SuprSend docs for relevant topics or examples |
| documentation | `documentation.fetch` | Fetch the full content of a documentation page by URI |
| users | `users.get` | Get a user's profile, channel addresses, and properties |
| users | `users.upsert` | Create a new user or update an existing one |
| users | `users.get_preferences` | Get a user's notification preferences across categories and channels |
| users | `users.update_preferences` | Update a user's preference for a specific notification category |
| users | `users.update_channel_preference` | Update global channel-level restrictions for a user |
| users | `users.get_list_subscriptions` | Get all lists a user is part of |
| users | `users.get_objects_subscriptions` | Get all objects a user is subscribed to |
| tenants | `tenants.get` | Get a tenant's configuration, branding, and properties |
| tenants | `tenants.get_all` | List all tenants in the workspace |
| tenants | `tenants.upsert` | Create a new tenant or update an existing one |
| tenants | `tenants.get_preferences` | Get default preference settings for all categories under a tenant |
| tenants | `tenants.update_preferences` | Update tenant-level preference overrides for a notification category |
| objects | `objects.get` | Get an object's profile, channels, and subscriber count |
| objects | `objects.upsert` | Create a new object or update an existing one |
| objects | `objects.get_preferences` | Get an object's notification preferences across categories and channels |
| objects | `objects.update_preferences` | Update an object's preference for a specific notification category |
| objects | `objects.update_channel_preference` | Update global channel-level restrictions for an object |
| workflows | `workflows.list` | List all workflows in the workspace |


## Giving scoped access to tools in your MCP setup

By default, the MCP server exposes all tools, but you might not want to grant your AI agent access to everything—especially in production environments. You can control which tools are available by using the `--tools` flag when starting the MCP server, ensuring your agent only interacts with the resources it actually needs.

The `--tools` flag accepts one or more tool identifiers in the format `tool_type.tool`. You can also use a wildcard `(*)` to enable all tools of a type. For example, `users.*` will allow access to all user-related tools, while `users.get_preferences` will expose only that single tool.

Here's an example of how to pass tool configuration:

```json
{
  "suprsend": {
    "command": "suprsend",
    "args": [
      "start-mcp-server",
      "--tools", "users.upsert,users.get,tenants.*"
    ],
    "name": "SuprSend MCP Server"
  }
}
```
