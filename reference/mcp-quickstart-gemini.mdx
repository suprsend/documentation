<Note>
  **Beta — launched 2026-10-08.** The hosted SuprSend MCP server is in Beta. The endpoint, auth flow, and tool list may still change before general availability.
</Note>

Add the hosted SuprSend MCP server to Gemini CLI so your agent can drive your SuprSend account — manage workflows, templates, broadcasts, preferences, and query delivery analytics in natural language.

<Steps>
  <Step title="Open the Gemini settings file">
    Edit `~/.gemini/settings.json`. Create it if it doesn't exist.
  </Step>

  <Step title="Add the SuprSend MCP server">
    ```json
    {
      "mcpServers": {
        "suprsend": {
          "httpUrl": "https://mcp.suprsend.com/mcp"
        }
      }
    }
    ```

    The field name is `httpUrl` — not `url` or `transport`. To pin a workspace, use `https://mcp.suprsend.com/mcp/staging`.

    Optional fields on the same object:

    | Field | Default | What it does |
    |---|---|---|
    | `headers` | `{}` | Extra HTTP headers; supports `$ENV_VAR` interpolation. |
    | `timeout` | `600000` (ms) | Per-call timeout. |
    | `trust` | `false` | Trust the server to skip per-tool confirmation prompts. |
    | `includeTools` | all | Allowlist of tool names Gemini will expose. |
    | `excludeTools` | none | Denylist of tool names. |
    | `oauth` | — | OAuth config overrides (Gemini discovers WorkOS automatically for SuprSend). |

    See the [Gemini CLI MCP docs](https://github.com/google-gemini/gemini-cli/blob/main/docs/tools/mcp-server.md) for the full field list.
  </Step>

  <Step title="Sign in with your SuprSend account">
    On the first tool call, Gemini CLI opens a browser window for WorkOS sign-in. Sign in with the SuprSend account that has access to the workspace you want to reach. Your role (admin or member) decides which tools you see.
  </Step>

  <Step title="Verify the connection">
    In a Gemini CLI session, try:

    ```
    List all workflows in my SuprSend workspace.
    ```

    If the server is connected and signed in, Gemini calls `workflows.list` and returns your workflows.
  </Step>
</Steps>

<Note>
  Gemini Code Assist (the IDE extension) reads the same `~/.gemini/settings.json` file, so the server is available there too once you've added it.
</Note>

<Tip>
  Scope the agent's reach by appending `?tools=` to the URL — for example `https://mcp.suprsend.com/mcp?tools=users.*,data.*` — or by setting `includeTools` locally in the Gemini config. See the [tool list](/reference/mcp-tool-list) for group names.
</Tip>
