Any AI client — Claude, ChatGPT, Cursor, VS Code with GitHub Copilot, Codex, Gemini, Windsurf — can now drive your SuprSend account over MCP. Manage users, lists, workflows, templates, broadcasts, preferences, messages, and delivery analytics in natural language, without opening the dashboard or writing SDK code.

## How it works

The SuprSend MCP server is a remote Streamable HTTP server. Your AI client connects directly to a hosted endpoint — there is nothing to install locally and no CLI to run.

- **Endpoint:** `https://mcp.suprsend.com/mcp`
- **Protocol:** built for MCP spec `2026-07-28`. Clients built against the 2025 spec also connect, but they do not get the `skills/list` and `skills/get` methods.
- **Workspace scoping:** append the workspace slug to the URL path to pin the connection — for example `https://mcp.suprsend.com/mcp/staging`. Without a slug, the server picks the workspace it finds first.
- **Tool scoping:** add a `?tools=` query to limit which tool groups the client sees — for example `https://mcp.suprsend.com/mcp?tools=users.*,data.*`. Scope can only reduce access, never widen it.

### Authentication

Sign in with your SuprSend account. When your AI client connects for the first time, it opens a browser window and the SuprSend MCP server runs an OAuth handshake through WorkOS. After sign-in, your SuprSend role decides what the agent can do:

- **Members** see only read tools.
- **Admins** see every tool, including the ones that send real notifications.

OAuth via WorkOS is the only supported auth path today. JWT bearer tokens for programmatic agents are coming soon.

### MCP Apps and Skills

Hosts that implement the MCP Apps extension get richer output than plain text:

- **`data.query`** results render as a chart (metric, line, bar, stacked bar, or pie) or as a table with a Refresh button.
- **`messages.get_content`** renders an actual message preview — email, Inbox, SMS, and push — with images and links off and OTPs or link queries masked. Slack messages render as JSON.

Clients that implement the MCP Skills extension get four SuprSend Skills on top of the tool list:

- `suprsend-semantic-layer` — maps your workspace concepts (tenants, categories, channels) to data queries.
- `suprsend-template-schema` — the full template schema for every channel.
- `suprsend-workflow-schema` — the full workflow node schema.
- `suprsend-docs-support` — pulls answers from SuprSend's docs.

### Easier install: the SuprSend plugins

Two plugin packages wrap the hosted server install so your client picks it up in one step:

- **`suprsend/claude-plugin`** — for Claude on web, Desktop, mobile, Cowork, and Claude Code.
- **`suprsend/agent-plugin`** — for VS Code, GitHub Copilot CLI, Codex, Cursor, Kiro, and other Agent Plugins 1.0.0 clients.

Both plugins ship a config that connects to `https://mcp.suprsend.com/mcp` — nothing runs on your machine. The per-client quickstarts above include the plugin command alongside the manual MCP config.
