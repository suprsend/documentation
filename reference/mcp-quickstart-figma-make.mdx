Custom connectors need a paid Figma plan.

## Set up the connection

<Steps>
  <Step title="Open Connectors">
    In the Figma Make prompt box, click **+** and select **Add context**. Then select **Connectors** in the left panel.

    <Frame>
      <img src="/images/mcp-figma-add-context.png" alt="Figma Make prompt box with the + menu open and Add context highlighted" />
    </Frame>
  </Step>

  <Step title="Create the connector">
    Under **Created by you**, click **Create connector**.

    Enter `SuprSend` as the **Name**. Upload an icon and add a **Tagline** and **Description** if you like, then click **Next**.

    <Frame>
      <img src="/images/mcp-figma-connector-details.png" alt="Create connector step 1 with Icon, Name, Tagline and Description fields" />
    </Frame>
  </Step>

  <Step title="Add the server URL">
    Paste `https://mcp.suprsend.com/mcp` into **MCP server URL**. Leave **Advanced settings** as they are, and click **Create**.

    <Frame>
      <img src="/images/mcp-figma-connector-url.png" alt="Create connector step 2 with the SuprSend MCP server URL entered" />
    </Frame>
  </Step>

  <Step title="Sign in with your SuprSend account">
    The SuprSend connector now shows under **Created by you**. Click **Connect** and sign in with your SuprSend account. The agent can't do more than your role allows: admins get every tool, members get the read-only tools.

    <Frame>
      <img src="/images/mcp-figma-connect.png" alt="SuprSend connector card under Created by you with a Connect button" />
    </Frame>
  </Step>

  <Step title="Choose the tools">
    Figma turns write tools off by default. Turn on the ones you need, such as `templates_upsert` and `templates_publish`, and set each to **Ask to run** or **Always run**. Leave send tools off unless you want to send test notifications from Figma.
  </Step>

  <Step title="Verify the connection">
    In a chat, ask:

    ```
    List my SuprSend workspaces.
    ```

    Figma answers with your SuprSend workspaces.
  </Step>
</Steps>

## Pin a workspace and restrict tools

By default, Figma Make can use every workspace and tool your role allows. To keep it on one workspace, or to give it only the tools a job needs, use one of these URLs as the **MCP server URL**:

- **Pin a workspace** by adding its slug to the path. The agent then can't switch to another workspace:

  ```
  https://mcp.suprsend.com/mcp/staging
  ```

- **Restrict tools** with `?tools=`, a comma-separated list of tool names or groups:

  ```
  https://mcp.suprsend.com/mcp/staging?tools=users_*,data_*
  ```

See [Scope the connection](/reference/mcp-overview#scope-the-connection) for every URL pattern, and the [tool list](/reference/mcp-tool-list) for every tool.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Server shows disconnected or refuses the connection">
    Check the workspace slug in the URL. It must match a workspace in your SuprSend account exactly, for example `staging`, not the workspace's display name. A slug that doesn't exist fails with `403 workspace_forbidden`. To see your slugs, remove the slug, reconnect, and ask: "List my SuprSend workspaces."
  </Accordion>
</AccordionGroup>
