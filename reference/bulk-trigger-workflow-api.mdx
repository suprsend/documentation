<Note>
  This page documents the **bulk variant** of the workflow trigger endpoint. To trigger workflows in bulk, send a JSON **array** of workflow trigger objects (instead of a single object) to `POST /trigger/`.

  - Maximum **100 workflow records** per request
  - Maximum **800 KB** total request body size
  - Email attachments (`data.$attachments`) are supported

  For a single workflow trigger, refer to the [Trigger Workflow](/reference/trigger-workflow-api) reference page (same endpoint, single object body).
</Note>
