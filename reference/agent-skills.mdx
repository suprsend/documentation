## What are Agent Skills?

Agent Skills are Markdown-based knowledge packages that you install directly into your AI coding agent — Cursor, Claude Code, GitHub Copilot, Amp, Cline, and others. Once installed, your agent automatically loads the right SuprSend knowledge when it detects you're working on a relevant task.

Without skills, agents guess at SuprSend's workflow schema, CLI flags, and API surface — and get things wrong. With skills, they have the actual spec.

---

## Installation

### Prerequisites

- Node.js and `npx` available in your terminal
- At least one compatible AI coding agent installed

### Install all skills

```bash
npx skills add suprsend/skills
```

The CLI detects which agents are installed on your machine and prompts you to choose targets. You can install project-scoped (committed to your repo) or globally.

<Tip>
  **Commit skills to your repo.** Checking in the installed skill files means every developer on your team gets the same agent behavior — no per-person setup required.
</Tip>

### Install a single skill

```bash
npx skills add https://github.com/suprsend/skills --skill suprsend-workflow-schema
npx skills add https://github.com/suprsend/skills --skill suprsend-cli
npx skills add https://github.com/suprsend/skills --skill suprsend-docs-support
```

### Where skills are installed

The installer handles directory placement automatically based on the agent you select:

| Agent | Skills directory |
|---|---|
| Amp, Cursor, Cline, Codex, Copilot, Warp, Kimi CLI, OpenCode, and more | `.agents/skills/` |
| Claude Code | `.claude/skills/` |
| Continue | `.continue/skills/` |
| Augment | `.augment/skills/` |

## How skills work

Skills follow the [agentskills.io](https://agentskills.io/specification) progressive disclosure model — keeping context usage lean while making full depth available when needed:

1. **At startup** — the skill name and description (~100 tokens each) are loaded so the agent knows what's available
2. **On activation** — when the agent detects a relevant task, it loads the full `SKILL.md` instructions
3. **On demand** — detailed reference files (per-node schema, per-command docs) load only when the agent needs them

## End-to-end example

Here's what a complete agent session looks like with all three skills installed:

**1. Describe the workflow in plain English**
> "Build a document access request notification. When a user requests access, notify the document owner via email immediately. If no response in 24 hours, send a Slack follow-up."

**2. Agent generates valid workflow JSON**

Using `suprsend-workflow-schema`, the agent produces a complete workflow definition with correct `node_type` values, branch conditions, delay config, and channel nodes.

**3. Push to SuprSend**

```bash
suprsend workflow push ./workflows/document-access-request.json
```

Using `suprsend-cli`, the agent knows the exact command and flags.

**4. Workflow is live**

Available immediately at [app.suprsend.com](https://app.suprsend.com) — no manual dashboard work needed.

## Improving agent output

After completing a task, ask your agent to self-evaluate:

```
In generating this workflow, retrospect what information could have helped
you to one-shot it and is missing in the available SuprSend skills.
```

Share the output with the team — it directly informs what gets added to the skills next.
