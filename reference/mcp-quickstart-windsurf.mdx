Windsurf is now part of Devin. Add SuprSend in Devin's web app or in the Devin CLI.

## Set up the connection

<Tabs>

<Tab title="Devin">

<Steps>
  <Step title="Open the MCP settings">
    In Devin, go to **Customize → MCPs**, then click **Add MCP** → **New MCP**.

    <Frame>
      <img src="/images/mcp-devin-add-mcp.png" alt="Devin Customize page on the MCPs tab, with the Add MCP menu open and New MCP highlighted" />
    </Frame>
  </Step>

  <Step title="Add the SuprSend MCP server">
    Fill in the form:

    - **Server name:** `SuprSend`
    - **Transport type:** HTTP
    - **Server URL:** `https://mcp.suprsend.com/mcp`
    - **Authentication:** OAuth

    Click **Add**.

    <Frame>
      <img src="/images/mcp-devin-new-mcp.png" alt="Devin New MCP form with Server name SuprSend, Transport type HTTP, Server URL https://mcp.suprsend.com/mcp and Authentication OAuth" />
    </Frame>
  </Step>

  <Step title="Confirm the integration">
    Devin shows a security notice. Check **I understand and want to proceed**, then click **Add**.

    <Frame>
      <img src="/images/mcp-devin-enable-integration.png" alt="Devin Enable MCP integration dialog with a security notice and the I understand and want to proceed checkbox" />
    </Frame>
  </Step>

  <Step title="Sign in with your SuprSend account">
    Devin opens your browser. Sign in with your SuprSend account. Your role decides the tools: admins get every tool, and members get read-only tools. Each member of your Devin organization signs in with their own account.
  </Step>

  <Step title="Verify the connection">
    In a new Devin session, ask:

    ```
    List my SuprSend workspaces.
    ```

    Devin answers with your SuprSend workspaces.
  </Step>
</Steps>

</Tab>

<Tab title="Devin CLI">

<Steps>
  <Step title="Add the SuprSend MCP server">
    ```bash
    devin mcp add suprsend https://mcp.suprsend.com/mcp
    ```
  </Step>

  <Step title="Sign in with your SuprSend account">
    ```bash
    devin mcp login suprsend
    ```

    Devin opens your browser. Sign in with your SuprSend account. Your role decides the tools: admins get every tool, and members get read-only tools.
  </Step>

  <Step title="Verify the connection">
    In a Devin CLI session, ask:

    ```
    List my SuprSend workspaces.
    ```

    Devin answers with your SuprSend workspaces.
  </Step>
</Steps>

</Tab>

</Tabs>

## Pin a workspace and restrict tools

By default, Devin can use every workspace and tool your role allows. To keep it on one workspace, or to give it only the tools a job needs, use one of these URLs as the **Server URL** in Devin, or in `devin mcp add`:

- **Pin a workspace** by adding its slug to the path. The agent then can't switch to another workspace:

  ```
  https://mcp.suprsend.com/mcp/staging
  ```

- **Restrict tools** with `?tools=`, a comma-separated list of tool names or groups:

  ```
  https://mcp.suprsend.com/mcp/staging?tools=users_*,data_*
  ```

See [Scope the connection](/reference/mcp-overview#scope-the-connection) for every URL pattern, and the [tool list](/reference/mcp-tool-list) for every tool.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Server shows disconnected or refuses the connection">
    Check the workspace slug in the URL. It must match a workspace in your SuprSend account exactly, for example `staging`, not the workspace's display name. A slug that doesn't exist fails with `403 workspace_forbidden`. To see your slugs, remove the slug, reconnect, and ask: "List my SuprSend workspaces."
  </Accordion>
</AccordionGroup>
