---
title: "Quickstart: Windsurf"
sidebarTitle: "Windsurf"
description: "Connect the SuprSend MCP server to Windsurf."
---

<Steps>
  <Step title="Install the SuprSend CLI">
    The MCP server runs through the SuprSend CLI.

    ```bash
    # macOS / Linux
    brew tap suprsend/tap
    brew install --cask suprsend
    ```

    For Windows or CI environments, download the binary from [GitHub Releases](https://github.com/suprsend/cli/releases).
  </Step>

  <Step title="Get a service token">
    Go to [Dashboard → Account Settings → Service Tokens](https://app.suprsend.com/en/account-settings/service-tokens) and generate a token for your workspace.
  </Step>

  <Step title="Add the MCP configuration">
    1. Go to **Windsurf Settings → Extensions**
    2. Add the following MCP configuration:

    ```json
    {
      "suprsend": {
        "command": "suprsend",
        "args": ["start-mcp-server"],
        "env": {
          "SUPRSEND_SERVICE_TOKEN": "your_service_token_here"
        },
        "name": "SuprSend MCP Server"
      }
    }
    ```

    3. Click the **Refresh** button in MCP Settings to activate the server.
  </Step>

  <Step title="Verify the connection">
    Open Windsurf's AI chat and try:

    ```
    List all workflows in my SuprSend workspace.
    ```

    If the server is connected, Windsurf will call the tool and return your workflows.
  </Step>
</Steps>

<Tip>
  Restrict which tools Windsurf can access using the `--tools` flag. See [Tool List](/reference/mcp-tool-list) for available identifiers.
</Tip>
