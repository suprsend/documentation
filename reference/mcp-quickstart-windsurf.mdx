<Note>
  **Beta — launched 2026-10-08.** The hosted SuprSend MCP server is in Beta. The endpoint, auth flow, and tool list may still change before general availability.
</Note>

<Note>
  Windsurf is now part of Devin. Documentation lives at [docs.devin.ai](https://docs.devin.ai/desktop/cascade/mcp); the config file paths below match that documentation.
</Note>

<Steps>
  <Step title="Open the Windsurf MCP config file">
    - **macOS and Linux:** `~/.config/devin/mcp_config.json`
    - **Windows:** `%APPDATA%\devin\mcp_config.json`

    Create the file if it doesn't exist.
  </Step>

  <Step title="Add the SuprSend MCP server">
    ```json
    {
      "mcpServers": {
        "suprsend": {
          "serverUrl": "https://mcp.suprsend.com/mcp",
          "headers": {}
        }
      }
    }
    ```

    `serverUrl` is the preferred field name; `url` also works. To pin a workspace, use `https://mcp.suprsend.com/mcp/staging`.

    Headers support environment-variable interpolation (`${env:AUTH_TOKEN}`) and file-based secrets (`${file:/path/to/secret}`) when the JWT bearer path for programmatic agents ships.
  </Step>

  <Step title="Sign in with your SuprSend account">
    Restart Windsurf. On the first tool call, Windsurf opens a browser window for WorkOS sign-in. Sign in with the SuprSend account that has access to the workspace you want to reach. Your role (admin or member) decides which tools you see.
  </Step>

  <Step title="Verify the connection">
    In Cascade (Windsurf's AI chat), try:

    ```
    List all workflows in my SuprSend workspace.
    ```

    If the server is connected, Windsurf calls `workflows.list` and returns your workflows.
  </Step>
</Steps>

<Tip>
  Scope the agent's reach by appending `?tools=` to the URL — for example `https://mcp.suprsend.com/mcp?tools=workflows.*,templates.*`. See the [tool list](/reference/mcp-tool-list) for group names.
</Tip>
