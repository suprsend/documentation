Synchronize workflow definitions from your SuprSend workspace to the local file system. This command downloads workflows from the management API, automatically handles pagination to retrieve all workflows, and saves them as individual JSON files in the `./suprsend/workflow/` directory.

## Syntax

```bash
suprsend workflow pull [flags]
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |
| `-m, --mode string` | Workflow mode to pull (`live` or `draft`) | `live` |
| `-d, --force-dir` | Create workflow directory without permission prompt | `false` |

## Examples

<CodeGroup>

```bash Basic Usage
# Pull all live workflows to current directory
suprsend workflow pull

# Pull workflows and create directory if needed
suprsend workflow pull --force-dir
```

```bash Advanced Usage
# Pull draft workflows from production
suprsend workflow pull --mode draft --workspace production --force-dir

# Pull with custom workspace and force directory creation
suprsend workflow pull --workspace staging --force-dir
```

</CodeGroup>
