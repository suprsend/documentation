Download workflow definitions from a SuprSend workspace to your local environment.
Useful for version control, editing, or keeping environments in sync.

```bash
suprsend workflow pull [flags]
```

## Options

| Flag                      | Description                               | Default |
| ------------------------- | ----------------------------------------- | ------- |
| `-h, --help`              | Show help for the command                 | –       |
| `-m, --mode string`       | Workflow mode to pull (`live` or `draft`) | `live`  |
| `-d, --output-dir string` | Directory to save pulled workflows        | `.`     |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file path

## Examples

Pull all live workflows to the current directory:

```bash
suprsend workflow pull
```

Pull workflows to a specific directory:

```bash
suprsend workflow pull --output-dir ./my-workflows
```

Pull draft workflows from production:

```bash
suprsend workflow pull --mode draft --workspace production --output-dir ./drafts
```
