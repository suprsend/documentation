Deactivate a workflow in a SuprSend workspace.  
Disabling a workflow prevents it from processing notifications until it is re-enabled.

```bash
suprsend workflow disable WORKFLOW_KEY [flags]
```

## Options

| Flag         | Description               | Default |
| ------------ | ------------------------- | ------- |
| `-h, --help` | Show help for the command | –       |

### Inherited Global Flags

This command also supports [Global Flags](/reference/cli-global-flags), such as:

* `--workspace` – Workspace to use (default: `staging`)
* `--service-token` – Service token for authentication
* `--output` – Output format (`pretty`, `json`, `yaml`)
* `--verbosity` – Logging level
* `--config` – Config file path

## Examples

Disable a workflow in your default (staging) workspace:

```bash
suprsend workflow disable my-workflow-key
```

Disable a workflow in the production workspace:

```bash
suprsend workflow disable my-workflow-key --workspace production
```
