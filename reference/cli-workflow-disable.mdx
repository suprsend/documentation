Set a workflow's activation status to disabled in a SuprSend workspace. This command makes a PATCH request to the management API endpoint to deactivate the specified workflow.

<Note>
To enable a workflow, use [`workflow enable`](/reference/cli-workflow-enable).
</Note>

## Syntax

```bash
suprsend workflow disable <workflow-key> [flags]
```

**Arguments:**
- `<workflow-key>` - Name of the workflow to disable (required)

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `-h, --help` | Show help for the command | – |

## Examples

<CodeGroup>

```bash Basic Usage
# Disable workflow in default workspace
suprsend workflow disable my-workflow-key

# Disable workflow with specific key
suprsend workflow disable user-signup
```

```bash Advanced Usage
# Disable workflow in production workspace
suprsend workflow disable my-workflow-key --workspace production

# Disable workflow in staging workspace
suprsend workflow disable order-confirmation --workspace staging
```

</CodeGroup>
