## Set up the connection

<Steps>
  <Step title="Add the SuprSend MCP server">
    Run **`MCP: Add Server`** from the command palette (`Cmd+Shift+P` on Mac, `Ctrl+Shift+P` on Windows and Linux). Choose **HTTP**, paste `https://mcp.suprsend.com/mcp`, and name the server `suprsend`.

    Choose **Global** to use it in every project, or **Workspace** to save it to `.vscode/mcp.json` in the current project.

    If that doesn't work, add the server to `mcp.json` yourself. Run **`MCP: Open User Configuration`**, or create `.vscode/mcp.json` in your project, and add:

    ```json
    {
      "servers": {
        "suprsend": {
          "type": "http",
          "url": "https://mcp.suprsend.com/mcp"
        }
      }
    }
    ```
  </Step>

  <Step title="Sign in with your SuprSend account">
    When you save the server, VS Code starts it, asks you to sign in, and opens your browser. Sign in with your SuprSend account. Your role decides the tools: admins get every tool, and members get read-only tools.
  </Step>

  <Step title="Verify the connection">
    Open Copilot Chat and switch it to **Agent** mode. MCP tools only work in Agent mode. Check that the SuprSend tools are on in the tools picker, then ask:

    ```
    List my SuprSend workspaces.
    ```

    Copilot answers with your SuprSend workspaces.
  </Step>
</Steps>

## Pin a workspace and restrict tools

By default, Copilot can use every workspace and tool your role allows. To keep it on one workspace, or to give it only the tools a job needs, use one of these URLs when you add the server, or in `mcp.json`:

- **Pin a workspace** by adding its slug to the path. The agent then can't switch to another workspace:

  ```
  https://mcp.suprsend.com/mcp/staging
  ```

- **Restrict tools** with `?tools=`, a comma-separated list of tool names or groups:

  ```
  https://mcp.suprsend.com/mcp/staging?tools=users_*,data_*
  ```

See [Scope the connection](/reference/mcp-overview#scope-the-connection) for every URL pattern, and the [tool list](/reference/mcp-tool-list) for every tool.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Server shows disconnected or refuses the connection">
    Check the workspace slug in the URL. It must match a workspace in your SuprSend account exactly, for example `staging`, not the workspace's display name. A slug that doesn't exist fails with `403 workspace_forbidden`. To see your slugs, remove the slug, reconnect, and ask: "List my SuprSend workspaces."
  </Accordion>
  <Accordion title="Tool list is empty after sign-in">
    Check that Copilot Chat is in **Agent** mode and the SuprSend tools are on in the tools picker. The `?tools=` filter may also be too strict: remove it and save the config again.
  </Accordion>
  <Accordion title="Settings Sync overwrites my config">
    User-level `mcp.json` syncs through VS Code's Settings Sync. If another machine's sync replaces your SuprSend entry, re-add it on the current machine and sync pushes the merged config.
  </Accordion>
</AccordionGroup>
