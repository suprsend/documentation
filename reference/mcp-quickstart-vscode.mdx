<Note>
  **Beta — launched 2026-10-08.** The hosted SuprSend MCP server is in Beta. The endpoint, auth flow, and tool list may still change before general availability.
</Note>

Add the hosted SuprSend MCP server to VS Code with GitHub Copilot Chat and drive your SuprSend account in natural language — manage workflows, templates, broadcasts, and preferences, or query delivery analytics.

## Install via the SuprSend agent plugin (recommended)

<Warning>
  VS Code [Agent Plugins](https://code.visualstudio.com/docs/copilot/customization/agent-plugins) are a preview feature. The host requires the `chat.plugins.enabled` setting to be on; it's managed at the organization level. If it's disabled, contact your admin before continuing.
</Warning>

<Steps>
  <Step title="Install the plugin from source">
    1. Open the command palette (`Cmd/Ctrl + Shift + P`).
    2. Run **`Chat: Install Plugin From Source`**.
    3. Enter the plugin URL:

    ```
    https://github.com/suprsend/agent-plugin
    ```
  </Step>

  <Step title="Enable the plugin">
    In the Extensions sidebar, search `@agentPlugins` and confirm **suprsend** is enabled under **Agent Plugins → Installed**.
  </Step>

  <Step title="Sign in with your SuprSend account">
    On the first tool call, VS Code prompts a browser sign-in. Sign in with the SuprSend account that has access to the workspace you want to reach.
  </Step>
</Steps>

See [Agent plugin](/reference/agent-plugin) for the full plugin install matrix.

## Alternative: edit `mcp.json` directly

<Steps>
  <Step title="Open the MCP config file">
    - **Workspace-level:** create `.vscode/mcp.json` in your project.
    - **User-level:** run **`MCP: Open User Configuration`** from the command palette.
  </Step>

  <Step title="Add the SuprSend MCP server">
    ```json
    {
      "servers": {
        "suprsend": {
          "type": "http",
          "url": "https://mcp.suprsend.com/mcp"
        }
      }
    }
    ```

    `type: "http"` is the one supported value for remote servers in VS Code. To pin a workspace, use `https://mcp.suprsend.com/mcp/staging`.
  </Step>

  <Step title="Sign in with your SuprSend account">
    Reload VS Code (`Developer: Reload Window`). On the first tool call, Copilot Chat prompts a browser sign-in. Approve the first tool call, and you're done.
  </Step>
</Steps>

<Tip>
  Scope the agent's reach by appending `?tools=` to the URL — for example `https://mcp.suprsend.com/mcp?tools=users.*,data.*`. See the [tool list](/reference/mcp-tool-list) for group names.
</Tip>

## Verify the connection

In a Copilot Chat panel, try:

```
List all workflows in my SuprSend workspace.
```

If the server is connected and signed in, Copilot calls `workflows.list` and returns your workflows.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Tool list is empty after sign-in">
    Your SuprSend role may be a member with no read tools on the pinned workspace, or the `?tools=` filter may be too strict. Remove the filter, confirm your role at [app.suprsend.com](https://app.suprsend.com), then reload the window.
  </Accordion>

  <Accordion title="Permissions dialog on first tool call">
    Copilot asks for permission before each tool runs for the first time. Approve the specific tool (not "always allow") until you're confident in the agent's behaviour on this workspace.
  </Accordion>

  <Accordion title="Settings Sync overwrites my config">
    User-level `mcp.json` syncs through VS Code's Settings Sync. If a different machine's sync replaces your SuprSend entry, re-add it on the current machine and sync will push the merged config.
  </Accordion>
</AccordionGroup>
