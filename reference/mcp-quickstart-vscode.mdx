## Set up the connection

<Tabs>

<Tab title="Agent plugin">

VS Code [Agent Plugins](https://code.visualstudio.com/docs/copilot/customization/agent-plugins) are a preview feature. They need the `chat.plugins.enabled` setting, which your organization manages.

<Steps>
  <Step title="Install the plugin">
    Run **`Chat: Install Plugin From Source`** from the command palette (`Cmd/Ctrl + Shift + P`) and enter:

    ```
    https://github.com/suprsend/agent-plugin
    ```

    The plugin adds the hosted server on the US endpoint. If your workspace's data is in the EU or India, use the `mcp.json` tab instead.
  </Step>

  <Step title="Sign in with your SuprSend account">
    On the first tool call, VS Code opens your browser. Sign in with your SuprSend account. The agent gets the same permissions your role has in the SuprSend dashboard.
  </Step>

  <Step title="Verify the connection">
    In Copilot Chat, ask:

    ```
    List my SuprSend workspaces.
    ```

    Copilot answers with your SuprSend workspaces.
  </Step>
</Steps>

</Tab>

<Tab title="mcp.json">

<Steps>
  <Step title="Add the SuprSend MCP server">
    Add this to `.vscode/mcp.json` in your project, or to your user configuration (**`MCP: Open User Configuration`**):

    ```json
    {
      "servers": {
        "suprsend": {
          "type": "http",
          "url": "https://mcp.suprsend.com/mcp"
        }
      }
    }
    ```

    This is the US endpoint. Use the endpoint for your workspace's data region:

    | Region | Endpoint |
    |---|---|
    | US | `https://mcp.suprsend.com/mcp` |
    | EU | `https://mcp.eu.suprsend.com/mcp` |
    | India | `https://mcp.in.suprsend.com/mcp` |
  </Step>

  <Step title="Sign in with your SuprSend account">
    Reload VS Code (**`Developer: Reload Window`**). On the first tool call, VS Code opens your browser. Sign in with your SuprSend account. The agent gets the same permissions your role has in the SuprSend dashboard.
  </Step>

  <Step title="Verify the connection">
    In Copilot Chat, ask:

    ```
    List my SuprSend workspaces.
    ```

    Copilot answers with your SuprSend workspaces.
  </Step>
</Steps>

</Tab>

</Tabs>

## Pin a workspace and restrict tools

By default, Copilot can use every workspace and tool your role allows. To keep it on one workspace, or to give it only the tools a job needs, use one of these URLs in `mcp.json`:

- **Pin a workspace** by adding its slug to the path. The agent then can't switch to another workspace:

  ```
  https://mcp.suprsend.com/mcp/staging
  ```

- **Restrict tools** with `?tools=`, a comma-separated list of tool names or groups:

  ```
  https://mcp.suprsend.com/mcp/staging?tools=users.*,data.*
  ```

See [Scope the connection](/reference/mcp-overview#scope-the-connection) for every URL pattern, and the [tool list](/reference/mcp-tool-list) for every tool.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Server shows disconnected or refuses the connection">
    Check the workspace slug in the URL. It must match a workspace in your SuprSend account exactly, for example `staging`, not the workspace's display name. A slug that doesn't exist fails with `403 workspace_forbidden`. To see your slugs, remove the slug, reconnect, and ask: "List my SuprSend workspaces."
  </Accordion>
  <Accordion title="Tool list is empty after sign-in">
    The `?tools=` filter may be too strict. Remove it and reload the window.
  </Accordion>
  <Accordion title="Settings Sync overwrites my config">
    User-level `mcp.json` syncs through VS Code's Settings Sync. If another machine's sync replaces your SuprSend entry, re-add it on the current machine and sync pushes the merged config.
  </Accordion>
</AccordionGroup>
